# 学科学情分析系统 - 开发详细说明文档

本文件基于 `学科学情_独立版.html` 的 UI 设计与交互逻辑编写，旨在指导前端开发人员进行功能实现。

---

## 1. 页面架构与布局 (Layout)

系统采用经典的 **App Shell** 结构：
- **左侧边栏 (Sidebar)**：一级导航，宽度 80px，包含图标快捷入口。
- **顶部导航 (Top Nav)**：二级导航，用于在“校级报告”、“班级报告”、“学科学情”等模块间切换。
- **主内容区 (Main Content)**：
    - **Filter Bar**：放置学科、班级、时间、任务类型等全局筛选项。
    - **Segmented Control**：控制视图维度（如：按时间 / 按章节）。
    - **Nested Layout**：左侧为章节目录（仅在按章节模式显示），右侧为核心数据展板。

---

## 2. 核心交互模块说明

### 2.1 统计概览 (Summary Cards)
- **知识点数量**：显示当前筛选范围内的总知识点数。
- **未掌握数量**：得分率低于“未掌握”阈值的知识点总数。
- **共性错题数**：班级错题的总量统计。
- **交互**：点击卡片可直接触发下钻（Drill-down）详情视图。

### 2.2 知识点分析视图 (Analysis Views)
支持 **树状图 (Tree View)** 和 **数据对比表 (Table View)** 切换。

#### [Tree View] - ECharts 实现
- **图表类型**：`tree` (正向或径向布局)。
- **逻辑说明**：
    - 根节点为学科体系名称。
    - **分级渲染**：不同层级的知识点（知、题、微）使用不同的前缀图标或颜色。
    - **状态配色**：
        - 绿色 (≥85%)：掌握
        - 橙色 (60%-85%)：一般
        - 红色 (<60%)：未掌握
- **点击交互**：点击树节点或标签可打开该知识点的详情侧拉面板。

#### [Table View] - 分级过滤
- **层级切换**：支持“全部”、“一级”、“二级”、“三级”知识点筛选展示。
- **列项定义**：
    - 知识点名称（带层级图标）
    - 考察频次
    - 班级得分率 vs 年级得分率
    - 得分率差值（正值绿色，负值红色）
    - 未掌握人数

## 3. 详情下钻逻辑 (Drill-down Details)

点击任何知识点后，从右侧滑出 **全屏详情视图**：
- **左侧列表**：同级知识点的快捷导航列表，显示得分率缩略信息。
- **右侧展示区**：
    - **趋势切换**：支持在“趋势图”（折线图）和“明细表”之间切换。
    - **作业考试明细**：列表展示该知识点在每一场任务中的表现。
    - **相关共性错题**：展示该知识点关联的具体错题内容及作答情况。

## 4. 专项配置逻辑 (Settings)

### 4.1 权重分配策略 (Weight Allocation)
在“作业考试明细”中可进行权重分配，支持以下交互：
- **默认模式：时间衰减 (Time Decay)**
    - 公式：$w_i = \frac{2(k-i+1)}{k(k+1)}$
    - 逻辑：离当前越近的任务权重越高，越能反映当前水平。
- **一键均分**：各任务权重相等（$1/n$）。
- **手动修改**：
    - 校验规则：各场权重之和必须等于 **1.0**。
    - 浮点数处理：UI 层面保留两位小数，提交时后端需重新归一化。

### 4.2 掌握程度设置 (Mastery Levels)
支持自定义评估标准：
- **3档模式**：掌握、一般、未掌握。
- **4档模式**：优秀、掌握、一般、未掌握。
- **逻辑**：修改分值区间后，主页面的树图配色与统计数量需实时更新。

## 5. 样式与资源规范

- **字体 (Typography)**：使用 `Outfit` 和系统默认无衬线字体。
- **色彩规范 (Colors)**：
    - Primary: `#3b82f6` (蓝色)
    - Danger: `#ef4444` (红色)
    - Warning: `#f59e0b` (橙色)
- **图标 (Icons)**：使用 `FontAwesome 6.4.0` 免费版。
- **动画 (Animations)**：
    - 弹窗采用 `fadeIn` + `slideUp`。
    - 侧拉详情页面采用 `translateX` 过渡效果。
