# 一、方案背景与目标

## 1.1 现状与痛点

参考样本是一份质量很高的人工（或人工深度参与）点评文档，但它的生产方式不可规模化：

1. **成本高**：52 份卷子逐份写出「总体评价 + 4-6 条主要问题 + 3-4 条修改建议」，且每条问题都要引用学生原文并给出订正，单班一次周练的点评工作量以小时计。
2. **口径不统一**：档次判定、问题严重度排序、建议颗粒度全凭教师个人经验，跨班级、跨场次不可比。
3. **班级数据不结构化**：分数分布、错词频次、覆盖人数等结论散落在自然语言段落里，无法沉淀为可追踪的学情数据。样本中「另见上表 20 个高频错词」所指的高频错词表在实际文档中并不存在，正是手工维护班级共性数据的典型失败案例。
4. **正向资产流失**：样本中出现的大量好句（`Only by...could I...`、`No sooner...than...`、`So glad am I...`、`Music had simply done what words could not`）只能靠教师手写摘录，无法形成可复用的班级积累库。
5. **无追踪闭环**：这次指出的「时态混乱约三分之二同学」，下次是否收敛，没有任何机制回答。

## 1.2 产品目标

把这份点评文档升级为**可自动生成、可教师复核、可结构化追踪、可导出交付**的班级智批报告，并接入现有学科学情体系。

具体目标：

| 目标 | 衡量方式 |
| --- | --- |
| 单班单次作文批改产出时间从小时级降到分钟级 | 上传→报告生成→教师复核完成的端到端耗时 |
| 点评口径统一、可跨班跨场次对比 | 同一份卷子在不同时间重跑，档次判定一致率 |
| 班级共性问题由数据自动得出而非人工归纳 | 高频错词榜、共性问题 TOP N 全部可溯源到实例 |
| 每条问题都有原文证据，零编造 | 引文字符级匹配校验通过率 100% |
| 教师始终拥有最终裁定权 | 未确认的 AI 结果不进入正式学情与发布报告 |

## 1.3 三条设计底线

从参考样本反推出的不可妥协约束，后续所有设计均服从：

- **证据可追溯**：任何一条问题、任何一句原文引用，都必须能在该生 OCR 还原文本中定位。定位失败即丢弃该条，不得保留。
- **口径可对齐**：分数与档次严格对齐内置的高考应用文写作五档标准，不自创评分体系；教师已批分数为最高优先级事实。
- **教师可干预**：AI 输出是**建议**，教师确认后才成为**结论**。锁定后的结果不被重跑覆盖。

# 二、适用题型与评分口径

## 2.1 题型范围

| 阶段 | 题型 | 满分 | 说明 |
| --- | --- | --- | --- |
| 首期（P0/P1） | 高考英语应用文写作 | 15 分 | 参考样本即此题型，评分标准与维度权重按此调优 |
| 扩展（P3） | 读后续写 | 25 分 | 需增加「情节协同度、人物一致性、原文伏笔回收」等专属维度 |
| 扩展（P3） | 概要写作 | 15 分 | 需增加「信息覆盖率、转述而非照抄」判定 |

不同题型**不合并统计**，分列展示与追踪。

## 2.2 内置评分锚（应用文写作 15 分制）

系统内置下表作为档次判定的唯一标准文案，报告中原样呈现（可折叠），教师不可在单次报告中临时改写，避免同一场次内标准漂移。

| 档次 | 分数 | 总体要求 |
| --- | --- | --- |
| 第五档 | 13-15 分 | 完全完成试题规定的任务；覆盖所有内容要点；应用了较丰富的语法结构和词汇；语法和用词方面有个别错误，但不影响意义表达；有效地使用了语句间的连接成分，全文结构紧凑。 |
| 第四档 | 11-12 分 | 完成了试题规定的任务；覆盖所有内容要点；应用的语法结构和词汇能满足任务需求；有一些语法结构和词汇方面的错误，但不影响理解；应用了简单的连接成分，全文结构基本紧凑。 |
| 第三档 | 8-10 分 | 基本完成了试题规定的任务；覆盖部分内容要点；应用的语法结构和词汇能基本满足任务需求；有一些语法结构和词汇方面的错误，影响了理解；未恰当使用连接成分，全文内容基本连贯。 |
| 第二档 | 5-7 分 | 未恰当完成试题规定的任务；漏掉或未描述清楚部分主要内容；有较多语法结构和词汇方面的错误，影响了理解；未使用连接成分，全文内容缺少连贯性。 |
| 第一档 | 0-4 分 | 未完成试题规定的任务；明显遗漏主要内容；语法结构单调、词汇有限；较多语法结构和词汇方面的错误，严重影响理解；缺乏连接成分，内容不连贯。 |

分数→档次为闭区间映射：`13-15→五档`、`11-12→四档`、`8-10→三档`、`5-7→二档`、`0-4→一档`。支持 0.5 分粒度（与教师实际批分习惯一致，样本中卷面总分即含 .5）。

## 2.3 两种运行模式

| | M1 辅评模式（默认） | M2 智评模式 |
| --- | --- | --- |
| 分数来源 | **沿用教师红笔已批分数**，AI 不重新打分 | AI 输出建议分 + 档次 + 判分理由 |
| AI 职责 | 诊断（错误标签 + 亮点）、逐人点评文案、班级聚合 | 上述全部 + 给分 |
| 教师动作 | 复核点评文案与问题条目，分数无需确认 | 必须逐份确认或修改分数后才生效 |
| 上线条件 | 通过引用可定位校验即可上线 | 必须先通过 10.3 的校准门槛 |
| 对应样本 | 参考文档即 M1 模式（「各生红笔分数为原卷已批分数」） | 无 |

**M1 是默认模式**：它绕开了「AI 打分是否可信」这一最大落地阻力，直接解决教师的真实痛点（写点评、归纳共性问题）。M2 仅在校准达标后开放，且开放后仍保留教师改分权。

## 2.4 维度分与档次的关系（重要口径）

第六章的六维得分率**仅用于诊断解释与趋势追踪，不反算作文总分**。总分一律以档次分为准。

原因：主观题的整体印象分不是维度分的线性加权和；若用维度加权和反算总分，会出现「维度分算出 10.7 分，教师批 8 分」这类无法向教师解释的矛盾。维度分回答的是「弱在哪、该练什么」，不是「该给几分」。

# 三、输入数据与预处理

## 3.1 必备输入

| 输入项 | 必需性 | 用途 |
| --- | --- | --- |
| 题目原文与写作要求 | 必需 | 抽取内容要点、词数要求、**题眼词清单** |
| 学生答题卡图像（逐份） | 必需 | OCR、卷面规范判定 |
| 班级名单（学号 + 姓名） | 必需 | 匹配、排序、缺考识别 |
| 教师已批分数 | M1 必需 | 沿用为最终分数 |
| 场次信息（考试/作业、结束时间） | 必需 | 对接跨场次权重规则 |
| 评分标准版本 | 可选 | 缺省取系统内置当前版本 |

## 3.2 题眼词清单（从参考样本提炼的关键机制）

样本中最重的失分点是**题眼词拼错**：`concert` 误写为 `concern`/`convert`、`band` 误写为 `bank`、`rhythm` 出现 `rhynm`/`rythom`/`rythems` 三种误拼。这类错误的危害远超普通拼写错误——它是本篇作文的核心名词，错则全篇指向不明。

系统据此建立机制：

1. 从题目要求中自动抽取题眼词（主题名词、场景词、指定要点关键词），教师可增删；
2. 题眼词命中错误时严重度**强制升为 S3**，并在班级报告中单独成榜；
3. 逐人点评中，题眼词错误必须排在「主要问题」首位（样本对陈思翰的处理即如此：「属题眼词失分，最伤分数」）。

## 3.3 图像处理

- 裁剪、透视矫正、去阴影与底色、增强对比；
- **答题区边界检测**：识别答题框范围，用于判定 `ERR-PAP-03 写出答题区`（样本中苗冉、陈瑞麒、杨睿杰、王冉东均有此问题，高考中答题区外内容无效）；
- **末行贴边检测**：判定 `ERR-PAP-04`（样本中刘屹澄末行贴近底边被扫描裁切）。

## 3.4 手写识别与文本还原

- 输出整篇文本 + **词级置信度** + 词级坐标；
- **涂改、划改、行上插词、铅笔补写区域不清除**，单独标记为卷面证据（`ERR-PAP-01/02`）。样本中李志涂改 5-6 处、周厚禄行上插词导致病句 `we song the whole world were could listening`，这些信息只有保留涂改痕迹才能识别；
- 无法辨识处输出占位符 `[?]`，样本中已有此实践（`What follo[?]...perform[?]nce`），系统将其规范化为统一标记。

## 3.5 词数统计口径

| 情形 | 是否计入词数 |
| --- | --- |
| 答题区内正常书写英文单词 | 计入 |
| 划掉/涂改掉的词 | 不计入 |
| 行上补插、铅笔补写的词 | 计入（其表达的确实是文章内容） |
| 答题区外书写的词 | 不计入有效词数，但记 `ERR-PAP-03` |
| 拼音专有名词（如 `Haikuotiankong`） | 计入，并另记 `ERR-NAM-01` |
| 缩写形式（`There're`、`don't`） | 按 1 个词计，并另记书面语缩写问题 |

样本参考值：全班平均约 130 词，超 150 词 10 人，最多约 210 词（邱亦楠），最少约 60 词（王冉东），高考要求 80 词左右。词数达标判定需以题目实际要求为准，不硬编码 80。

## 3.6 OCR 质量闸门

- 词置信度低于阈值（建议初始 0.75，待校准）→ 该词标 `待确认`：**不参与高频错词统计、不作为扣分依据**，但仍展示供教师核对；
- 整页平均置信度低于阈值（建议初始 0.6）→ 该份转人工，**不进入班级聚合**，报告头部显示「N 份待人工批改」；
- 严禁在低置信文本上生成「拼写错误」类结论——这是最容易产生幻觉的环节。

# 四、评价维度体系（六维）

把样本中隐含的点评角度显性化为可计算、可聚合、可追踪的维度。

| 编码 | 维度 | 内涵 | 建议权重 | 样本证据 |
| --- | --- | --- | --- | --- |
| D1 | 内容与要点 | 要点覆盖、内容具体度、切题、细节支撑 | 25% | 郭璐菊内容跑偏（滑向光盘行动）7 分；梅曦月留白三分之一；李想用具体数字支撑细节被点为亮点 |
| D2 | 语言准确性 | 拼写、词形词性、时态语态、主谓一致、冠词、可数性、搭配、句式正确性 | 30% | 样本第一共性问题：拼写失分严重且集中；第二：约三分之二同学时态混乱 |
| D3 | 词汇丰富度与语域 | 高级词汇、地道搭配、自造词、口语/网络语域、体裁语体 | 12% | 黄铭玮广播稿口吻不符体裁；郭致远 `mad`、陈思翰 `even a devil may cry` 语域不当 |
| D4 | 句式多样性 | 从句、非谓语、倒装强调、虚拟语气；句式单一为负项 | 13% | 陈泽宇句式单一（Then/Finally 罗列）被明确指为冲四档障碍；韩浩琪、张津铭、于璟妍的倒装句被树为标杆 |
| D5 | 篇章结构与衔接 | 三段式完整性、段落聚焦、连接成分、首尾呼应 | 12% | 宛钰皓只有两段缺总结段「文章没写完」；李昱璇第二段环境描写与主题关联弱 |
| D6 | 规范与卷面 | 词数达标、涂改、答题区外书写、标点、大小写、换行拆词、专有名词与日期规范 | 8% | 样本单列「卷面与答题规范」为共性问题第 6 条 |

维度得分率：

$$
R_d = \frac{\text{该维度实得分}}{\text{该维度满分}} \times 100\%
$$

维度扣分来源 = 该维度下所有错误实例按严重度加权累计，并设下限 0、上限 100%。权重为**建议初始值，需业务校准**，支持按题型与学校配置。

维度权重与档次分并列展示时，报告须明示：「维度得分率用于定位薄弱项，不用于反算作文总分」（见 2.4）。

# 五、错误标签体系（Taxonomy）

标签体系是班级聚合与跨场次追踪的**唯一基础**。所有实例必须落到已注册标签，禁止自由文本标签，否则无法聚合。

## 5.1 严重度分级

| 级别 | 定义 | 权重 |
| --- | --- | --- |
| S3 硬伤 | 影响理解、题眼词错误、要点缺失/跑题、结构缺失、答题区外书写、体裁不符、词数严重不足 | 1.0 |
| S2 明显错误 | 语法/搭配/词形错误，阅卷可辨识但确实失分 | 0.6 |
| S1 规范瑕疵 | 标点、大小写、换行、书写布局、专名格式等 | 0.3 |

严重度权重为建议初始值。同一标签在特定条件下可升级（如题眼词拼写错误由 S2 强制升 S3）。

- 新增标签须走注册流程（编码、维度、严重度、判定要点、正反例），不允许 AI 运行时自创标签；

## 6.2 点评文案生成规范

严格对齐参考样本的成熟范式：

**总体评价（80-140 字）**，必须含三要素：
1. 一个**具体**优点，带原文引用或具体细节（不写「结构清晰、语言流畅」这类无信息量套话）；
2. 主要失分归因，指向维度与标签；
3. 一句可执行的提分方向或档位预期。

样本范式（戴棹一）：「结构清晰，内容涵盖个人节目与全员合唱，结尾点明意义（platform、passion、enrich school life），过渡自然，书写流畅，是本卷中规中矩的第三档中上之作。失分点集中在零星拼写（Than→Then）与时态前后不一致（boosts 与 enriched 并存），属于『再检查一步就能上 11 分』的类型。」——优点具体到词，归因具体到标签，预期具体到分数，这是生成质量的验收基准。

**主要问题（3-6 条）**，每条固定格式：`原文引用 → 错误说明 → 正确形式`，按严重度降序、同级按维度权重降序。题眼词错误（`ERR-SPE-01`）强制置顶。

**修改建议（3-4 条）**，必须可操作：包含具体训练动作、清单或专练对象。禁止输出「多加练习」「注意语法」这类空话。

样本范式对比：
- ✅ 合格：「整理『不及物动词+介词』清单：listen to / arrive at / belong to / attend（无 to）」
- ✅ 合格：「每周做 2 组『两句合一』训练，用定语从句、非谓语提升句式层级」
- ❌ 不合格：「加强语法练习，提高写作水平」

**语气规范**：第二人称、具体、鼓励与直接并存；不堆砌形容词；**禁止学生间横向贬损比较**（可以说「全班标杆之一」，不可以说「比某某强多了」）；对低分卷必须先给一个真实优点再谈问题（样本对郭璐菊的处理：先肯定「书写全班最工整之列，卷面零涂改，这是重要优势」，再指出内容跑偏，并给出「把方向校正后，你完全可以上到第三、四档」）。

## 6.3 提分空间提示（upliftHint）

样本中反复出现的高价值表达：「修掉这三处就能上 10 分」「13 分可期」「你的 8 分里至少有 1 分丢在卷面」。将其产品化：

- 输入：该生当前分、所处档次的分数区间、S3/S2 错误清单及其所属维度；
- 逻辑：判断「若清除全部 S3 + 前 N 条 S2 错误，是否足以跨入上一档分数区间」；
- 输出：**定性区间表达**，绑定到具体条目，例如「清除 3 处题眼词拼写 + 统一时态，可从 8 分进入第四档（11-12 分）区间」；
- **禁止输出精确小数预测**（如「可提升 2.3 分」）——主观题不存在这种精度，伪精度会损害教师信任。

## 6.4 卷面评级

`优秀（零涂改、布局留余量）/ 良好 / 待改进（涂改多处或补写）/ 不合格（写出答题区或末行裁切）`，并在报告中列出待改进与不合格名单（样本已单列此项）。

## 7.5 共性问题 TOP N 与排序算法

**准入门槛**：某标签覆盖人数 ≥ `max(2, 班级人数 × 5%)` 才可进入班级共性问题；否则只出现在个人报告中。52 人班的门槛为 3 人。

**排序得分**：

$$
\text{IssueScore}(t) = \left(\frac{n_t}{N}\right)^{\alpha} \times s_t \times d_t
$$

- $n_t$：命中该标签的人数（**按人去重**，一人多次命中同一标签只计 1，避免个别学生刷高某标签）；
- $N$：有效卷份数（不含缺考、转人工、无效成绩）；
- $\alpha$：人数比抑制指数，建议初始 0.5（开方），防止极端人数比压过严重度差异；
- $s_t$：严重度权重（S3=1.0 / S2=0.6 / S1=0.3）；
- $d_t$：该标签所属维度权重（D1-D6，归一化到 0-1）。

**并列裁决**（保证结果可复现）：IssueScore 相同 → 严重度高者优先 → 覆盖人数多者优先 → 标签编码字典序。

**展示**：TOP 5-8 条，每条包含 覆盖人数与占比、严重度、典型原文示例 2-3 条、统一订正、班级级训练建议。默认按严重程度排序（与样本一致），可切换为按覆盖人数排序。

**同族合并**：语义同族的标签在班级层面合并展示，避免报告被同类问题刷屏。例如 `ERR-SPE-01/02/03/04` 合并为「拼写失分严重且集中」一条，内部保留子类明细可展开——样本正是这样处理的（一条拼写问题下同时给出题眼词、rhythm 三种误拼、以及 20 个高频错词的指引）。

## 7.6 共性优点与班级好句池

- 共性优点 3-5 条，每条须有覆盖人数或具体例证，不写空泛表扬（样本：「三段式结构意识普遍较好，多数同学能按『概况—节目—感受』组织内容」）；
- **班级好句池**：由 `HLT-*` 标签自动汇集，每条含 原句、亮点标签、出处学生、可迁移的话题方向、建议动作（背诵/仿写/迁移）；
- 好句池是报告的**正向资产输出**，支持单独导出为「本周积累页」供早读使用；
- 是否展示出处学生姓名可配置（默认展示，见第十七章待确认项）。样本明确展示了姓名并写「建议全班积累」。

## 7.9 分层与临界名单

| 分层 | 判定 | 用途 |
| --- | --- | --- |
| 标杆卷 | 本班最高档，且含 ≥2 个 `HLT-*` 高级标签 | 讲评示范、好句池主要来源 |
| 冲档临界生 | 分数位于某档下沿（如 10 分冲四档、12 分冲五档），且 `upliftHint` 显示清除现有 S3/S2 后可跨档 | **最高性价比的辅导对象**，样本中大量存在（戴棹一「再检查一步就能上 11 分」、韦思衡「四处修完，12-13 分可期」） |
| 稳定中段 | 档次中段，问题分散 | 常规训练 |
| 重点辅导 | 一档/二档，或 `ERR-CON-01/02`、`ERR-LEN-02` 命中 | 优先解决要点覆盖与词数，样本对王冉东、郭璐菊、李瑾涵的处理路径即「先保要点、先少错写短」 |
| 待人工 | OCR 失败或需复核 | 不进聚合 |

临界名单是班级报告对教师最有行动价值的输出，须在报告中前置展示。

## 7.10 班级教学建议

3-5 条，每条必须满足：**指向具体标签族 + 给出具体训练动作 + 标注预期影响面（覆盖人数）**。

样本范式（合格）：
- 「专项清除『although...but / because...so』中式连用」
- 「不可数名词清单专项：music / advice / news / progress / fun」
- 「记叙类应用文全文主体时态=一般过去时，写完通读统一」
- 「压缩专项：保留三种曲风各 1 句 + 感受 1 句，目标 100 词内」

生成规则：从共性问题 TOP N 反查标签绑定的训练建议模板，按覆盖人数降序取前 3-5 条，去重合并同类项；同时至少包含 1 条正向建议（保持并迁移已有优势），避免报告全是批评。

# 八、跨场次追踪（对接现有学科学情体系）

## 8.1 映射关系

将六维与错误标签族映射为英语学科的**能力节点**，挂接到现有知识图谱的子节点上（父级节点不直接挂接，沿用《知识点汇总分析方案》4.1 的冒泡规则）：

```
英语 · 书面表达（父）
├── D1 内容与要点（父）
│   ├── 要点覆盖 / 内容具体度 / 切题一致性
├── D2 语言准确性（父）
│   ├── 拼写与词形 / 时态语态 / 主谓一致与可数性 / 冠词与所有格 / 搭配 / 句法结构
├── D3 词汇丰富度与语域
├── D4 句式多样性
├── D5 篇章结构与衔接
└── D6 规范与卷面
```

## 8.2 权重规则复用

**直接复用**《学科学情·知识点汇总分析方案》第三章，不另立规则：

- 默认按实际日期间隔的时间衰减：$a_i = 2^{-\Delta d_i / H}$，$w_i = a_i / \sum_{j=1}^{k} a_j$，初始 $H = 30$ 天；
- 同日等权、近日期近似等权、跨月逐渐衰减；
- 支持一键均分、恢复时间衰减、手动调权（非负且总和 1.0）；
- 某维度/标签未在全部场次考查时，未考查场次不进有效集 $S$、不记 0 分，按原比例在 $S$ 内重新归一化；
- 有效场次权重之和为 0 时显示 `--` 并提示，不做除零计算。

## 8.3 追踪输出

| 输出 | 说明 |
| --- | --- |
| 维度掌握率趋势 | 六维得分率随场次变化的折线 |
| **错误标签消退曲线** | 关键标签的覆盖人数比随场次变化，例如「记叙时态混用 67% → 40% → 25%」，直接回答「上次指出的问题改了没有」 |
| 好句池累积量 | `HLT-*` 高级句式的人数覆盖增长（倒装、非谓语、从句的使用面是否扩大） |
| 词数收敛情况 | 平均词数是否向题目要求收敛 |
| 档次迁移矩阵 | 相邻两次场次的档次流动（升档/持平/降档人数） |
| 个人追踪 | 单个学生的维度雷达对比与标签清单变化 |

## 8.4 口径约束

- 只有**同题型、同评分标准版本**的场次才可合并汇总；应用文与读后续写分列，不合并；
- 满分不同的题型（15 分 / 25 分）一律换算为得分率后再汇总，不比较原始分；
- M1 模式下汇总的是教师分，M2 模式下汇总的是已确认分；**未经教师确认的 AI 建议分不得进入任何跨场次汇总**；
- 主观分的场次间可比性弱于客观题，报告中须常驻提示：「作文分为主观评分，跨场次趋势反映整体走向，单份 ±1 分差异不具备诊断意义」。

# 九、教师复核工作流

## 9.1 状态机

```
待批改 → AI 已生成 → 教师复核中 → 已确认（锁定） → 已发布
                        ↓
                   转人工（OCR 失败 / 低置信 / 分差过大）
```

- `已确认（锁定）`后 AI 重跑不得覆盖，只能生成新版本；
- `已发布`后修改须走「撤回发布」并留痕。

## 9.2 复核操作

| 操作 | 说明 |
| --- | --- |
| 改分 | 仅 M2 需要；M1 下教师分只读，如需修正走「成绩变更」并留痕 |
| 删除错误条 | AI 误判时删除，删除动作与理由计入校准样本 |
| 修改错误条 | 改标签、改订正、改说明 |
| 新增错误条 | 手工添加，必须选已注册标签；填写的原文引用同样过字符级匹配校验 |
| 增删亮点 | — |
| 编辑点评文案 | 三段文案均可编辑，保留 AI 原文以便对比与回流 |
| 批量确认 | 仅对「置信度 ≥ 阈值 且 无 S3 争议项」的卷子开放 |
| 按标签筛选 | 例如只看命中 `ERR-TEN-01` 的卷子，便于集中讲评备课 |

## 9.3 发布前校验

- 全部学生均有分数，或已标记为缺考/作弊/排除名单/转人工；
- 至少 1 条共性问题，否则显示空态并说明（有效卷不足或错误分散）；
- 所有保留的错误条 `verified = true`（引文匹配通过）；
- 报告头如实显示「N 份待人工批改，未计入本次班级统计」。

## 9.4 复核数据回流

教师对 AI 结果的每一次修改（删除率、改标率、文案编辑距离、M2 改分幅度）都作为校准样本沉淀，用于：调整低置信阈值、优化标签判定规则、评估是否达到 M2 开放门槛。**回流数据不含学生原卷图像与姓名的对外传输**（见第十四章）。

# 十、质量保障与防幻觉

主观题智批最大的风险不是分数偏差，而是**编造学生没写过的内容**。以下机制为强制项。

## 10.1 引文可定位校验（硬闸门）

- 生成后，对每条 `errors[].quote` 与 `highlights[].quote` 在该生 OCR 文本中做字符级匹配；
- 匹配失败 → 该条**直接丢弃**，不做模糊匹配、不做「近似改写后保留」；
- 若丢弃后某维度无任何实例支撑，该维度结论降级为「暂无充分证据」，不得输出定性判断；
- OCR 本身不确定的字符在引文中保留 `[?]` 标记（沿用样本做法），并在报告中说明该标记含义；
- 校验通过率必须为 100% 才允许发布，未通过的条目计入质量日志。

## 10.2 禁止行为清单

| 禁止 | 理由 |
| --- | --- |
| 推测学生「本想表达什么」并据此扣分 | 评分依据只能是实际书写内容 |
| 因字迹潦草直接降档 | 只能按可辨识内容评，辨识不清处标 `待确认` |
| 输出无原文支撑的定性判断 | 违反证据可追溯底线 |
| 在低置信文本上生成拼写/词形类结论 | 幻觉高发区 |
| 编造或补全学生原文（如自动加冠词后当作原文引用） | 引用必须是原始书写 |
| 输出精确到小数的提分预测 | 主观题伪精度 |
| 生成「多加练习」类空泛建议 | 无行动价值 |
| 跨学生贬损性比较 | 教育伦理与报告可接受度 |
| 把待验证的教学假设写成既定结论 | 例如「词数超标必然导致低分」须以本班数据呈现，而非断言 |

## 10.3 一致性校准（M2 开放门槛）

| 指标 | 建议门槛（初始值，需业务校准） |
| --- | --- |
| AI 与教师分档次一致率 | ≥ 80% |
| \|AI 分 − 教师分\| ≤ 1 分占比 | ≥ 75% |
| 分差 MAE | ≤ 1.0 分 |
| 分差 > 3 分的卷子占比 | ≤ 2%，且全部进人工队列 |
| 重跑稳定性（同卷两次独立运行的档次一致率） | ≥ 95% |

未达标 → 不开放 M2 自动给分，仅保留 M1 辅评模式。校准集须覆盖各档次（尤其一档与五档的边界卷），不能只用中段卷验证。

## 10.4 双重评阅抽样

- 每批次抽样 ≥ 20% 做二次独立评分/诊断，比对标签命中一致性与档次一致性；
- 不一致卷自动进人工队列；
- 一致率作为该批次报告的质量指标，展示在报告附录中（让教师知道这批结果的可信度）。

## 10.5 低置信兜底文案

统一措辞，不猜测、不静默跳过：

- 「该处字迹辨识不清，未计入本次统计，请教师核对原卷。」
- 「本页识别置信度偏低，已转人工批改，未纳入班级汇总。」
- 「题目要求未录入，词数达标与要点覆盖无法判定，相关维度显示『暂无数据』。」

# 十二、展示精度与格式规范

- **分数**：整数或 0.5 分，与教师批分粒度一致；不显示无意义的 `.00`；
- **维度得分率、汇总掌握率**：完整精度计算（≥6 位小数），展示四舍五入保留两位小数；小数点后两位均为 0 时只显示整数（沿用现有规则）；
- **占比**：保留一位小数；展示值四舍五入导致总和不等于 100% 时提示「展示值已四舍五入」，**不调整实际值补尾差**；
- **人数**：整数，按人去重；
- **符号语义固定**（对齐样本，导出时保持一致）：`●` 事实陈述与共性优点、`▲` 问题条目、`★` 建议条目；
- **排序**：逐人点评默认按姓名拼音排序（样本口径），可切换按分数降序/学号；共性问题默认按严重度排序，可切换按覆盖人数；
- **导出排版**：Word/PDF 沿用样本结构（评分标准表 + 分数分布表 + 分级符号列表），保证教师拿到手即可直接用于教研与讲评。

# 十三、异常与边界场景

| # | 场景 | 处理 |
| --- | --- | --- |
| 1 | 空白卷 / 未作答 | 0 分，一档，不进共性问题统计，单列「未作答名单」 |
| 2 | 缺考 / 作弊 / 排除名单 | 不计入任何班级聚合，报告附录说明排除人数与原因 |
| 3 | OCR 整页失败 | 转人工，不计入聚合，报告头显示待人工份数 |
| 4 | 班级有效卷 < 5 | **不生成共性问题与共性问题排序**（样本不足），只做分数分布 + 逐人点评，并提示「有效样本不足，班级共性分析不可用」 |
| 5 | 图像缺页 / 只有部分答题区 | 按可识别部分评，缺失部分标「疑似未拍摄完整」，提示教师核对，不猜测内容 |
| 6 | 答题区外有内容 | 出界内容不计入有效词数与评分依据，但记 `ERR-PAP-03` 并说明高考后果 |
| 7 | 题目要求未录入 | 词数达标、要点覆盖、题眼词均不可判，相关维度与标签显示「暂无数据」，**不得按经验猜测要点** |
| 8 | 教师分与 AI 分差 > 3 分（M2） | 强制进复核队列，禁用批量确认 |
| 9 | 教师分超出满分或为负 | 阻断报告生成，提示数据异常 |
| 10 | 同分不同档争议 | 一律以教师分为准，AI 不改教师分 |
| 11 | 多题型混合场次 | 按题型分组统计，分别出报告，不合并 |
| 12 | 重跑已锁定 / 已发布报告 | 不覆盖，生成新版本，旧版本保留可查 |
| 13 | 某标签覆盖人数为 0 | 不在报告中出现，不显示「0 人」占位 |
| 14 | 全部卷子均在同一档次 | 分数分布正常展示，档次迁移与临界名单显示相应空态 |
| 15 | 学生姓名重复 | 以学号为主键，报告中姓名后附学号末位区分 |
| 16 | 有效集权重之和为 0（跨场次汇总） | 显示 `--` 并提示调整权重，不做除零计算 |

# 十四、权限与隐私

- **可见范围**：任课教师（本班全部）；备课组长/教研（跨班对比，可按配置对学生姓名脱敏）；学生本人仅见自己的逐人点评与班级共性部分（不见他人分数与名单）；
- **好句池署名**：默认展示学生姓名（样本口径），提供关闭开关，关闭后以「某同学」代替；
- **临界/辅导名单**：属敏感分层信息，仅教师可见，**不进入学生端与家长端**；
- **原卷图像**：留存期限、下载与打印权限受控；导出文件带班级标识与生成时间；
- **数据边界**：学生原卷图像、姓名、作文原文不传给学生与家长范围之外的第三方服务；若智批依赖外部模型服务，须在学校已授权且向教师明示的前提下进行，并提供本地化/脱敏（以匿名 ID 替换姓名）选项；
- **留存**：复核日志与校准样本保留原始判定，用于质量追溯。

| AC-01 | 上传 52 份应用文答题卡 + 教师分，运行 M1 | 52 份均产出结构化结果，或在附录中如实列出转人工份数与原因 |

| AC-03 | 低置信处理 | 词置信度低于阈值的词不出现在任何拼写类错误条与高频错词榜中 |
| AC-04 | 分数分布 | 分数段人数、档次占比、平均分、最高/最低（含姓名）与教师批分完全一致 |
| AC-05 | 共性问题准入 | 覆盖人数 < max(2, 班级×5%) 的标签不出现在班级共性问题中，仅出现在个人报告 |
| AC-06 | 共性问题排序 | 排序结果符合 7.5 公式与并列裁决规则；同输入重跑排序完全一致 |
| AC-07 | 同族合并 | 拼写类四个子标签在班级层合并为一条，可展开查看子类明细 |
| AC-08 | 题眼词 | 题眼词错误在个人点评中置顶，在高频错词榜中高亮置顶 |
| AC-09 | 高频错词榜 | 自动生成，含 错误写法/正确写法/人数/次数/是否题眼词/关联标签，人数按人去重；可导出默写表 |
| AC-10 | 班级好句池 | 全部条目来自 `HLT-*` 实例且引文校验通过，含出处与迁移建议；姓名展示开关生效 |
| AC-11 | 逐人点评结构 | 每人含 分数/档次/卷面总分/词数、总体评价 80-140 字、主要问题 3-6 条（原文→说明→订正）、修改建议 3-4 条（含具体训练动作）；默认按姓名拼音排序 |
| AC-12 | 空泛建议拦截 | 建议文案不含「多加练习」「注意语法」等无动作词，抽检不合格率为 0 |
| AC-13 | 提分空间提示 | 输出为绑定具体条目的定性档位表达，不出现精确小数预测 |
| AC-14 | 分层名单 | 冲档临界生名单非空时须每人生成可跨档的具体清除项；名单仅教师可见 |
| AC-15 | 复核锁定 | 已确认卷在重跑后内容不变；重跑生成新版本且旧版本可查 |
| AC-16 | 批量确认限制 | 存在分差 > 3 分或 S3 争议项的卷子不出现在批量确认可选集中 |
| AC-17 | 小样本 | 有效卷 < 5 时不生成共性问题，并显示样本不足提示 |
| AC-18 | 题目要求缺失 | 词数达标、要点覆盖、题眼词相关结论显示「暂无数据」，不出现猜测性判定 |
| AC-19 | 跨场次汇总 | 沿用 H=30 天时间衰减；未考查维度的场次不进有效集且不记 0；有效集权重和为 0 时显示 `--` |
| AC-20 | 未确认分不入汇总 | M2 下未经教师确认的 AI 建议分不出现在任何跨场次趋势与班级汇总中 |
| AC-21 | 展示精度 | 得分率两位小数、末两位为 0 只显示整数；占比一位小数并提示四舍五入；不调整实际值补尾差 |
| AC-22 | 导出 | Word/PDF 排版结构与参考样本一致（评分标准表、分数分布表、`●/▲/★` 符号体系） |
| AC-23 | M2 校准门槛 | 档次一致率 ≥80%、\|分差\|≤1 占比 ≥75%、MAE ≤1.0、重跑稳定率 ≥95%，全部达标才开放自动给分 |
| AC-24 | 双重评阅抽样 | 每批次抽样 ≥20%，一致率指标写入报告附录 |
| AC-25 | 隐私 | 学生端不见他人分数与名单；临界/辅导名单不外露；好句池署名开关生效 |
