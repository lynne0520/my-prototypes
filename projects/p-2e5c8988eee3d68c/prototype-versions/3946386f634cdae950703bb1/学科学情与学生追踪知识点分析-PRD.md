### 0.2 术语

| 术语 | 定义 |
| --- | --- |
| 考核项 | 当前维度下树的非根节点统称：知识点维度=知识点，能力维度=能力 |
| 掌握度 / 得分率 | 原型中节点 mastery 字段，0~100，百分制 |

## XK-02 顶部筛选栏（filter-bar）

**功能描述**

筛选条件对学科学情视图三个主页签全局生效。

1. **学年下拉** `#yearAuthSelect`：**默认当前学年**（演示基线 2025-2026 学年），下拉只列教师带班/任教权限内的学年并标注该学年所带年级班级（2025-2026学年 · 现带高二1班 / 2024-2025学年 · 曾带高三1班 / 2023-2024学年 · 曾带高一2班）；切换后**按该学年的教务权限查询**：年级-班级级联重建为该年所带年级/班级（`TEACHER_AUTH_YEARS`）并重算周期模块，支持教师查询历史带班学生的作业/考试情况。
2. **年级-班级级联** `#gradeClassCascade`：**默认取教务权限范围内的第一个年级 + 该年级的第一个班级**（演示为高二1班），触发钮显示当前值，面板左列年级（高一/高二/高三）、右列动态生成班级列表。
   - 联动规则：选中**具体班级**时摘要卡区显示「班级平均得分率」卡；选中**全部班级**时无单一班级口径，该卡隐藏（`syncSummaryCards`）。
3. **学科下拉**：可选范围为**教师教务权限内的学科**，**默认选中该范围的第一个学科**；演示原型为方便查看空态而放宽为六科全列（语文 / **数学（默认）** / 英语 / 物理 / 化学 / 生物），权限内实际只有数学，切到其他学科进入「该学科知识体系未覆盖」空态。
4. **时间筛选** `#timeSegment` 四档：学年 / **月（默认）** / 周 / 自定义，档位切换对应日期控件显隐：
   - 学年 → 学年下拉；月 → `type=month`（默认 2026-09）；周 → `type=week`（默认 2026-W38）+ 自然周区间 hint（ISO 周一算法）；自定义 → 起止两个 `type=date`（`#customDateStart/#customDateEnd`）。
   - **跨学年支持**：月/周/自定义控件 `min/max` = 教权数据范围并集（2023-09-01 ~ 2026-10-12），教师可跨学年查询教权范围内学生历史作业、考试。
   - **自定义环比规则**：环比窗口 = **起始日期前的等长前置窗口**（与自定义区间同天数，[起始−len天, 起始−1天]）；窗口内有任务则环比 = 本周期 − 窗口内任务均值；**窗口内无任务 = 无环比数据 → 全链路隐藏环比**（KPI delta、摘要徽章、结论文案均不显示，不展示误导性 0%）。档位切换 / 日期变更触发 `refreshDashboard()` 重算。
5. **学情来源** `#filterCount`「已选：24 份」：点击打开学情来源弹窗（见 XK-12.3）。
6. **设置掌握程度** `#btnMasterySetup`：打开掌握程度设置弹窗（见 XK-12.1），对整体学科学情与学生追踪-知识点分析同步生效（全校共用档位配置）。**权限分级**：学科组长及以上可写（入口显示齿轮 + 「设置掌握程度」+ 角色标签），学科教师 / 班主任等只读（锁标 + 「查看掌握程度」+ 「角色·只读」标签，仅能查看设置后的结果）。

**已知限制**：学科切换目前不重算演示数据；时间档位与日期变更已重算环比链路（`currentPrevBase()`），周期任务清单仍为演示固定数据，真实数据接入后应全局重算。

### XK-04.2 周期结论（periodInsightList）

规则引擎 `INSIGHT_RULES`（声明式规则表：**when(s) 决定条目是否出现 / cls(s) 定语义色 / build(s) 生成文案**），`renderPeriodInsights()` 按 when 过滤后逐条渲染为 `insight-item`；数值全部来自 `calcPeriodStats()` 实时计算，非固定文案。底部口径行：统计区间近一月 · 纳入任务数（作业/考试分列）· 对比基准上一周期 69.8%。

**统计口径（calcPeriodStats）**

- 班级平均得分率 pRate = 周期内各次任务 classRate 的**算术平均**（按任务次数平均，非按分值加权）；年级均 gRate 同口径。
- 环比 dRate = pRate − 环比基准（`currentPrevBase()`：学年/月/周档 = `prevPeriodRate` 演示值 69.8%；自定义档 = 起始日期前等长前置窗口内任务 classRate 均值，窗口无任务返回 null）；**dRate 为 null 时全链路隐藏环比**（KPI delta / 摘要徽章 / 结论文案），趋势判定回退周期内首尾 prog。首末差 prog = 末次 − 首次。
- 稳定度 = 100 − 各次得分率**总体标准差** sd（÷n）；极差 = 最高 − 最低。
- 年级对比胜场 winCnt：classRate **严格大于** gradeRate 的任务数；考试胜场在 type=exam 子集内同口径统计。
- 顽固薄弱两套口径并存：本模块（周期概览）用 `periodLeafStubs()`——heatData 两维度行按**全维度末级节点名**过滤后统计，失分率 ≥40% 的已考查场次 ≥3 次入选，按场均失分率降序，**不随维度切换**；「知识点分析」页签模块（摘要卡5/图谱诊断/教学建议）用 `calcPeriodStats().stubSorted`——`heatData[当前维度]` 混合层级逐行统计，随维度切换。

**规则明细**

| id | 触发 when | 语义色 cls | 文案要点 build |
| --- | --- | --- | --- |
| trend 趋势 | 必出 | 恒蓝 | pRate%、环比 ±变动值（个百分点）、首末 ±变化值（个百分点）（得分率升绿/降红）+ 趋势判定；**环比缺失时文案改「无环比数据」并按周期内首尾判定趋势** |
| stable 稳定度 | 必出 | sd≥5 红 / 3≤sd<5 琥珀 / sd<3 绿 | 稳定度（100−sd）、sd、最高/最低、极差；后缀分档：波动偏大，提升尚未稳定 / 波动中等，需关注状态起伏 / 表现稳定 |
| grade 年级对比 | 必出 | 胜率 ≥60% 绿 / <40% 红 / 其余琥珀 | N 次任务 X 次高于年级均；落后清单（classRate ≤ 年级）逐条列「任务名」（班级% vs 年级%）；考试 examWin/examCnt 领先 |
| stub 顽固薄弱 | 全维度末级顽固薄弱非空 | 恒红 | 命中数 + 名单（末级知识点，含能力维度）+ 判定口径（≥3 次失分率 ≥40%）；定性「属结构性问题，建议安排专项复习而非重复讲题」 |
| advice 行动建议 | 全维度末级顽固薄弱非空 | 恒琥珀 | 针对均失分率最高项（periodLeafStubs()[0]）优先安排专项课时；下阶段验证目标：失分率降至 40% 以下 |

**趋势判定档位（按 dRate）**：≥+3 个百分点 显著回升；[+1,+3) 缓慢回升；(−1,+1) 基本持平；(−3,−1] 缓慢下滑；≤−3 明显下滑。

### XK-06.4 热力演进图功能与计算规则

**定位**：以「考核项 × 任务」矩阵呈现本期各次任务上班级在每个考核项的失分率变化，用来识别结构性薄弱（顽固项）及其走势。它是知识点分析四视图之一，也是摘要卡5、周期概览「顽固薄弱知识点」卡的下钻落点。

**数据构成**：

- 知识点、能力两个维度各有一组行；每行对应一个考核项，每列对应本期的一次任务（时间正序，共 6 次），格内数值是该考核项在该次任务的**失分率**（0~100）；
- **未考查与零失分严格区分**：未考查的场次留空，格内显示「·」，悬停提示「该场未考查」，不参与任何平均与顽固计数；零失分显示 0；
- 失分率与得分率互补：得分率 = 100 − 失分率。

**计算规则**：

1. **行过滤**：目录里隐藏的一级模块，其下考核项整行不展示；知识点按所属模块判断，能力按所属模块判断，索引里查不到的考核项默认保留。
2. **累计列**：该行所有已考查场次失分率的算术平均取整；一场都没考查的记 0。
3. **顽固判定**：该行失分率 ≥40% 的场次达到 3 次及以上，行头打「顽固」标记，与摘要卡5、周期概览的顽固薄弱口径同源。
4. **行排序**：按累计失分率降序，最严重的排最上面。
5. **单元格着色（五档）**：低于 20% 轻度、20%~40% 中度、40%~60% 较重、60%~75% 严重、75% 及以上极重；底部图例与档位一一对应，累计列按同一套色阶着色。
6. **列头**：任务名 + 日期（月-日）+ 类型（考试 / 作业），顺序与本期任务列表一致；单元格悬停显示任务全称、考核项、失分率。
7. **底部结论**：动态生成，没有固定文案，规则见本节末表格。
8. **维度联动**：矩阵随知识点 / 能力维度的切换重新取数；周期概览「顽固薄弱知识点」卡与摘要卡5 按两个维度的全部末级节点统一统计，不随维度切换（见 XK-04.1）。
9. **教师友好增强**：
   - 表格上方标注「格内数值为班级失分率（%），颜色越红丢分越重，得分率 = 100 − 失分率」，避免把失分率当得分率读；
   - 「热力演进」页签旁有「?」问号，悬停显示口径说明；
   - 行尾新增「判定」列，依次判定：顽固（≥3 次重度失分）/ 反复（2 次）/ 偶发（1 次）/ 恶化 / 回升 / 稳定；趋势用有效场次按时间前后两半的均值差判断，相差 5 个百分点以内算稳定；每种判定都带悬停说明；
   - 整行悬停给出完整叙事：考查次数 + 累计失分率 + 最近一次 + 处置建议（顽固 → 安排专项课时；反复 → 盯紧后续；偶发 → 暂不专项；恶化 → 尽快介入；回升 → 干预起效；稳定 → 保持节奏）。
10. **下钻定位**：周期概览「顽固薄弱知识点」卡与摘要卡5 点击后，跳到热力演进并高亮当前维度全部顽固行、滚动到可见位置；诊断区的顽固条目点击时，点名高亮对应行。点名项在当前维度找不到时，退化为高亮全部顽固行；仍然没有就高亮置顶行。高亮为脉冲闪烁 3 次后自动消失，不长期覆盖单元格的档位颜色；任何情况下都不删除其他行（保住横向对比）。

**底部结论生成规则**：按当次数据实时生成，没有固定文案。

| 取数项 | 生成规则 | 说明 |
| --- | --- | --- |
| 统计行数 | 当前维度矩阵剔除目录已隐藏模块后的可见行数；隐藏模块后「共 N 个」同步变小 | 与表格行数一致 |

| --- | --- | --- |
| 无可展示行 | 目录一级模块全部关闭 | 当前目录下没有可展示的知识点（或能力），请恢复左侧已关闭的模块后再查看。 |

### XK-06.5 周期知识点得分率计算规则（含时间衰减）

**定义**：周期知识点得分率 = 某个末级知识点（或能力点）在统计周期内各次被考查任务上得分率的加权聚合值。树节点掌握度、表格「班级得分率」、目录得分率徽章、诊断计数与达标率判定都取自这个数。

**当前原型**：矩阵失分率与节点掌握度都是固定的演示值（相当于下面规则的预计算结果），只作展示；接入真实数据后按以下规则实时计算。

**计算步骤**：

1. **单场得分率**：某次任务上，该知识点取本次任务里考到该点的题目的平均得分率，等于 100 减失分率；该场没考到这个点，整场不参与聚合。
2. **时间衰减权重**：以周期结束日为基准，每次任务按距今的天数打折——每过 30 天（半衰期，后台常量，前端不提供配置入口）权重减半，也就是以 0.5 的「间隔天数 ÷ 30」次方作为该场权重。越近的任务权重越接近 1，周期得分率因此反映近期水平，而不是全期简单平均。
3. **加权聚合**：周期得分率 = 各场「权重 × 得分率」之和 ÷ 各场权重之和，四舍五入保留 1 位小数。
4. **边界情况**：只被考查 1 场时直接取该场得分率（权重归一后退化）；考查 0 场时标记「周期内未覆盖」，**不计入知识点达标率的分母**（与 XK-04.1「已覆盖末级节点」口径一致）。
5. **简单均值对照**：同时保留不做衰减的算术平均作参照，热力演进「累计」列用的就是这一口径。衰减值高于简单均值，说明近期表现好于全期平均，处于回升通道；反之则在走弱。
6. **掌握度映射**：周期得分率经「设置掌握程度」的档位配置映射为达标 / 薄弱 / 未掌握等状态；未掌握阈值取最低档上界，随档位切换联动（XK-12.1）。
7. **年级对比**：年级同知识点得分率按同一口径聚合，表格与详情里的「与年级差」= 班级周期得分率 − 年级周期得分率。

## XK-08 错因结构分析（causeSection）

- 堆叠柱状图（causeStackChart）：各次任务失分归因占比（CAUSE_DEFS × causeMatrix），图例行可点击显隐系列。
- 限制提示：**仅智批作业支持错因分析**（橙色文案）。

**关键发现规则表（causeFindingList，`renderCauseFindings`）**

判定算法（与维度无关，初始化渲染一次，不随知识点/能力切换重算）：

1. 取错因矩阵首行（最早一次任务）与末行（最近一次任务），逐错因计算占比差 Δ = 末次 − 首次（保留 1 位小数）。
2. **|Δ| ≥ 3 个百分点 → 显著迁移**：按 |Δ| 降序逐条展示；占比上升（Δ>0）红色条目、下降（Δ<0）绿色条目（错因场景：上升=恶化、下降=改善）。
3. **|Δ| < 3 个百分点 → 归入「基本稳定」汇总条**（蓝色）：列出全部稳定错因名，注明占比变化均在 ±3 个百分点 以内、错因结构未发生明显迁移。

单条结构：`错因名：首次% → 末次%（±Δ 个百分点）` + 干预建议（`causeAdviceOf(def, up)`）。

干预建议文案（CAUSE_DEFS 预置，按上升/下降各一套）：

| 错因 | 上升 up（恶化） | 下降 down（改善） |
| --- | --- | --- |
| 计算失误 | 占比持续上升，建议用「限时 10 分钟 3 题」高频短训替代整卷练习 | 计算准确率改善，继续保持解题步骤规范化要求 |
| 概念混淆 | 相近概念辨析不清，建议采用成对对比式讲解 | 概念辨析讲评见效，可维持当前教学节奏 |
| 审题不清 | 漏读条件增多，建议强化「圈画关键词」审题训练 | 审题习惯培养见效，错误占比稳步下降 |
| 方法选择 | 题型与方法匹配困难，建议按题型归纳解题决策路径 | 方法选择趋于合理，可进入综合题型训练 |
| 书写规范 | 步骤书写失分增加，建议展示标准答卷范例 | 书写规范保持良好，基本稳定 |
| 未作答 | 空白题增多，集中在卷末压轴题，属答题时间分配问题 | 作答完成度改善，继续保持 |

兜底规则：新增错因未预置 advice 时使用通用模板——上升「占比持续上升，建议针对该错因安排专项干预，并在下周期复测验证」；下降「占比稳步下降，保持当前教学节奏并持续观察」。配色同理走 `causeColorOf` 色板循环兜底，不写死错因枚举。

#### XK-12.5.5 前序断层归因（kgTraceRoot + kgCollectFaults + renderKgFaultList）

- **候选条件**：level ≥2、掌握度 <60%、证据状态为 period/history（暂无证据与未学节点不进候选——静态掌握率不代表周期表现）；按掌握度升序取前 5。
- **回溯算法**：从目标沿 `kpRelations.prerequisite` 链取**最弱有证据前置**逐级回溯，已达标（≥70%）即终止；无证据前置记录为**证据断点**（未知 ≠ 薄弱），不参与根因比较；防环上限 8 层。
- **结果四态**：rootCause（链上存在 <70% 根因 → 「根因在前序：X」+ 前置补练徽章）/ 断点（「根因未知 · 前置暂无证据」+ 前置诊断徽章）/ 前置已达标（「本点自身问题」+ 同点巩固徽章）/ **关系未建**（目标在 `kpRelations` 无前置条目 → 「前置关系未建 · 无法归因」+ 待标注徽章——冷启动不归因造假，题库补标后自动升级）。
- **条目渲染**：链路从左到右「根因 → 表现」，节点按根因红 / 薄弱黄 / 达标绿着色并标掌握度，断点以虚样式附于链尾；处置文案四态对应（先补根因再讲当前 / 先诊断再归因，不得直接判定为基础不牢 / 可直接专项 / 直接专项巩固且待题库补标）。
- **计数**：「有根因数/断层总数」（如 5/5，noRel 条目不计入分子）；条目点击进入关联诊断抽屉。

### XK-12.6 题库知识图谱组件引用与接口需求（给题库团队）

**背景与定位**：本页「关联图谱」（XK-06.2）当前为页面内 ECharts 力导向/放射自研实现；题库团队已有独立知识图谱可视化组件（tupu 原型：`F:\07 project\tupu\`，d3 + build_graph.py 按 data_cache 生成）。为避免双图谱并行维护、样式互相污染，规划**一期复用 + 二期替换内核**的集成路径，对题库组件提出以下 Headless 化接口需求。

**接口需求清单（6 类）**：

| # | 需求类别 | 具体要求 | 用途 |
| --- | --- | --- | --- |
| 1 | 布局配置 | 初始化选项：`hideSidebar`（组件自带侧栏默认关）/ `hideToolbar` / `hideHeader` / `theme`（light/dark） | 嵌入学情页时隐藏组件冗余 UI，仅保留画布 |
| 2 | 主题契约 | 全部配色走 CSS 变量（如 `--kg-node-*`、`--kg-edge-*`），不硬编码色值；提供变量清单文档 | 学情页注入模块配色（KG_MODULE_COLORS）与深浅色主题，避免样式冲突 |
| 3 | 数据透传 | `data`（节点 + 关系边 JSON Schema）+ `styleOf(node/edge)` 回调（宿主自定义颜色、大小、透明度、标签） | 学情页注入掌握度着色、断层红边、四态灰色编码等页面语义 |
| 4 | 命令 API | `setModules(开关字典)` / `setDepth(n)` / `setLayout(force/radial)` / `setHighlight(name)` / `fit()` | 目录开关、深度切换、布局切换、节点选中高亮、适应画布——与现有工具栏一一对应 |
| 5 | 事件 | `onNodeClick(name)` / `onEdgeClick(rel)` / `onReady()` | 节点点击打开右侧详情面板（kgRenderDetail）、关系边提示、初始化后默认选中 |
| 6 | 交付形式 | npm 包（优先）或 UMD 单文件 + 语义化版本（semver）+ CHANGELOG；打包不含 d3/ECharts 运行时（peerDependency 或 externals） | 版本可锁、升级可追溯、避免与宿主页面图表库版本冲突 |

**降级策略**：

- **一期（当前）**：本页保留自研 ECharts 图谱，题库组件仅作「全屏查看完整知识图谱」的外链入口（新标签打开）——零集成风险；
- **二期**：题库组件按上述接口完成 Headless 化后，以嵌入模式替换本页图谱内核（工具栏/目录/详情面板为学情页自有 UI，仅画布来自题库组件）；接口未就绪前不阻塞学情页迭代。

**治理提示（数据口径红线）**：

- tupu 原型的「前置/后续」关系由 build_graph.py 按目录相邻章节自动生成，**非教研确认的真实依赖关系**；接入前须由教研侧逐条确认，否则断层诊断（红边）会产生假阳性；
- 本页知识体系（kpTree 111 节点）与题库知识体系须先建立节点 ID 映射表（同名 ≠ 同 ID）；
- 「无作答证据 = 未知 ≠ 未掌握」红线同样适用于图谱展示：无证据节点不得因演示掌握度着红色。

## ST-13 个人周期学情概览（stKpPeriodSection）

位置：时间筛选条之后、维度工具之前；筛选条以下分两大模块——**01 个人周期学情概览**（本模块）与 **02 知识点维度分析**（维度工具至教学建议全部子模块）。

数据源 `stKpPeriodStats()`：基于 `stKpTaskList(该生)`（个人 mine / 班级 cls 得分率，按日期升序）；个人无上周期数据 → 无环比，趋势判定回退为周期内首末进步（与班级「环比缺失回退首尾」同逻辑）。

| KPI 卡（4 张） | 口径 |
| --- | --- |
| 个人平均得分率 | 各次任务个人得分率算术平均；徽章 = 与班级基准差 正负百分点 |
| 稳定度 | 100 − 个人得分率标准差；副行：标准差 / 最高 / 最低 |
| 个人顽固薄弱 | 同诊断-顽固薄弱（stKpStubList：≥3 次失分率 ≥40%）；非数学学科显示「演示知识体系未覆盖」 |
| 高于班级场次 | mine > cls 场次 / 周期任务总数；副行：落后场次 + 作业/考试拆分 |

**趋势与状态结论化**：「周期进步」「状态判定」两张 KPI 卡已并入周期结论——trend 条目承载末次−首次进步（正负百分点）与趋势档位，status 条目承载 V2.0 六状态（附有效场次 / 平均得分率），不再并列设卡。

**该生周期得分趋势**（`stKpRenderPeriodTrend`）：x 轴 = 已勾选任务（stKpTaskList，与 KPI/结论同口径，日期升序），折线 = 个人得分率（蓝实线，考试▲/作业●）+ 班级得分率（灰虚线）；空任务显示空态（原在学情来源弹窗内，见 ST-14 变更记录）。

**学情状态通俗解读条**（`#stKpPeriodStatusNote`）：状态胶囊 + 大白话（与学情页徽章同源 `ST_STATUS_BY_ID`）；「断崖下跌 / 持续低位」红色提醒态，其余蓝色；无判定时显示「当前筛选范围内暂无该生状态判定」。六状态大白话：待观察=场次不足，先按最近一次看 / 断崖下跌=最近明显掉队，尽快干预 / 持续低位=一直吃力，先补基础降难度 / 低位回升=开始好转，保持节奏 / 明显进步=进步确认，可提高挑战度 / 平稳=稳定缺变化，从薄弱点突破。

**个人周期结论**：规则表 `PERSON_INSIGHT_RULES`（when/cls/build，与班级 INSIGHT_RULES 同构）：trend 趋势 / stable 稳定度 / vsClass 班级对比（落后清单逐条列「任务名」（个人% vs 班级%））/ stub 顽固薄弱 / status 状态建议；空任务时显示单条空态。

## PRD 查看器

> 查看器顶部支持**关键词搜索**：输入关键词（如「环比」「顽固」「需关注」）实时搜索全部章节标题与正文（含本地修改后的内容），结果下拉按标题命中优先排序并高亮命中词，点击结果定位到对应章节（滚动 + 闪烁高亮）；支持 Enter 直达首条、Esc 先收起结果再清空输入、点搜索区外收起下拉。
>
> 查看器支持手动编辑：点击章节标题右侧铅笔图标进入编辑态（HTML 源码编辑），保存后写入本浏览器 localStorage（key：`xkStPrdOverrides_v1`，仅存与默认不同的章节），章节标题标注「已修改」、目录项带橙色圆点；支持恢复默认；头部提供导出/导入 JSON（合并后的完整 23 节 PRD，用于备份与跨浏览器迁移）。编辑态按 Esc 优先取消编辑；有未保存修改时离开（切换编辑/取消/导入）有确认拦截。
