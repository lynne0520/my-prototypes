## 2. 产品背景与目标

### 2.1 背景

单次作业、考试只能说明某一时点的表现。教师需要把一段时间内的有效任务汇总，回答以下问题：

1. 本班在本学科的整体表现是在提升、下滑，还是持续波动？
2. 哪些知识点、能力尚未掌握，哪些问题在多次任务中反复出现？
3. 当前薄弱点是否与前置知识、概念混淆、题型易错步骤有关？
4. 应优先讲评哪些题目，并如何组织后续重练？

### 2.2 产品目标

- 建立“确定范围 → 查看周期趋势 → 定位考核项 → 分析关联原因 → 查看证据题目”的教师分析路径。
- 将知识点与能力纳入同一套分析框架，同时保留二者的差异化展示。
- 支持班级与年级对比、周期对比，避免只展示孤立得分率。
- 通过任务清单、明细表、热力矩阵支撑结论溯源。
- 支持导出数据及错题处理入口，便于教师开展讲评与复习。

### 2.3 用户与权限

| 用户 | 核心诉求 | 本期边界 |
| --- | --- | --- |
| 学科任课教师 | 查看授权班级的学科学情、定位薄弱项、选择讲评内容 | 核心使用者 |
| 有跨班权限的教师或教研人员 | 在授权范围内查看多个班级或年级聚合结果 | 权限与“全部班级”口径待确认 |
| 学生、家长 | 查看个人诊断或成长情况 | 不属于本页面需求 |
| 学校管理员 | 配置学校组织、学年、任课关系等 | 由平台基础能力提供，本页不建设管理后台 |

【补充】所有查询、导出和错题写入都必须进行服务端权限校验，不能仅依靠前端隐藏选项。

### 2.4 典型使用场景

| 场景 | 操作路径 | 预期结果 |
| --- | --- | --- |
| 月度复盘 | 选择班级、学科、月份 → 确认学情来源 → 查看概览与趋势 | 了解周期整体表现及重点关注项 |
| 薄弱项备课 | 点击未掌握数量 → 查看分层表格 → 打开具体考核项 | 找到低分项、对应任务与证据题目 |
| 顽固问题排查 | 点击顽固薄弱项 → 热力演进 → 图谱诊断 | 识别重复失分、可能的前置短板与混淆点 |
| 讲评组织 | 查看共性错题 → 按得分率或知识点筛选 → 添加重练 / 类题 | 将诊断结果转为讲评与练习素材 |
| 前序诊断与加练规划 | 知识图谱诊断 → 前序断层 / 证据总览 → 关联诊断抽屉 → 生成分目的加练建议 | 区分前置诊断 / 前置补练 / 概念辨析 / 同点巩固 / 后续应用与复测，导出建议清单 |
| 数据留档 | 选择分析维度、层级或详情任务类型 → 导出 | 获得与当前统计口径一致的 CSV |

## 5. 全局筛选与学情来源

### 5.1 F01：筛选项

| 字段 | 控件与选项 | 原型默认值 | 目标行为 |
| --- | --- | --- | --- |
| 学年 | 单选下拉 | 2025-2026 学年；另有 2024-2025 学年 | 【补充】从学校学年配置获取，默认当前有效学年 |
| 年级 / 班级 | 两列级联菜单 | 高二 1 班 | 先浏览年级，再选择班级，选择后关闭；仅提供授权范围 |
| 年级范围 | 高一、高二、高三 | 高二 | 原型高中样例，不将年级列表写死为系统能力边界 |
| 班级范围 | 各年级的具体班级、“全部班级” | 1 班 | 【待确认】“全部班级”的权限及合并统计方式 |
| 学科 | 语文、数学、英语、物理、化学、生物 | 数学 | 显示纯学科名称；正式数据随选择切换 |
| 时间粒度 | 学年、月、周、自定义 | 月 | 同一时间只能选中一种粒度 |
| 学情来源数量 | “已选：N 份” | 24 份 | 点击打开来源弹窗；N 为已确认选择的有效任务数 |

原型高一、高二分别演示“全部班级、1班、2班”，高三演示“全部班级、1班”；这些数量不作为正式限制。

### 5.2 时间范围规则

| 粒度 | 输入方式 | 范围定义 |
| --- | --- | --- |
| 学年 | 学年下拉 | 【补充】读取学校配置的学年起止日期，不自行假定固定日期 |
| 月 | 月份选择器 | 自然月首日到末日 |
| 周 | ISO 周选择器 + 日期提示 | 周一到周日，提示实际起止日期；跨年周使用 ISO 周年计算 |
| 自定义 | 开始日期、结束日期 | 包含开始日与结束日 |

【补充】日期以学校业务时区解释，查询可采用“开始日零点包含、结束日次日零点不包含”，保证结束日任务不遗漏。任务归属时间建议使用任务结束时间，与辅助汇总方案保持一致。

校验与联动：

- 自定义日期必须完整，开始日期不得晚于结束日期。
- 左侧学年与时间档位中的学年必须同步，不允许形成两个矛盾的学年条件。
- 月、周、自定义范围与所选学年冲突时给予明确提示，不静默改换学年或使用无关数据；跨学年查询是否放开为待确认项。
- 改变班级、学科、学年或有效日期后，重新获取可用任务，再刷新统计；未加载完成前不得显示“新筛选条件 + 旧结论”的混合状态。
- 【补充】首次进入使用当前有效学年、授权默认班级、默认学科及当月；原型中的固定年月不作为生产默认值。
- 【原型限制】目前时间档位主要控制日期控件显隐，班级切换主要更新显示值，尚未实现真实任务过滤与全页重算。

### 5.3 F02：学情来源弹窗

**布局与字段**

- 标题“学情来源”，右上角关闭。
- 左栏作业、右栏考试；各栏标题显示“已选数量 / 可选数量”。
- 每条任务展示复选框、名称、日期；长名称应能查看完整内容。
- 两栏分别支持全选 / 取消全选；【补充】部分选中时显示半选态。
- 各栏可独立滚动；无任务时分别显示“暂无作业”或“暂无考试”。

**来源有效性【补充，来源于辅助方案】**

- 纳入已发布完整学情且有分值的考试、作业；测评若属于现有任务类型，按平台分类映射后纳入。
- 学案、无分值题卡、临时成绩、未发布完整学情的任务不进入可选列表，也不参与统计。
- 不属于当前班级、学科、时间范围或权限范围的任务不得出现。
- 列表按结束时间从近到远排列；同一任务不得重复展示。

**确认 / 取消流程**

1. 打开弹窗时复制当前已确认的选择作为编辑草稿。
2. 勾选仅修改草稿；弹窗中计数实时变化。
3. 点击“确定”时校验至少选择 1 项，提交草稿并刷新任务集合与全页数据。
4. 点击“取消”或关闭按钮丢弃草稿，主页面计数和已确认选择均保持不变。
5. 无可用任务时允许关闭弹窗，主页面展示空状态；禁止提交空选择发起正常统计。
6. 【补充】全局筛选条件变化后默认全选新范围的有效任务；同范围内再次打开保留已确认选择。

【原型限制】原型勾选会直接修改内存数据，取消不回滚；确定只更新“已选数量”，不驱动统计；允许零选择。正式实现按上述目标行为补齐。

## 6. 核心数据与统计口径

### 6.1 统一统计上下文

【补充】每次结果必须对应同一组上下文：学校、学年、年级、班级范围、学科、起止日期、已选任务 ID、统计版本、考核维度、掌握程度方案；采用权重时还需包含权重配置版本。

- “已选 N 份”、周期任务数、任务清单、趋势图横轴、热力矩阵任务列必须来自同一已选任务集合。
- 树、表格、图谱节点、详情中的同一考核项使用统一 ID，不能仅按名称字符串匹配。
- 年级对比使用同一学科、同一任务及相同有效成绩规则；没有可比数据时显示“—”。
- 【待确认】选择“全部班级”时，是展示合并学生样本还是班级均值。建议合并有效学生样本并将“本班”改为“所选班级”，但不得未经确认直接按班级得分率平均。

### 6.2 有效成绩、缺失与零分

| 情形 | 处理要求 |
| --- | --- |
| 正常参加但某题未答、交白卷 | 相关题目计 0 分，分母保留；可计入“未作答”错因 |
| 缺考、作弊、明确排除的成绩 | 不进入有效成绩分子、分母 |
| 任务尚未批阅完成或成绩异常待核实 | 【补充】标记不可用或计算中，不直接当作 0 分 |
| 某任务未考查某考核项 | 该项该任务为 `null` / 未考查，不按 0 分处理 |
| 满分为 0、没有有效参考者 | 不产生得分率，展示“—”或“暂无数据” |
| 得分为 0 且存在有效满分 | 正常显示 0%，属于真实低分，不显示为无数据 |

辅助方案对“无有效成绩记 0”和“无有效成绩不统计”存在表述冲突。本 PRD 将正常未答与异常待核实分开；具体成绩状态映射由业务与数据负责人评审确认。

### 6.3 指标定义

| 指标 | 计算 / 判定方式 | 说明 |
| --- | --- | --- |
| 单题班级得分率 | 有效学生该题得分之和 ÷ 对应有效满分之和 × 100% | 不能用“答对人数比例”替代有部分分的得分率 |
| 单任务班级得分率 | 有效学生本任务得分之和 ÷ 有效满分之和 × 100% | 使用同一任务统计规则 |
| 周期平均得分率 | 周期内有效任务得分率的算术平均 | 【原型】按任务次数平均，不按满分、人数或时间加权 |
| 年级周期平均得分率 | 对应任务年级得分率的算术平均 | 对比任务集合必须一致；缺失时说明有效对比任务数 |
| 班级与年级差值 | 班级得分率 − 年级得分率 | 单位为百分点 `pp`，不是相对变化率 |
| 周期环比 | 当前周期平均得分率 − 上一周期平均得分率 | 上一周期定义见 6.4 |
| 首尾变化 | 最后一次任务得分率 − 第一次任务得分率 | 必须与环比区分 |
| 标准差 | `sqrt(Σ(r_i − mean(r))² / n)` | 【原型】使用总体标准差，单位与得分率数值一致 |
| 稳定度 | `100 − 标准差` | 【原型】自定义描述指标，不当作通用教育测量标准 |
| 考核项数量 | 当前维度已覆盖、非根节点的去重节点数 | 原型统计全部层级；不是仅统计一级或叶子节点 |
| 未掌握项数 | 掌握率低于最低档上界的考核项数 | 默认 `<60%` |
| 考核项达标率 | 掌握率 `≥80%` 的已覆盖项数 ÷ 已覆盖项总数 × 100% | 【原型】达标阈值固定 80%；不与“共性错题”阈值混用 |
| 顽固薄弱项 | 同一项在至少 3 次不同任务中失分率 `≥40%` | 不要求连续；未考查场次不算命中 |
| 提交率 | 已交人次 ÷ 应交人次 × 100% | 已交包含迟交，迟交是已交子集；按任务分别累计 |
| 考查频次 | 【补充建议】已选范围内实际考查该项的不同有效任务数 | 【待确认】是否采用题目出现次数；原型缺少真实值，回退显示 10 |
| 班级未掌握人数 | 【补充】该项有有效数据且个人掌握率低于阈值的去重学生数 | 不把无数据学生当作未掌握，需学生粒度计算能力 |
| 需关注学生 | 命中关注规则的去重学生数 | 【待确认】断崖下跌、持续低位、首次低分、答题异常的阈值与跟进来源 |

**父子层级与去重【补充】**

- 沿用辅助方案：题目挂接末级节点，父节点通过子树关联题目汇总；不得把各子节点得分率直接相加。
- 同一道题挂接多个知识点时，父节点汇总必须按题目或评分单元去重，不能重复累计满分。
- 同一题可同时进入知识点与能力分析，但不能将两套维度的题量相加作为总题量。
- “已覆盖”指范围内至少有一次有效考查；全周期未考查节点可保留为灰色结构节点，但不计入掌握分布与未掌握数量。

### 6.4 上一周期与结论生成

【补充建议，待业务确认】月对比上一自然月，周对比上一自然周，学年对比上一学年，自定义对比紧邻之前的等天数区间；保持班级、学科及成绩有效性规则一致。

- 上一周期无可比数据时，环比、基准线及对应判断显示“暂无对比数据”，不得回填演示基准。
- 自选任务集合可能与上一周期不同，应展示两期任务数，并提示比较不代表试卷难度已校准。
- 同一次任务的本班与年级得分率相等时表述为“持平”，不能写“落后”。
- 任务不足 2 次时只展示单次表现，不生成首尾趋势或“表现稳定”的结论；任务不足 3 次时提示顽固薄弱判定样本不足。

【原型】趋势标签按环比差值判定：

| 环比差值 | 标签 |
| --- | --- |
| `Δ ≥ 3pp` | 显著回升 |
| `1pp ≤ Δ < 3pp` | 缓慢回升 |
| `−1pp < Δ < 1pp` | 基本持平 |
| `−3pp < Δ ≤ −1pp` | 缓慢下滑 |
| `Δ ≤ −3pp` | 明显下滑 |

上述“显著”是产品规则标签，不表示进行了统计显著性检验。

【原型】波动说明：标准差 `<3` 为表现稳定，`3≤标准差<5` 为波动中等，`≥5` 为波动偏大。

### 6.5 展示精度

- 【原型基线】常规得分率及百分点差值主要保留 1 位小数；热力累计值、部分诊断比例显示整数。
- 【补充】计算使用原始精度，完成计算后再格式化，不使用已经四舍五入的展示值继续计算。
- 得分率使用 `%`，两个得分率相减使用 `pp`；数量显示整数并标明“个 / 道 / 人 / 人次 / 次”。
- 【待确认】辅助汇总方案要求知识点掌握率保留 2 位小数、去尾零，与当前原型不一致。未确认前文档按原型展示描述，不混用两套验收精度。

### 8.3 F08：设置权重

**入口与当前状态**

- 从考核项详情“设置权重”进入，展示当前项关联任务及权重输入框，范围 0～1，步长 0.01。
- 【原型】每次打开按 `1/n` 均分并保留两位小数；确认只检查总和，未保存输入、未改变掌握率，也没有时间衰减或一键均分按钮。
- 【待确认】正式权重默认值与作用范围。辅助汇总方案要求全局任务时间衰减，当前 UI 是单考核项任务均分，不能当作同一个已确认规则。

**无论采用何种方案均须满足的目标规则【补充】**

1. 每个权重为有限数值，`0≤w≤1`；空值、非数值、负数、超过 1 均不可提交。
2. 总和必须为 1；前端浮点容差不大于 0.001，服务端验证后按真实精度归一化。
3. 只有一场时权重固定为 1；无有效任务时显示空态，确认不可用。
4. 自动均分时处理舍入余数，不能给 3 场分别填 0.33 后导致默认值无法通过校验。
5. 确认后保存配置并重算受影响掌握率与未掌握人数；取消、关闭不生效。
6. 再次打开回显已保存权重；任务集合改变时不能静默沿用已经失效的权重。
7. 权重只影响已约定的跨任务掌握率，不改变单任务原始得分率，不自动影响周期任务算术平均、热力单元格或固定次数的顽固判定。
8. 详情任务类型切换是查看过滤，不应悄悄修改已保存的统计权重。

**跨任务汇总公式【补充】**

对考核项 `k`，设有有效得分率的任务集合为 `V_k`：

`P_k = Σ(i∈V_k)(w_i × P_ik) / Σ(i∈V_k)w_i`

- 未考查任务不进入集合；正常考查得 0 分的任务保留。
- 若所有有效任务权重均为 0，则无法计算该项；禁止提交相关无效配置或明确显示“无有效权重”，不能默认为 0% 掌握。
- 年级对比采用同一组权重与可比任务；无法对齐时不展示误导性差值。

**待评审的两种默认策略**

| 策略 | 来源 | 公式与影响 |
| --- | --- | --- |
| 均分 | 当前原型 UI | `w_i=1/n`，各任务等权；需明确是单项配置还是全局配置 |
| 时间衰减 | 辅助汇总方案 | 任务由近到远排序，`w_i=2(n−i+1)/(n(n+1))`，近期权重更高；该方案还提出“一键均分 / 恢复时间衰减” |

未确认前，时间衰减及两个快捷按钮不作为当前原型已具备能力，也不与均分方案同时写入默认验收。

### 9.2 F10：知识图谱诊断

仅知识点维度显示，包含四张卡片。诊断基于本周期成绩与维护关系，不随画布模块显隐变化。

#### 9.2.1 顽固薄弱知识点

- 判定：同一知识点在至少 3 次不同有效任务中失分率 `≥40%`。
- 按有效任务平均失分率降序，原型最多显示 5 项。

- 【补充】标题显示总命中项数，并标明“展示前 5 项”；原型标题当前只取展示条数。

#### 9.2.2 前序断层归因 TOP

- 从二级及三级中选取掌握率 `<60%` 的目标，按掌握率升序取前 5 项。

- 到达无前置、最低前置已达 `70%` 或达到安全边界时停止；原型最多追踪 8 个节点。
- 展示“前序 → 中间项 → 当前目标”的链路、各项掌握率及优先补习建议。

### 9.3 F11：错因结构分析

- 左侧为各任务的横向 100% 堆叠条，右侧为“关键发现”。
- 原型六类：计算失误、概念混淆、审题不清、方法选择、书写规范、未作答。
- 每个任务显示同一组错因颜色；悬停显示任务名称、日期及各类占比。
- 【待确认】“错因占比”的统计分母。页面表达是失分归因，建议采用该错因归属失分 / 可归因总失分，而不是混用题数、人数与分值。

### 9.4 F14：前序 / 后序关联诊断与分目的加练

本节方案与「讲评试卷 3.0」原型（`F:\07 project\讲评试卷2.2\讲评试卷3.0\PRD.md`）同源：题库知识图谱携带前序（前置依赖）、后序（后续应用）、易混淆等教研标注关系后，页面必须把关系转化为教学动作，而不是停留在“图谱更好看”。两页共用同一套证据链方法论；因数据源不同，证据口径存在关键差异。

#### 9.4.1 场景差异：单次作业 vs 周期汇总

| 维度 | 讲评试卷 3.0（单次作业） | 学科学情（本页，周期汇总） |
| --- | --- | --- |
| 数据源 | 本次一份作业 + 历史考试记录 | 筛选范围内全部已选任务的多场汇总 |
| 前序 / 后序证据 | 单次作业内无法获取前后序知识点的作答数据，多数前置只能标「待诊断」，先诊断再下结论 | 前后序知识点在周期内往往有独立作答记录，可直接给出周期汇总掌握率；仅周期内外均未考查的知识点仍为「暂无证据」 |
| 主要动作 | 讲评顺序编排 + 课堂分组补练 + 复测追踪 | 薄弱归因（断层链）+ 分组加练建议输出 + 导出，供讲评与作业模块承接 |
| 加练形态 | 题篮 + 确认布置（课后闭环） | 建议清单（目的 / 名单 / 题量 / 复测），布置动作由题库与讲评页完成（P1 对接） |

结论：单次作业里「待诊断」的前置，在周期汇总下大多升级为「周期内考查」，证据断点只剩周期内外均未考查的少数节点——这正是本页承接该方案的独特价值，也是方案落在本页而非讲评页的原因。

#### 9.4.2 证据状态（周期版四态）

| 状态 | 定义 | 徽章 | 支撑动作 |
| --- | --- | --- | --- |
| 周期内考查（period） | 当前勾选场次集合中该知识点有 ≥1 场有效作答记录；掌握率取 8.3 / 辅助方案 4.2 的跨场次加权汇总 | 蓝 · 周期内 N 场 | 直接归因；<70% 作前置补练依据；≥80% 作后续应用依据 |
| 历史证据（history） | 周期内未独立考查，但历史任务有作答记录；显示最近历史任务名与得分率 | 青 · 历史证据 | <70% 可作前置补练依据（弱于周期内证据）；≥70% 视为尚可 |
| 暂无证据（none） | 周期内与历史均无作答记录 | 橙 · 暂无证据 | 只能先诊断；禁止判为未掌握；断层回溯在此断开 |
| 未学（unlearned） | 教学进度未覆盖 | 灰 · 未学仅衔接 | 仅课堂衔接预告；不诊断、不加练、不进断层候选 |

- 【原型】证据状态由本地例外表 + 默认规则派生演示；真实接入按「场次 × 题目知识点命中」实时推导。
- 【补充】暂无证据与未学节点在关联诊断上下文中不展示掌握率数字（未知 ≠ 0%）；树状图、表格等其他模块的静态掌握率为原型演示值，两套口径差异须在页面声明文案中说明。
- 【补充】前序判定阈值沿用 9.2.2 的 70%（断层专用），与掌握档位 60% / 80% 相互独立，不随 F07 档位设置联动。

#### 9.4.3 前序断层归因的证据化修正（F10 联动）

1. 暂无证据、未学节点不进入断层归因候选（其静态掌握率不代表周期表现）。
2. 回溯链遇到暂无证据前置时标记「证据断点」：链路在该处停止，断点节点显示“暂无作答证据，先诊断再归因”，不得当作根因。
3. 根因节点必须有周期内或历史证据且 <70%；全部有证据前置 ≥70% 时判定为“本点自身问题”。
4. 断层卡每项可点击进入 9.4.4 关联诊断抽屉；每项带加练目的徽章（前置补练 / 前置诊断 / 同点巩固）。

#### 9.4.4 关联诊断抽屉

单个知识点的证据全景 + 分组处理建议。右侧滑入抽屉（宽 min(560px, 94vw)、全高、无全屏遮罩，可边看图谱边查证据），仅知识点维度可用。

入口：

- 前序断层归因卡条目点击（携带目标知识点）；
- 证据总览卡待诊断清单点击；
- 关联图谱节点详情面板「关联诊断」按钮。

结构（自上而下）：

1. 头部：层级徽章、名称、周期汇总掌握率与档位、证据状态徽章、未掌握人数；一 / 二级知识点注明“关联由子知识点聚合，剔除模块内自关联”。
2. 前序区：逐行 = 关系 chip + 前置名称 + 证据徽章 + 证据明细 + 按证据状态生成的动作：
   - 周期内 / 历史证据且 <70% →「查看分组建议」；
   - 暂无证据 →「查看分组建议」；
   - 有证据且 ≥70% → 文案“前置表现尚可，暂无需补练”；
   - 未学 → 文案“未学内容仅课堂衔接，不诊断、不加练”。
3. 易混淆区（存在时）：易混对象 + 全班命中人次（有记录时）+「查看分组建议」。
4. 后序区：未学 → “仅课堂衔接预告，不布置加练”；周期内考查且 ≥80% →「查看分组建议」；其余 → “当前掌握后再安排”；暂无证据 → “待诊断 / 考查后评估”。
5. 学生分组建议：diag / pre / solid / next 四卡片，含名单 chips、分组理由、查看分组建议入口；空组以理由文案代替。
6. 判断边界提示（固定）：综合题失分 ≠ 全关联薄弱；班级均值 ≠ 人人有问题；无作答证据 = 未知，先诊断再下结论。
7. 底部操作条（sticky 常显）：关闭 /「生成分目的加练建议」。

交互：

- 与分目的加练抽屉互斥：打开任一方先收起另一方。
- 从前序区快捷按钮进入加练抽屉时，对应目的区自动定位并高亮。
- 【补充】抽屉内切换目标知识点时保留抽屉形态，不重置主页面滚动位置。

#### 9.4.5 学生分组规则（按知识点作答证据，非总分分层）

| 分组 | 判定 | 对应加练目的 |
| --- | --- | --- |
| diag 组 | 目标周期汇总 <60% 失分，且直接前置中存在暂无证据节点 | 前置诊断 |
| pre 组 | 目标失分，最弱有证据前置汇总 <70% | 前置补练 |
| solid 组 | 目标失分，有证据前置均 ≥70%（或无前置） | 同点巩固 |

- 【补充】真实数据按学生粒度作答证据生成：学生个人对该知识点的周期汇总掌握率 + 其对前置链的作答记录；名单支持教师手工增删，增删留痕。

| 前置补练 | pre | pre 组非空（最弱前置有证据且 <70%） | 基础题 3 题 · 约 12 分钟 |
| 概念辨析 | confuse | 存在易混淆教研标注（有命中记录时附人次） | 成对对比题 2 题 · 约 8 分钟 |
| 同点巩固 | solid | 目标汇总 <80% 且 solid 组非空 | 巩固题 3 题 · 约 15 分钟 |
| 后续应用 | next | 目标汇总 ≥80% | 提高迁移题 2 题 · 约 12 分钟 |
| 复测验证 | retest | 存在任一补练类目的时自动附带 | 同知识点换情境 1 题 · 约 5 分钟 |

输出规则：

- 每目的区含：目的徽章、策略说明、布置范围（仅名单学生 N 人 / 全班共练，默认名单）、名单 chips、建议题量与时长、依据说明（前置名称与掌握率等，供教师核验）。
- 风控警示：目标汇总 <80% 时，后续应用区显示“建议先完成同点巩固”。
- 复测区固定文案：“原题订正只记订正完成，不计为掌握；复测须同知识点、换情境”。
- 底部实时计数：N 组 · 建议共 M 题 · 约 K 分钟（含复测）。
- 导出：CSV（目的 / 目标知识点 / 范围 / 名单 / 建议题数 / 预计时长 / 依据 / 复测说明），文件名 `学科学情_分目的加练建议_{知识点}.csv`；支持复制纯文本摘要。
- 【补充】本页定位为“建议输出”，不直接选题与布置；题目选择、题篮与布置闭环由题库 / 讲评页承接（P1 打通），避免分析页越界为作业发布页。
- 【待确认】建议题量默认值（2 / 3 题）是否按知识点难度与未掌握人数自适应。

#### 9.4.7 证据总览卡（知识图谱诊断第五卡）

- 四态计数 chips：周期内考查 / 历史证据 / 暂无证据（橙色警示）/ 未学，统计范围为当前知识点体系全部节点。
- 待诊断清单：暂无证据且被薄弱目标前置链引用的节点，逐项显示“是谁的前置”，点击进入关联诊断抽屉。
- 固定红线文案：无证据 = 未知，先诊断再下结论；未学内容仅衔接不加练；班级均值 ≠ 人人有问题。
- 声明文案：前序 / 后序证据来自周期内多任务汇总——单次作业内无法获取前后序知识点的作答数据，需阶段性多份作业、考试累积；当前为原型模拟。

#### 9.4.8 判断红线（贯穿全部子功能）

1. 证据链驱动：每个结论必须挂证据；无作答证据 = 未知，不代表未掌握。
2. 关系必须教研确认：章节目录相邻 ≠ 学习依赖；未经教研标注的前后序不得用于归因（沿用 9.1.2）。
3. 未学内容只衔接：不诊断、不加练、不进断层候选。
4. 原题订正 ≠ 掌握：复测须同知识点、换情境。
5. 按学生分组证据处理：班级均值偏低 ≠ 人人有问题；综合题失分 ≠ 全关联薄弱。

#### 9.4.9 迭代规划与埋点

- P1：证据状态、分组名单接入真实作答数据；加练建议对接题库选题（按目的标签选题）；与讲评页题篮 / 作业布置打通；复测结果回写掌握状态。
- P2：跨周期证据累积（同一前置多周期加权）；教学进度未覆盖自动同步；教研关系维护工作台（标注 / 审核 / 留痕）。
- 建议埋点：关联诊断抽屉打开（按知识点与入口来源）、断层卡点击率、加练建议生成 → 导出 / 复制转化、复测通过率（按目的分组）。

## 10. 班级共性错题与导出

### 10.1 F12：共性错题准入规则

基础候选必须同时满足：

1. 属于当前全局筛选及已确认任务集合。
2. 本班该题得分率严格 `<60%`。
3. 答错（含未答）人数占有效人数比例严格 `>30%`。

【补充建议】“答错”按该题得分小于满分判定，包含部分得分；有效正常参考但未作答计入，缺考等排除。此定义需与平台题目统计规则确认。

- `60%` 得分率不进入；恰好 `30%` 答错比例不进入。
- 同一任务同一题目按唯一题目实例去重，不因挂接多个知识点重复出现在同一列表。
- 同一道标准题在不同任务中再次出现，可以保留不同任务记录，因为班级表现与来源不同；加入错题本的标准题去重策略另见 10.3。
- 【原型限制】当前演示只按得分率区间过滤，没有错误人数数据，也未真正执行双条件准入，且包含上界 60。不能直接作为正式判定实现。

### 10.2 错题工具栏与题卡

| 控件 | 行为 |
| --- | --- |
| 共 N 道 | 显示局部过滤后的题目实例数量，不要求始终等于上方基础集合数量 |
| 按知识点筛选 | 开启后展示三组标签；关闭后忽略这些标签，保留得分率区间与排序 |
| 得分率范围 | 默认 0～60%，作为基础候选之上的二次过滤，不能放宽基础准入 |
| 排序 | 默认得分率降序，点击切换升序 / 降序，保持其他筛选不变 |
| 知识体系 | 全部 / 同步教学 / 高考复习，单选 |
| 维度 | 全部 / 知识点 / 能力，单选 |
| 知识点标签 | 基于可用候选生成，默认全部，单选；能力模式下应明确为能力标签 |

- 【补充】区间必须为 0～100 内有限数值，最小值不得大于最大值；非法时显示行内提示，不按错误输入刷新。
- 主维度决定错题基础数据源；局部维度标签与主维度冲突时，原型会出现空结果。建议禁用不适用选项或合并重复维度控制，评审确认后实现。
- 题卡展示题号、题干、班级得分率、年级得分率、来源任务。
- 【补充】正式题干应支持原有题库富文本、数学公式、选项及图片；原型仅为纯文本样例。
- 无结果显示“暂无符合条件的共性错题”，用户可继续调整条件。

### 10.3 错题操作入口

| 操作 | 目标行为 | 当前状态 |
| --- | --- | --- |
| 数据分析 | 打开该题已有分析能力，携带题目实例、任务及班级上下文 | 只有按钮外观，未绑定业务 |
| 添加重练 | 把该题加入重练待选集合，不等同于立即发布作业 | 只有按钮外观，目标集合待确认 |
| 添加类题 | 进入类题选择并加入待选集合，明确关联依据 | 只有按钮外观，推荐与题库接口待确认 |
| 加入全部错题 | 对当前局部过滤结果执行批量添加，不是整个学科全部题目 | 原型只变更按钮文案并禁用，无真实写入 |

【补充】批量添加必须显示本次数量，提交中防重复，成功后反馈新增 / 已存在 / 失败数量；失败可重试，空列表不可提交。按选定目标集合和标准题 ID 做幂等去重，保留来源任务证据。

【待确认】目标为教师错题本、班级错题本还是重练篮；未明确前不承诺已接通写入。切换筛选后按钮根据新结果重新计算状态，不能沿用原型“一次点击永久禁用”的状态。

### 10.4 F13：CSV 导出

| 导出入口 | 数据范围 | 字段 | 原型文件名 |
| --- | --- | --- | --- |
| 分析明细导出 | 当前维度、表格层级、未掌握过滤；【补充】叠加全局和章节过滤 | 名称、考查频次、班级得分率、年级得分率、差值、未掌握人数、掌握程度 | `学科学情_知识点明细.csv` 或 `学科学情_能力明细.csv` |
| 详情导出 | 当前考核项及详情任务类型，继承全局任务范围 | 作业考试名称、对应题号、班级得分率、年级得分率 | `学科学情_考核项名称_作业考试明细.csv` |

- 原型使用 UTF-8 BOM、CSV 引号转义与换行处理，保证常用表格软件读取中文。
- 在树状图、热力视图中点击明细导出仍导出考核项表，不是导出当前图像或热力矩阵；需通过提示解释。
- 【补充】导出数量、过滤条件、精度与页面一致；差值列单位统一 `pp`。
- 【补充】文件名增加班级、学科、日期区间等上下文，避免不同范围文件混淆。
- 【补充】无数据时提示“暂无可导出数据”；服务端校验权限，防止 CSV 公式注入，清理非法文件名字符。
- 浏览器下载失败应提供重试提示，不伪报成功。

## 13. 异常状态与非功能需求

### 13.1 异常与边界

| 情况 | 页面反馈与处理 |
| --- | --- |
| 全局无可用任务 | 显示“当前时间段内无可用考试或作业”；不保留上一范围的图表结论 |
| 来源草稿全取消 | “确定”不可用或提交校验提示“请至少选择一场考试或作业” |
| 全班无有效成绩 | 得分率显示“—”，未掌握人数不以全班人数填充 |
| 有任务但未考查某项 | 该项标注未考查；热力“·”，不按 0 分处理 |
| 仅一场任务 | 展示单场数据，权重 1，不生成首尾趋势与稳定性结论 |
| 不足三场任务 | 不确认顽固薄弱，明确“任务数不足，暂无法判定” |
| 没有年级数据 | 隐藏对应折线，比较值“—”，不把年级填成 0% |
| 上一周期无数据 | 隐藏基准线及环比结论，显示暂无对比数据 |
| 图谱关系未维护 | 保留知识结构和得分，关系详情显示暂无维护 |
| 关联诊断无前置维护 | 前序区显示“暂未维护前置关系”；无证据前置显示“暂无证据 · 待诊断”，不判为未掌握；未学后序仅衔接文案，无加练按钮 |
| 图谱过滤后无节点 | 提示选择模块或开启关系，可通过“全部显示”恢复 |
| 详情数据为空 | 显示当前项名称与空态，不跳到其他有数据节点 |
| 权重不合法 | 高亮输入与具体原因，阻止保存，保留编辑内容 |
| 错题结果为空 | 显示空态，批量加入不可用 |
| 请求失败或超时 | 模块内错误提示与重试，区分失败和真实无数据 |
| 无权限或授权变化 | 不返回敏感结果，显示无访问权限；导出与写入同步受限 |

### 13.2 展示与兼容

- 以桌面浏览器为主要验收环境，覆盖实际教学终端常用 Chrome / Edge。
- 当前样式在宽度 ≤1200px 时将图谱详情放到下方、诊断卡改为单列；≤1100px 时周期与错因的图文区域上下排列。
- 明细目录默认约 280px，≤900px 约 240px；≤680px 明细目录和内容上下排列。
- 上述是当前局部适配能力，不等于已完成全页面移动端适配。正式上线需检查导航、筛选栏、弹层、宽表与图谱在目标屏宽下可操作。
- 横向滚动限制在对应表格 / 矩阵模块内；长题干、长任务名不遮挡操作。
- 状态同时使用文字、数字与颜色；控件有清晰焦点，目录开关提供可访问名称和展开状态。
- 【补充】弹层支持合理焦点管理与键盘关闭；尊重减少动画偏好。

### 13.3 性能、可靠性与安全

- 图谱、趋势等重型图表可延后或按需初始化，不阻塞基础筛选与文字数据。
- 大任务量、大节点量下采用分页、按需加载或聚合，不截断数据却不提示。
- 首屏与切换耗时目标在确认真实数据量及部署环境后制定，不以本地 Mock 测试作为生产 SLA。
- 外部图表、字体、图标资源失败时有降级或重试；生产应采用平台可用资源策略。
- 导出、错题写入及学生粒度数据访问留存必要审计，不把学生敏感信息暴露在非授权上下文。
- 题干与任务名称等富文本进行安全处理，防止脚本注入；CSV 防公式执行。
- 诊断规则、数据版本、分母与证据可追踪，避免结论不可解释。

### 13.4 效果观察【补充建议】

记录筛选、来源确认、维度 / 视图切换、详情进入、图谱节点查看、导出及错题处理的必要事件，关联匿名化查询上下文。用于观察教师分析使用率、薄弱项下钻率、导出成功率和错题处理转化，不预设未经验证的增长目标。

## 14. 验收标准

标注为【补充】的目标行为需在产品评审纳入后执行；【待确认】决策先形成结论，再补齐对应测试数据。以下不是声明当前原型全部通过。

## 15. 原型现状与待确认清单

### 15.1 关键差异与开发补齐项

| 项目 | 当前事实 | 正式需求处理 |
| --- | --- | --- |
| 数据来源 | 主体为本地 Mock，无完整后端链路 | 接入统一统计上下文和真实接口 |
| 日期与任务 | 筛选月份、来源任务、周期任务的年份和范围不一致；周期文案固定“近一月” | 动态显示真实范围，统一任务 ID 与数据集 |
| 学情来源数量 | 初始显示 24 份，但周期图只有 6 次任务 | 同一选择集合驱动全部模块 |
| 学科 / 班级筛选 | 选项可操作，但未带动真实重算 | 补齐数据联动与加载状态 |
| 来源取消 | 取消后临时勾选仍保留，顶部数可能与弹窗不一致 | 使用草稿 / 已确认双状态 |
| 章节目录 | 物理静态样例，勾选未过滤数学分析 | 使用教材映射，补齐明细范围过滤 |
| 考查频次 | 缺失时默认 10 | 明确频次定义并返回真实值 |
| 未掌握人数 | 使用静态字段，不随实际权重重算 | 接入学生粒度结果与阈值计算 |
| 子级详情 | 点击“并集与交集”实际回退“集合与逻辑” | 使用节点 ID 准确下钻 |
| 未掌握卡定位 | 切表格后滚动到第一个 section，即周期概览 | 改为定位分析明细 |
| 掌握设置 | 仅 3 / 4 档预设，区间文字与代码边界相反 | 保留预设能力，统一边界与取消语义 |
| 权重 | 输入不保存，不参与统计，三场均分会出现0.99 | 确认默认策略与作用域后实现保存与重算 |

| 关联图谱箭头 | 统一箭头配置未区分对等关系 | 按关系方向绘制、无向关系去重 |
| 图谱计数 | 画布可见节点与全体系节点是不同口径 | 分别标注，不能强求所有模块数值相同 |
| 诊断截断 | 顽固标题显示前5条数量，其他部分显示总数 | 统一“总数 + 展示前N条”说明 |
| 诊断推断 | 文案有因果与教学效果断言，部分样例需学科复核 | 保留证据链，改为审慎、可核查的建议 |
| 共性错题 | 缺错答人数，使用区间且包含60% | 实现严格双条件与去重 |
| 错题处理 | 单题按钮未接线，批量按钮只修改UI | 明确目标服务并对接真实结果 |
| 导出 | 两类CSV可生成，差值单位仍为% | 保留能力并补权限、范围、单位及安全处理 |
| 前后序证据 | 证据状态、场次数、历史记录、未学标记均为本地模拟派生 | 接入场次 × 题目命中与教学进度；暂无证据节点在全部模块统一不显示掌握率 |
| 学生分组与加练 | 名单为模拟池派生，加练建议仅输出清单，未接题库与布置链路 | 接入学生粒度作答证据；P1 对接题库选题与讲评页 / 作业布置，复测结果回写 |

### 15.3 本次原型核验记录

本次读取当前 HTML、脚本、相关样式和历史方案，并在独立浏览器会话中核实关键交互。以下为演示结果，不是生产数据：

- 页面实际初始化为知识点 **111** 个、能力 **10** 个；不能采用 HTML 加载前占位的“知识点10 / 能力19”。
