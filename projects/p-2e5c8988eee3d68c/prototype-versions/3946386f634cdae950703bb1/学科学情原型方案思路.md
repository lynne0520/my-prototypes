# 学科学情分析系统 · 原型产品汇报稿

> 汇报对象：校领导 / 产品决策层
> 建议时长：20 ~ 30 分钟（演示 15 分钟 + 答疑 5 ~ 10 分钟）
> 汇报形式：原型实操演示 + 讲解
> 配套资产：原型 `index.html`、产品级 PRD《学科学情分析系统-PRD.md》、实现级 PRD《学科学情与学生追踪知识点分析-PRD.md》

---

## 一、开场：我们解决什么问题（2 分钟）

### 1.1 核心命题

> 单次作业、考试只能说明某一时点的表现。我们把一段时间的作业和考试汇总起来，帮老师回答四个问题：
>
> 1. 本班在该学科的整体表现是**在提升、下滑，还是持续波动**？
> 2. 哪些知识点、能力**尚未掌握**，哪些问题在多次任务中**反复出现**？
> 3. 当前的薄弱点，是**自身问题，还是前置知识没打牢**、概念混淆、题型易错？
> 4. 应**优先讲评哪些题目**，并如何组织**后续重练**？

### 1.2 教师视角的三大痛点（引出产品必要性）

| 痛点 | 现状 | 本产品回应 |
| --- | --- | --- |
| 看得到分数，看不到规律 | 成绩单是孤立的数字，趋势、稳定性、反复失分无法一眼识别 | 周期学情概览：六指标 + 结论 + 趋势一屏呈现 |
| 看得到薄弱，找不到根因 | "函数不好"是现象，学生卡在哪一步无从判断 | 图谱诊断 + 错因结构：归因到前序知识、概念辨析、题型易错步骤 |
| 诊断得出来，落不了课堂 | 分析报告止于结论，与备课、讲评、练习脱节 | 教学建议 + 分目的加练 + 一键组卷：诊断直接变成明天的课 |

## 二、设计思路：四条产品方法论（核心讲解，8 分钟）

### 思路 1：从"数据看板"升级为"诊断—归因—处方"闭环

传统学情产品停留在"展示得分率"。本原型沿教师真实工作路径，设计为三段式闭环：

```
确定范围 → 周期趋势 → 定位薄弱 → 归因（为什么弱）→ 处方（讲什么、练什么）
   │           │            │              │                │
 筛选栏     周期概览     四视图明细     图谱诊断/错因      教学建议/加练/组卷
```

- **诊断**：六张周期指标卡 + 五张摘要卡 + 四视图明细（树状图 / 热力演进 / 表格 / 关联图谱）
- **归因**：图谱诊断六标签（顽固薄弱 / 前序断层 / 易混淆 / 题型易错点 / 前后序证据 / 已达标）+ 错因结构分析——回答"为什么弱"
- **处方**：教学建议六条规则 + 分目的加练建议 + 一键生成综合练习卷——回答"怎么办"

> 汇报话术："市面上的看板告诉您得分率是 60%，我们告诉您 60% 的根因在前序知识点没打牢，并且给出先补哪、补几题、给谁补。"

### 思路 2：证据驱动的严谨数据口径（本产品最大的差异化）

原型内置多条"数据红线"，体现专业性与可信度：

| 数据红线 | 产品意义 |
| --- | --- |
| **未知 ≠ 未掌握** | 没有作答证据的知识点标"暂无证据"，绝不下"未掌握"结论 |
| 证据四态 | 周期内考查 / 历史证据 / 暂无证据 / 未学·仅衔接，四态对应四套不同处置 |
| 顽固薄弱须 ≥3 次失分率 ≥40% | 防止单次偶然失分被误判为顽疾 |
| 前序断层沿最弱前置回溯至根因 | "直接讲薄弱点无效，学生卡在前序步骤"——先补根因再讲当前 |
| 稳定度、环比、年级对比 | 避免孤立得分率误导判断 |

> 汇报话术："这条红线来自教学规律：没考过不等于不会。系统绝不会把一个没考过的知识点标红说学生没掌握——这就是这套产品跟'拍脑袋看板'的分水岭。"

### 思路 3：班级整体 + 学生个人双视角，同一套知识体系

- **学科学情**（班级视角）：班级整体诊断，服务讲评备课
- **学生追踪**（个人视角）：单生个人口径，服务个性化辅导；个人掌握度与班级基准对比
- 两套视图共用同一套知识体系树、同一套诊断算法，口径完全一致

> 一句话："老师既能在讲台上看全班，也能在面批时看某一个人。"

### 思路 4：周期汇总而非单次作业

趋势判断、顽固性识别、错因迁移（首尾对比）都建立在周期多任务汇总的证据上。单次作业回答不了"反复失分"与"在改善还是恶化"。

## 三、演示脚本：六幕故事线（15 分钟）

> 演示设定：高二 1 班 · 数学 · 近一月（作业 4 次 + 考试 2 次）

### 第 1 幕 周期概览：一屏看全局

- **操作**：主页签「学情汇总」→ 周期学情概览
- **演示点**：
  - 六张 KPI 卡：平均得分率 71.1%（环比 +1.3pp）、稳定度 95.6、知识点达标率 13.9%、顽固薄弱知识点 2 个、提交率 95.8%、需关注学生 8 人
  - 周期结论（规则引擎五条：趋势 / 稳定度 / 年级对比 / 顽固薄弱 / 行动建议）
  - 得分趋势图：班级 vs 年级双折线 + 上周期基准线
- **话术**："一屏回答三个问题：升了还是降了、稳不稳、谁在拖后腿。"

### 第 2 幕 定位薄弱：从数字到知识点

- **操作**：切「知识点分析」页签 → 摘要卡 → 点击「未掌握 27」下钻表格 → 切换四视图
- **演示点**：
  - 维度切换（知识点 111 / 能力 10，全页联动）
  - 热力演进：考核项 × 任务失分率矩阵，顽固项一眼识别
  - 关联图谱：默认聚焦 69 节点 / 120 边，勾选「查看全部知识点」展开 111 节点 / 205 边（含未检测 46）；八种关系可开关、力导向/放射双布局
  - 明细下钻：表格行「查看详情」打开作业考试明细详情页（趋势/表格双视图），可再跳转该次作业/考试讲评页（原型 toast）
- **话术**："从班级平均分到具体知识点，每一层下钻都有数据依据。"

### 第 3 幕 归因：回答"为什么弱"

- **操作**：图谱诊断六标签逐一查看
- **演示点**：
  - 顽固薄弱：演绎推理（场均失分 51%）、单调性（49%）
  - 前序断层：根因链可视化（根因红 / 薄弱黄 / 达标绿），"有根因数/断层总数"计数
  - 易混淆：成对辨析 + 全班命中人次
  - 题型易错点：阅卷标注 + 客观题规则匹配
  - 前后序证据：四态 chips（周期内考查 / 历史证据 / 暂无证据 / 未学）
  - 已达标：减量维持建议
- **话术**："这就是'为什么弱'的答案，而且每一步都有证据支撑。"

### 第 4 幕 处方：诊断变成明天的课

- **操作**：错因结构分析 → 教学建议 → 一键生成综合练习卷
- **演示点**：
  - 错因堆叠图 + 关键发现（首尾对比，如"计算失误占比上升 → 限时 10 分钟 3 题高频短训"）
  - 教学建议六条规则，每条带数据依据 + 智能出题按钮 + 直达按钮
  - 综合练习方案：组卷表（覆盖范围 / 题量 / 场景 / 用时）
- **话术**："诊断结果直接变成明天的备课方案，一键生成练习卷。"

### 第 5 幕 深水区亮点：一人一策

- **操作**：前序断层条目 → 前后序关联诊断抽屉 → 生成分目的加练建议
- **演示点**：
  - 证据四态徽章 + 判断红线（"综合题失分 ≠ 全关联薄弱""班级均值 ≠ 人人有问题""无作答证据 = 未知"）
  - 学生分组四组：前置诊断（2 题 6 分钟）/ 前置补练（3 题 12 分钟）/ 同点巩固（3 题 15 分钟）/ 后续应用（2 题 12 分钟）
  - 分目的加练抽屉：按目的区派生、复测区、实时计数、导出 CSV；顶部面包屑可一键返回上一层关联诊断
- **话术**："同一道错题，不同学生的处方不一样——这是真正的一人一策。"

### 第 6 幕 个体关怀：从全班名单到每人一张处方

- **操作**：主页签「学生学情」筛查名单 → 行内跳转「学生追踪」→ 某学生「知识点分析」
- **演示点**：
  - 学生学情页签：17 人名单 + 学情分布柱状图（优秀/良好/合格/待合格/未学习五档，柱顶标人数）+ 等级/需关注筛选（需关注 8 人，与 KPI 卡同源）
  - 进退步徽章（明显退步红 / 持续低位橙 / 显著进步绿）+ 得分率趋势 sparkline（周期前段→后段，升绿降红）
  - 名单行「学情分析/详情」一键跳转学生追踪个人诊断（学生名三处同步）
  - 个人摘要卡（与班级基准 ±pp 对比）
  - 个人知识图谱诊断六标签（个人口径）
  - 个人错因结构 + 个人教学建议
  - 关联图谱个人口径：个人掌握度 + 断层红色警示
- **话术**："全班诊断用于讲评备课，个人诊断用于面批辅导——同一套知识体系，两个视角。"

### 收尾彩蛋

- **操作**：点击页面右下角 PRD 查看器入口
- **演示点**：页内每个功能区域带编号徽章，点击弹出对应规格说明；全站 23 个章节编号（XK-01~12 + ST-01~11）、页面 20 枚功能徽章
- **话术**："这个原型不是拍脑袋画的——每一个数字都有口径文档支撑，产品可追溯到规则级。"

## 四、价值主张总结（1 分钟）

| 维度 | 价值 |
| --- | --- |
| 对老师 | 从"看数据"到"拿到可执行的讲评与练习方案"，节省备课与诊断时间 |
| 对教学管理 | 周期趋势、稳定度、提交率、需关注学生名单，支撑月度复盘与跟进 |
| 对产品 | 证据驱动口径 + 规则引擎，结论可解释、口径可审计，具备数据产品专业性 |
| 对生态 | 与讲评试卷 3.0 同源方案，诊断结果无缝对接题库与讲评页 |

## 五、常见追问预案

| 追问 | 应答口径 |
| --- | --- |
| 数据从哪里来？ | 原型阶段使用确定性演示数据；真实接入后证据由"场次 × 题目命中"实时推导，学情来源弹窗已支持作业/考试双栏勾选 |
| 与讲评试卷 3.0 什么关系？ | 同源方案：前后序关联诊断与分目的加练直接承接讲评 3.0，本系统补齐"周期汇总"视角（单次作业 → 周期多任务汇总） |
| AI 在哪里？ | 本期为规则引擎 + 干预模板（结论可解释、口径可审计）；大模型自动诊断、出题对接为 P1 规划 |
| 口径怎么算的？ | 例如"知识点达标率 13.9%"= 全维度末级知识点 79 个中达标 11 个；该口径按作业/考试整体统计，与维度切换解耦 |
| 老师会用吗？ | 每一处结论都带行动出口（生成练习、导出 CSV、直达按钮），最小化老师操作路径 |
| 学生进退步怎么判定？ | 原型为演示名单（明显退步 5 / 持续低位 3 / 显著进步 5，与需关注 KPI 同源）；建议判定口径已写入 PRD（后半段较前半段 ±10pp、持续低位 <60% 连续 2 周期），待教研评审后接入真实算法 |

## 六、后续规划（铺垫，1 分钟）

1. **P0**：真实数据接入（作业/考试 + 阅卷标注），演示数据全部替换为可复算的真实口径
2. **P1**：大模型自动诊断（当前规则引擎升级为 LLM 辅助归因）、题库/讲评页/作业布置对接
3. **P2**：校级报告 / 班级报告导航落地、学生端个人报告

## 附：汇报注意事项

- **先讲问题再演示**：每个模块演示前先抛教师痛点，用"提问式引导"（"月考后您最想知道什么？"）
- **主动交代边界反而加分**：演示数据为模拟、错因分析仅智批作业支持、周期结论为规则引擎（非 AI）——体现工程严谨
- **口径问题是领导对数据产品最敏感的点**：主动展示 KPI 卡「?」悬浮提示与 PRD 查看器，证明口径透明可查
- **演示顺序不跳页**：按六幕动线推进，每幕以一句话术收束，保证领导始终跟得上叙事
