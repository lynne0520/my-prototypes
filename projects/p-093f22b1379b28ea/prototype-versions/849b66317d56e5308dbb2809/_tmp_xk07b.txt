**规则 0 · 可诊断性前置**：任何规则执行前先判该条目是否可诊断（原因码与文案见 XK-07D），不可诊断项不进入判定、排序与计数。

**规则 1 · 证据等级（全部诊断共用，先行过滤）**

| 等级 | 定义 | 允许的结论 |
| --- | --- | --- |
| A | 周期内 ≥3 场直接考查 | 可定性（顽固 / 断层 / 达标） |
| B | 1~2 场直接考查 | 只出「疑似」，进折叠区 |
| C | 仅有历史证据 | 只做趋势参考，不进主清单 |
| D | 无作答证据（暂无证据 / 未学） | 禁止出结论，只能「待诊断」 |

**阈值符号（唯一出处：设置 · 掌握程度档位，改档位即全页联动）**

| 符号 | 含义 | 取值 |
| --- | --- | --- |
| `T_u` | 未掌握阈值 = 最低档上界（知识点与能力共用） | 3 档 / 4 档均为 60%；后台改档位后统计卡、档位色、诊断、建议同步重算 |
| `R` | 达标线 =「掌握」档下限 | 80%（4 档的 90% 是「优秀」下限，不作达标线） |
| `T_p` | 前置薄弱线 | 70%（教研常量） |
| `T_m` | 方法掌握线（仅规则 6） | 65%，独立参数，不与 `T_u` 混用 |

> 规则 2~7 中凡出现「薄弱 / 未掌握」一律取 `T_u`，任何位置不得写死第二套数字（阈值单点，见 CALC-01 §3）。

### 规则 2 · 顽固薄弱

**算法**：`n` = 周期内该考核项失分率 ≥40% 的不同任务场次；`L` = 该考核项有效场次失分率的算术平均（不按分值、不按时间加权，与 XK-06 顽固口径同源）。强度与病型只决定结论措辞与动作，不决定是否命中。

| 触发条件 | 结论 | 处置 |
| --- | --- | --- |
| `n` = 0 | 不命中（已检查、无问题） | 不出卡，且不计入「无法诊断」 |
| 1 ≤ `n` ≤ 2（证据 A/B） | 观察项 | 折叠区，不出教学动作 |
| 3 ≤ `n` ≤ 4 且证据 A | 疑似顽固 | 折叠区 + 排 1 次复测，不进主清单 |
| `n` ≥ 5 且证据 A | 结构性顽固 | 主清单 + 按病型定动作 |
| 证据 B（仅 1~2 场直接考查） | 证据不足 | 只出「疑似」，不得出结构性结论 |
| 证据 C（仅有历史证据） | 趋势参考 | 不进主清单、不计入顽固数 |
| 证据 D（无作答证据） | 待诊断 | 禁止出结论（未知 ≠ 未掌握） |

**病型（按顺位命中即止，不叠加；病型定动作，不定强弱）**

| 病型（按顺位命中即止） | 触发条件 | 结论与处置 |
| --- | --- | --- |
| ① 概念型 | 落在命中的易混淆对上，且该对为双弱或单弱 | 概念未建立 → 讲新知 / 成对辨析 |
| ② 基础型 | 近端前置 ≤2 层存在 < `T_p` 节点 | 基础不牢 → 前序补偿（同时命中断层时以断层为主因） |
| ③ 方法型 | 关联方法中 ≥1 个命中规则 6 的方法薄弱 | 解法未建立 → 方法专题 + 按方法组卷 |
| ④ 习惯型 | 命中易错点在 ≥3 个其他知识点同时命中 | 跨点习惯性错误 → 审题 / 书写规范 |
| ⑤ 孤立型 | 无任何关系标注 | 关系未建 → 补标注，不计入教学动作条数 |

### 规则 3 · 前序断层

**算法**：起点 = 掌握度 < `T_u` 的末级知识点；沿前置链回溯（≤5 层、跨一级模块停止、visited 防环），取第一个 < `T_p` 的节点为根因；关系度为类型常量（前置 90），只用于并列排序，不进任何公式。

| 触发条件 | 结论 | 处置 |
| --- | --- | --- |
| 目标点 ≥ `T_u` | 不命中 | 无需回溯 |
| 5 层内找到 < `T_p` 前置（同模块、无环） | 前序断层 | 先补该前置；直接讲本点无效 |
| 5 层内的 < `T_p` 前置跨一级模块 | 跨模块断层（仅提示） | 不归因，教研确认是否跨模块补 |
| 近 5 层无 < `T_p` 前置 | 本点自身问题 | 改判，转规则 2 |
| 回溯超过 5 层仍未定位 | 超过 5 层未定位根因 | 提示补标注 / 拆分知识点 |
| 无前置边 | 关系未建（第四态） | 补标注，不计入「有根因数」 |
| 前置节点无证据（D） | 不参与根因比较 | 补任务，不进分子分母 |
| 链上命中环 | 跳过环上节点（visited） | 数据侧断环（现有 1 个 45 节点环） |

### 规则 4 · 易混淆

**算法**：题库 149 对为单向存储，先按无序对归一去重（否则命中数少一半）；`a`、`b` = 两侧知识点掌握度；`k` = 周期内命中人次。

| 触发条件 | 结论 | 处置 |
| --- | --- | --- |
| `a` < `T_u` 且 `b` < `T_u` | 双弱：概念未建立 | 讲新知 + 成对辨析 |
| 一侧 < `T_u`、另一侧在 [`T_u`, `R`) | 单弱：方向性混淆（左侧） | 课中辨析 + 1 次复测 |
| 一侧 < `T_u`、另一侧 ≥ `R` | 单弱：方向性混淆（已确认） | 课中辨析，不重讲已稳的一侧 |
| 两侧 ≥ `R` 且同题失分 | 双强：情境性混淆 | 换情境复测，不重讲概念 |
| 两侧 ≥ `R` 且无同题失分 | 不命中 | 不出卡 |
| 任一侧无证据 | 不可判 | 标 EVD 原因码，安排补测 |
| 相邻对同时命中 | 混淆链（链长 ≤3） | 成组辨析，不逐对重复出卡 |
| `k` < 5 | 不出卡 | 折叠，仅计数 |

### 规则 5 · 易错点

**算法**：点级 = 知识点 × 易错点，来源为阅卷标注 + 客观题规则匹配。

| 触发条件 | 结论 | 处置 |
| --- | --- | --- |
| 单点命中 1~2 个知识点 | 点级易错 | 直接写进讲评稿 |
| 同一易错点在 ≥3 个知识点命中 | 跨点习惯性错误 | 升级为审题 / 书写规范，不再逐点重复 |
| 命中知识点无作答证据 | 不归因 | 只列标注，不计入结论 |

### 规则 6 · 方法聚合

**算法**：`M` = 关联知识点掌握度的算术平均（不按关系度加权）；`p` = 关联点中（顽固 ∪ 断层）占比；`m` = 关联知识点数。方法掌握线 `T_m` 独立于 `T_u`。

| 触发条件 | 结论 | 处置 |
| --- | --- | --- |
| `m` = 1 | 不单独诊断 | 并入该知识点的诊断条 |
| `m` ≥ 2 且全部无证据 | 不可判 | 补测，不出结论 |
| `m` ≥ 2 且 `p` ≥ 50% | 方法薄弱（构成性：关联点本身已溃） | 方法专题，先补关联点 |
| `m` ≥ 2 且 `p` < 50% 且 `M` < `T_m` | 方法掌握不足（水平性） | 专项课 + 按方法组卷 |
| `m` ≥ 2 且 `p` < 50% 且 `M` ≥ `T_m` | 不命中 | 不计 |
| `m` ≥ 5（附加建议） | 覆盖广 | 建议连排 2 课时并按方法组卷 |

### 规则 7 · 能力二分（可测 / 不可测）

**算法**

1. 唯一化：1821 条边（考查 919 + 依赖 902）按「知识点-能力」对去重 → 1594 对；重叠的 227 对一律归考查侧（可测优先），依赖侧余 675 对，每个对只进一个分母。
2. 考查侧：`k` = 该能力下**有作答证据**的考查侧知识点数（不是关系表全量）；`A` = 这些知识点掌握度的算术平均。
3. 依赖侧：`h` = 该能力依赖侧知识点中掌握度 < `T_u` 的占比（分母 = 该侧有证据的点数）。

| 触发条件 | 结论 | 处置 |
| --- | --- | --- |
| `k` ≥ 8 且 `A` < `T_u` | 能力短板（可测） | 跨知识点能力专项 |
| `k` ≥ 8 且 `T_u` ≤ `A` < `R` | 能力一般 | 观察，不占专项课时 |
| `k` ≥ 8 且 `A` ≥ `R` | 能力达标 | 转减量维持 |
| `k` < 8（不论 `A`） | 样本不足（可测点 `k`/8） | 补测，不得出短板结论 |
| 仅依赖边且 `h` ≥ 40% | 待补测（禁止判薄弱） | 安排覆盖该能力的测评 |
| 仅依赖边且 `h` < 40% | 不可判 | 不出卡 |
| 有考查边但 `k` < 8 且 `h` ≥ 40% | 待补测（可测不足） | 补测 |
| 4 个能力同时命中 | 按 `A` 升序取前 2 | 防教学建议条数失控 |

> **`≥8` 的定位**：8 是「防单点极值绑架能力结论」的下限——`n` = 8 时单个满分点对均值的最大拉升为（100 − `T_u`）÷ 8 ≈ 5pp，`n` = 3 时达 12pp，「三个点里一个特别好」就足以洗白一个真短板。它不是统计显著样本量（`n` = 8 时均值标准误约 7pp、95% 置信半宽约 ±14pp），因此能力结论必须同时显示 `k` 与证据等级。该参数后台可调，调低到 ≤3 会使能力结论退化为知识点结论。

**参数总表（默认值，均可后台调整）**

| 参数 | 默认 | 参数 | 默认 |
| --- | --- | --- | --- |
| 顽固次数 / 失分率阈值 | 3 次 / 40% | 结构性强度 | ≥5 次 |
| 断层目标 / 前置阈值 | `T_u`（跟随设置）/ 70% | 断层回溯层数 | 5 层 |
| 易混出卡门槛 | 5 人次 | 方法聚合最少点 | 2 个 |
| 方法薄弱占比 / 掌握线 | 50% / 65% | 能力聚合最少点 / 短板线 | 8 个 / `T_u` |
| 跨点习惯错误 | ≥3 个知识点 | 能力短板输出上限 | 2 个 |
| 达标线 | 「掌握」档下限 80%（3 档 / 4 档相同） | 进步阈值 | 8 个百分点 |

> `T_u` 与 `R` 的唯一出处是「设置 · 掌握程度」档位；改档位后统计卡徽章、树图档位色、诊断判定与教学建议同步重算，任何位置不得写死 60 / 80。
