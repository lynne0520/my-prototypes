## 0 文档说明

**编号规则**：每个一级视图一个前缀（XK = 学科学情，ST = 学生追踪），按页面视觉流两位序号编号；诊断规则细化章以字母后缀区分（XK-07A ~ XK-07D），页面上只挂主章节徽章。页面各模块左上角的编号徽章点击即打开右侧抽屉并定位本章。

**视图框架**

```
学情分析
├─ 学科学情
│   ├─ 顶部筛选栏 → 周期学情概览（KPI / 趋势 / 任务清单 / 周期结论）
│   ├─ 主页签：学情汇总 / 知识点分析
│   ├─ 知识点分析：维度 chip → 摘要卡 → 目录 + 树 / 热力演进 / 表格 / 图谱
│   └─ 知识图谱诊断（6 标签）→ 错因结构 → 教学建议
└─ 学生追踪
    └─ 学生列表 → 学生头部 + 三页签（作业 / 考试 / 错题本）
```

**核心术语**

| 术语 | 含义 |
| --- | --- |
| 末级节点 | 知识点或能力树中无子节点的节点，达标率、顽固薄弱等统计均以它为单位 |
| 顽固薄弱 | 同一考核项在 ≥3 次不同任务中失分率 ≥40%（失分率 = 100 − 得分率） |
| 前序断层 | 目标节点掌握度低于未掌握阈值，且前置链上存在 <70% 节点，须先补前序 |
| 证据等级 | A ≥3 场直接考查 / B 1~2 场 / C 仅历史证据 / D 无作答证据（未知 ≠ 未掌握） |
| 掌握档位 | 全校共用，3 档（80 / 60）或 4 档（90 / 80 / 60），改档位全页联动 |

## XK-04 周期学情概览

位置：学情汇总页签。统计区间 = 当前时间档位区间（默认周 2026-W38 = 09-14 ~ 09-20，与筛选栏胶囊同源），展示纳入任务数（作业/考试分列）。维度口径与维度切换解耦：两卡都不随维度切换，且同源于本周期题目挂接集合（定义见 CALC-01 的 `mSet`）——达标率取该集合内掌握度达标的节点占比，顽固薄弱取该集合内满足「≥3 场失分率 ≥40%」者（含能力末级节点）。两卡同源但不可互推：一个看掌握档，一个看连续失分次数。

| 卡 | 口径 |
| --- | --- |
| 平均得分率 | 各次任务班级得分率的算术平均（按任务次数，不按分值加权） |
| 稳定度 | 100 − 各次得分率的总体标准差，越高越稳 |
| 知识点达标率 | 本周期题目挂接集合（`mSet`）中掌握度 ≥ 达标线的节点数 ÷ 集合节点数（挂接集合 = 题目挂接的末级知识点 + 有派生值的能力末级节点；不是全树末级节点，集合内不设「无证据」节点、不做证据过滤）；达标 / 薄弱 / 未掌握三类一律正算、互不反算；阈值随掌握档位联动；点击下钻明细模块 |
| 顽固薄弱知识点 | 挂接集合内同一节点 ≥3 次不同任务失分率 ≥40%（含能力末级节点）；点击下钻热力演进 |
| 提交率 | 实交人次 ÷ 应交人次 × 100，应交人次 = 班级人数 × 任务数（不设迟交单列，迟交计入已交） |

**周期结论**：由声明式规则表驱动，每条规则定义「出现条件 / 语义色 / 文案模板」，数字按当次统计实时计算。

| 规则 | 出现条件 | 语义色 | 文案要点 |
| --- | --- | --- | --- |
| 趋势 | 必出 | 恒蓝 | 平均得分率、首末变化（升绿降红）+ 趋势档位：升 ≥3 个百分点显著回升 / 升 1~3 缓慢回升 / 相差 1 个点内基本持平 / 降 1~3 缓慢下滑 / 降 ≥3 明显下滑 |
| 稳定度 | 必出 | 不设语义色（只给数值与文字后缀） | 稳定度、标准差、最高最低与极差；后缀判定指标：`σ` ≥5 → 波动偏大，提升尚未稳定；3 ≤ `σ` <5 → 波动中等，起伏偏大；`σ` <3 → 表现稳定。`σ` = 各次班级得分率的总体标准差（除以 n），保留 1 位小数后比较 |
| 年级对比 | 必出 | 胜率 ≥60% 绿 / <40% 红 / 其余琥珀 | N 次任务中 X 次高于年级均值；落后清单逐条列「任务名（班级% vs 年级%）」；考试另行统计领先场次 |
| 顽固薄弱 | 全维度末级顽固非空 | 恒红 | 命中数 + 名单（含能力维度）+ 判定口径；定性「结构性问题，建议专项复习而非重复讲题」 |
| 行动建议 | 全维度末级顽固非空 | 恒琥珀 | 针对平均失分率最高的一项优先安排专项课时；验证目标失分率降至 40% 以下 |

- **得分趋势图**：本班得分率（蓝实线，考试三角、作业圆点）与年级得分率（灰虚线）双折线。
- **任务清单**：列头可排序。每行「首要薄弱点」= 该场任务**已考查末级知识点中得分率最低**者（得分率 = 100 − 失分率，同一末级知识点挂多题时按分值加权）；并列最低的全部展示、顿号分隔；列宽不足截断为「…」，悬停单元格弹出气泡显示全部（并列时标注并列项数）；该场无挂接末级知识点置「—」。合计行口径不同：取 `mSet` 内周期累计失分率最高的一项（考核项 / 能力末级节点口径，与卡4 顽固薄弱同源），悬停同样显示气泡说明。
- **查看明细分流**：作业 → 作业讲评页，考试 → 试卷讲评页，携带该行任务标识落地到具体任务；跳转前按角色判定讲评页菜单权限，无权限不跳转并提示「暂无查看权限」（约 2.2 秒消失，入口仍可见）；原型阶段点击仅提示「打开作业详情」，真实跳转与权限判定待讲评模块接入。

## XK-06 知识点分析明细

- **标题联动**：模块标题随维度显示「知识点分析明细」或「能力分析明细」，主页签名恒为「知识点分析」。
- **统一目录**：一级节点多选开关 + 「已开/总数」计数 + 覆盖徽章「已考 x/y」（子树有检测证据节点数 ÷ 子树节点总数）；关闭项灰显加删除线，再次点击恢复，只影响展示层；零覆盖一级模块默认隐藏，勾选「查看全部知识点」后显示（琥珀提醒，得分率位改「未检测」）；目录色点 = 该模块掌握度档位色，无证据恒灰，不按模块类型取色。
- **查看全部知识点**：默认不勾选，仅知识点维度渲染；勾选后目录、树状图、表格、关联图谱显示全部 111 个节点；统计口径（摘要卡、KPI、诊断计数、教学建议）不随开关变化，属统计红线；知识点与能力两个维度的开关状态分别记忆。
- **树状图（默认）**：节点按掌握度档位着色；暂无证据与未学恒灰（勾选后仍灰，悬停提示证据状态）；有历史得分的按历史得分率着色；底部图例随掌握档位实时生成。
- **表格**：层级页签「全部/一级/二级/三级」；不显示检测状态列；无本期证据的行数值显示「—」，未知不算未掌握。
- **关联图谱**：深度一级 / 二级 / 三级（默认）；关系类型不给筛选开关（关联关系按需加载、数据量过大无法一次性取全，画布固定按默认口径渲染：前置·后续 + 树状结构）；另有标签策略（简洁 / 自动 / 全显，控制画布文字说明）、仅看关联、力导向 / 放射布局。画布只渲染知识点节点及其间边，能力、题型、方法、易错点四类关联对象只在节点详情面板的关联清单出现，不占节点也不连边（清单显示口径见下节「详情面板关联清单显示口径」）；节点填充色 = 掌握度档位色，断层节点改红色描边 + 红晕 + 加粗线宽（填充仍表掌握度）；断层红边只画有证据的前置关系；统计条只给两个数字「知识点 当前显示数 / 总数」（总数不随目录模块开关变化，目录隐藏模块时只有显示数减少；未检测数量与口径见悬停提示）。
- **导出**：按当前维度、层级、目录过滤后的同口径数据导出 CSV（带 BOM），含检测状态列。

**详情面板关联清单显示口径**

点击画布节点打开节点详情面板。面板自上而下：层级标签（一级 / 二级 / 三级知识点）+ 节点周期得分率、节点名、层级路径、两个统计项、清单区；节点无本期证据时头部改显「未检测」灰字，未学与已学无证据的悬停文案不同。统计项固定两项——「关联关系 N」与「子节点 N」，同时是清单切换入口；「前后序关联诊断」按钮只在关联关系清单出现，子节点清单不出现；切换节点时默认回到关联关系清单。

关联关系固定 8 组、按序渲染；某组无数据则整组不渲染，组标题后带该组条数。所有关系类型的对端都是知识点，只是分属不同维度（知识点树 / 能力树 / 题库标签），行尾一律取对端自己的周期得分率：

| 分组（按序） | 对端维度 | 行尾得分率 |
| --- | --- | --- |
| 1 前置知识 | 知识点树 | 该前置自己的周期得分率 |
| 2 后续知识 | 知识点树 | 该后续自己的周期得分率 |
| 3 易混淆知识点 | 知识点树 | 该点自己的周期得分率 |
| 4 考查能力 | 能力树 | 该能力自己的周期得分率（按能力标签挂接分值加权） |
| 5 依赖能力 | 能力树 | 同上，取该能力自己的分 |
| 6 考查题型 | 题库标签 | 恒出「-」 |
| 7 常用方法 | 题库标签 | 恒出「-」 |
| 8 易错点 | 题库标签 | 恒出「-」 |

行格式（8 组通用）：

- 一行 = 行首色点 + 名称 + 行尾周期得分率；行内不挂层级或类型标签胶囊，身份由分组标题表达（面板窄，标签会挤压名称）。
- 行首色点取对端自身掌握情况：无证据恒灰，仅有周期外历史证据时按历史得分率取色（与图谱同口径）；行尾数字按掌握档位着色、保留整数。
- 得分率位只有两种结果：本期有作答证据 → 数字；本期无证据 / 未学 / 仅有周期外历史证据 → 「-」，三种情形的悬停文案不同。未知 ≠ 未掌握，禁止补 0 或写「未检测」冒充数值。
- 不出现任何派生均值：「引用它的知识点均分」「关联点均值」不得冒充对端得分率——那是别的维度的分，不是这个对象的表现。
- 每组最多列 8 行，超出显示「… 及另外 N 项」；统计项计数取全部条数，不受 8 行截断影响。
- 断层标记只在「前置知识」组判定：当前节点未掌握（<60%）且前置 <70% 时行加红底与「断层」标记（与画布断层红边同源）。
- 能力行取该能力自己维度的周期得分率，按该能力标签挂接题目的分值加权，时间衰减与知识点同口径。
- 题库未回传题型 / 方法 / 易错点标签的作答挂接，这三组在真实数据上恒为「-」；不得用关联知识点均分顶替。

点击与空态：

- 点击行选中该对端：知识点或能力 → 换为该对象的详情面板；题型 / 方法 / 易错点不在任何树内 → 只在画布上脉冲高亮，不换面板。
- 关联关系为空出「该知识点暂未维护关联关系」；子节点为空出「该知识点暂无直接子节点」；未选中节点时面板出「点击图谱中的节点 / 查看知识点关联详情」。

能力详情（能力作为知识点被点开时）：

- 头部为「一级 / 二级 / 三级能力」+ 该能力自己的周期得分率；无题目挂接该能力标签时出「未检测」。
- 两个统计项：「关联知识点 N」（同一知识点同时挂考查与依赖只计一次）、「子能力 N」。
- 两个清单「挂接为考查能力的知识点」「挂接为依赖能力的知识点」按关系类型分列，行尾出各知识点自己的周期得分率；同一知识点同时挂两类时两个分组都出现，计数不重复。两个清单都是全量引用集，不等于薄弱子集；规则 6 只看该能力自身得分率，不计算依赖侧薄弱占比。
- 子能力清单行尾出子能力自己的周期得分率；无子能力出「该能力暂无子能力」。
- 行点击进入对应详情；能力不在画布上画点画线，因此不提供「前后序关联诊断」入口。

**节点得分率**：按时间衰减加权计算——单场得分率 = 100 − 该场失分率，权重 = 0.5 的（距周期结束天数 ÷ 半衰期 30 天）次幂，加权求和后除以权重之和。完整步骤、数值示例、边界与口径边界见 XK-06A；热力演进累计列用未加权的有效场次算术平均，两者不可互相引用。

**热力演进**

| 项 | 规则 |
| --- | --- |
| 单元格 | 失分率五档着色：<20% 轻度 / 20~40% 中度 / 40~60% 较重 / 60~75% 严重 / ≥75% 极重；五档固定，不随掌握档位的 3 档 / 4 档切换；0% 单独一档（与未考查区分；失分率与掌握度是两套口径，40% 分界是得分率 60% 未掌握线的镜像，属固定锚点） |
| 累计列 | 有效场次失分率的算术平均，不做时间衰减；得分率 = 100 − 失分率 |
| 顽固判定 | 失分率 ≥40% 的场次达到 3 次及以上（与摘要卡同名口径） |
| 行尾判定章 | 顽固 / 反复 / 偶发 / 恶化 / 回升 / 稳定六种，规则见下节「行尾判定章：六态判定规则」 |

**行尾判定章：六态判定规则**

判定按固定顺序短路，先命中先定档。先数重度场次：**H = 本行有效考查场次中失分率 ≥40% 的次数**，再按下表依次命中——H ≥ 3 判顽固、H = 2 判反复、H = 1 判偶发；只有 H = 0（全程没有任何一场失分率 ≥40%）时才进入趋势判定，用前后两半段均值差 Δ 分出恶化 / 回升 / 稳定。

| 判定章 | 触发条件 | 章面文字 | 悬停判定依据 |
| --- | --- | --- | --- |
| 顽固 | H ≥ 3 | 顽固 · H 次 | H 次失分 ≥40%，结构性薄弱，重复讲题无效，建议专项课时 |
| 反复 | H = 2 | 反复 | 2 次失分 ≥40%，顽固苗头，需盯紧后续任务 |
| 偶发 | H = 1 | 偶发 | 仅 1 次重度失分，倾向偶发（题难 / 粗心），暂不专项处理 |
| 恶化 | H = 0 且 Δ ≥ 5 | 恶化 | 后半段失分均值较前半段 +Δ%，失分加重，建议尽快介入 |
| 回升 | H = 0 且 Δ ≤ −5 | 回升 | 后半段失分均值较前半段 Δ%，失分收窄，前期干预在起效 |
| 稳定 | H = 0 且 Δ 落在 −5 与 5 之间 | 稳定 | Δ ≠ 0 时显示「前后两半均值差 ±Δ%，基本稳定」；Δ = 0 时显示「前后两半均值持平」 |

**趋势差 Δ 的算法**

1. 取本行**实际考查**的场次（格子为「·」的未考查场次直接跳过，不按 0 计入），按任务日期正序排成 v₁ … vₙ；
2. 前半段 = 前 ⌊n ÷ 2⌋ 场，后半段 = 其余场次；n 为奇数时中间那一场归后半段；
3. 两段各取算术平均——不按分值加权，也不做时间衰减；
4. Δ = 后半段均值 − 前半段均值，四舍五入保留 1 位小数；
5. Δ ≥ 5 判恶化（失分变重）；Δ ≤ −5 判回升（失分收窄）；其余判稳定。n = 1 时无两段可比，Δ 记为 0，直接判稳定。

**六态验算示例**（序列为按时间正序的失分率 %）

| 考查序列 | 计算 | 判定 |
| --- | --- | --- |
| 55 / 30 / 45 / 38 / 52 | H = 3（55、45、52），趋势不参与 | 顽固 · 3 次 |
| 60 / 15 / 10 | H = 1；趋势虽为 Δ = 12.5 − 60 = −47.5 | 偶发（趋势被优先级吞并） |
| 38 / 22 / 30 / 18 | H = 0；前半 30，后半 24，Δ = −6 | 回升 |
| 12 / 20 / 26 / 18 / 32 | H = 0；前半 16，后半 25.3，Δ = +9.3 | 恶化 |
| 20 / 25 / 22 | H = 0；前半 20，后半 23.5，Δ = +3.5 | 稳定 |

**边界与已知取舍**

- **优先级吞并**：趋势只在 H = 0 时生效。只要本行出现过 1 次及以上重度失分，判定章就只回答「这块是否结构性薄弱」，不回答「是否在好转」。因此「回升」不等于「顽固项在好转」——它只描述全程失分率均 <40% 的行。要判断顽固项是否收窄，看矩阵末两列数值或行悬停叙事里的「最近一次」值。
- **考查场次的半，不是任务数的半**：未考查场次不参与前后切分，n 只数实际考到的次数；同一行在一场未考查的周期里，切分点会随之平移。
- **奇数取整方向**：n 为奇数时中间一场归后半段（n = 3 即「前 1 场对后 2 场」，n = 5 即「前 2 场对后 3 场」），让「最近」一侧多占一场。
- **阈值含等号**：Δ = 5 判恶化，Δ = −5 判回升；Δ 先四舍五入保留 1 位小数再比较，4.9 仍判稳定。
- **0% 与「·」不可混同**：0% 是一场有效考查且无失分，会拉低所在段均值、把走势推向「回升」；「·」是未考查，直接跳过，不影响判定。
- **与累计列无关**：累计列（有效场次算术平均）只决定行排序与「最突出短板」，不参与六态计算。两者可以背离——长周期累计偏高但近两场在下行，判定章照样可能是顽固。
- **必有且仅有一态**：六态互斥，考查场次 ≥1 的行必命中一态；行首「顽固」标记与判定章「顽固」同源（同为 H ≥ 3），不是两套判定。
- **口径同源**：摘要卡6 顽固薄弱项、周期结论的顽固薄弱规则都取 H ≥ 3，与判定章同一阈值，改动须三处同改。

**底部结论生成规则**（按当次数据实时生成，无固定文案）

| 取数项 | 规则 |
| --- | --- |
| 统计行数 | 当前维度可展示的考核项行数；目录关闭的模块不计入，「共 N 个」同步变小 |
| 顽固数 | 可展示行中命中顽固的行数，与行首「顽固」标记同源 |
| 顽固名单 | 命中行按表格顺序（累计失分率降序）顿号连接，不按命中场次排序 |
| 最突出短板 | 固定取表格首行（累计失分率最高）的名称与累计值，可以不是顽固项 |
| 累计失分率 | 有效场次失分率的算术平均取整，不做时间衰减；与周期得分率加权口径不同，两者不可互相引用 |

| 分支 | 触发条件 | 文案 |
| --- | --- | --- |
| 无可展示行 | 目录一级模块全部关闭 | 当前目录下没有可展示的知识点（或能力），请恢复左侧已关闭的模块后再查看 |
| 有顽固项 | 顽固数 > 0 | 共 N 个知识点，其中 X 个命中顽固薄弱：逐项点名；累计最高项失分率 Y% 为当前最突出短板，建议安排专项课时集中突破 |
| 无顽固项 | 顽固数 = 0 且行数 > 0 | 共 N 个知识点，暂无顽固薄弱项（≥3 次失分率 ≥40%），整体失分以偶发性为主，保持当前教学节奏 |

> 取数顺序：先按目录过滤行，再算累计失分率与顽固标记，最后按累计失分率降序排列，因此首行一定是当前可展示行中累计失分率最高的一项。

## XK-06A 周期得分率与时间衰减模型

**要解决的问题**：同一知识点在一个周期内常被多次考查。直接取算术平均，两个月前的一次低分会与上周的一次高分同权，已经补上的漏洞被旧证据继续拖着，教师看到的掌握状态滞后于现实。时间衰减模型以「周期结束日」为锚点，越靠近锚点的证据权重越高。

**计算步骤**

1. 单场知识点得分率（`qRate`）：作业、考试两类任务已分别实现计算，本 PRD 不展开算式；下游只消费其结果，场次之间不再按分值加权；
2. 距锚点天数 Δ = 周期结束日 − 该场任务日期（自然日，当日为 0 天）；
3. 单场权重 w = 0.5 的（Δ ÷ H）次幂，H 为半衰期，默认 30 天，属后台常量、前端不开放配置；
4. 周期得分率 = Σ（w × 单场得分率）÷ Σw，四舍五入保留 1 位小数；
5. 加权结果按掌握档位映射为掌握状态（3 档 80 / 60，4 档 90 / 80 / 60）；达标线 = 「掌握」档下限，3 档与 4 档均为 80%——4 档的 90% 是「优秀」下限，不参与达标判定。

**权重随距锚点时间的衰减（H = 30 天）**

| 距周期结束 | 权重 w | 相对影响 |
| --- | --- | --- |
| 0 天（当天） | 1.000 | 与基准同权 |
| 7 天 | 0.851 | 八成半 |
| 15 天 | 0.707 | 七成 |
| 30 天 | 0.500 | 半权（半衰期定义点） |
| 45 天 | 0.354 | 约三分之一 |
| 60 天 | 0.250 | 四分之一 |

> 权重只用于同一周期内的相对比较：全部 w 同乘一个常数，结果不变，因此只看各场占比、不必关心绝对量级。锚点取周期结束日而非「今天」，是为了同一周期在任何一天打开都得到同一个得分率。

**数值示例**（周期结束日 10-31，H = 30 天）

| 任务 | 日期 | Δ | 权重 w | 单场得分率 | w × 得分率 |
| --- | --- | --- | --- | --- | --- |
| A | 10-03 | 28 天 | 0.524 | 60.0% | 31.4 |
| B | 10-14 | 17 天 | 0.675 | 72.0% | 48.6 |
| C | 10-28 | 3 天 | 0.933 | 88.0% | 82.1 |
| 合计 | — | — | Σw = 2.132 | 算术均值 73.3% | Σ = 162.1 |

- 周期得分率 = 162.1 ÷ 2.132 = **76.1%**，比算术均值高 2.8 个百分点：最近两场权重合计 1.608（占 75%），最远一场只占 25%。
- 敏感性：把 A 改成 100%、C 改成 50% 后，算术均值 73.3% → 74.0%（几乎不动），加权结果 76.1% → 69.3%（下移 6.8 个百分点）——加权模型对最近一次的变化更敏感，这正是「学生最近补上了没有」要看的东西。

**边界与豁免**

| 情形 | 处理 |
| --- | --- |
| 周期内仅 1 场考查 | 直接取该场得分率（权重归一后为 1，与算术均值一致） |
| 0 场考查（未挂接） | 该节点不在挂接集合内，因而不进达标率分母；不显示 0 与档位色（未知 ≠ 未掌握） |
| 某场未考查该点 | 该场不参与，也不按 0 分计入（按 0 算会系统性压低得分率） |
| 分值缺失 / 满分为 0 | 剔除该场并计入数据异常，不改变分母 |
| 换周期或改时间档 | 全部场次按新锚点重算权重，不做增量复用 |
| 同一任务多次批改改分 | 取最终生效成绩，一场任务只算一次 |
| 半衰期调整 | 全量重算并留痕，历史报表不回溯改写 |

**口径边界（不可混用）**

| 位置 | 用的口径 |
| --- | --- |
| 树状图、表格、关联图谱的节点得分率与掌握状态 | 本模型加权值 |
| 摘要卡班级 / 年级平均得分率、周期 KPI 平均得分率、稳定度 | 按任务次数的算术平均（不按分值、不加权） |
| 热力演进单元格 | 单场失分率原值，不做聚合 |
| 热力演进累计列、顽固判定、最突出短板、结论里的累计失分率 | 有效场次的算术平均，与加权口径互不引用 |
| 达标率 | 分子为集合内加权得分率 ≥ 达标线的节点数，分母为 `mSet`（本周期题目挂接的末级知识点，加上关联知识点至少 1 个被挂接的能力末级节点），不是知识树的末级节点；三档正算，不得反算 |

**口径选择理由与调参**

- 用指数衰减而非线性衰减：线性衰减在半衰期处直接截断，会让「刚过窗口」的一次低分突然消失，产生断崖；指数衰减连续、单调、可累加。
- 场次之间等权（只按时间衰减），不按分值或题量加权：掌握状态关心「这个点会不会」，不关心「这个点占多少分」，否则一道 12 分大题会主导判断。
- 保留未加权均值：两个口径并列展示才能看出「近期是否偏离长期水平」，只给加权值会把波动藏起来。
- 半衰期取 30 天：与月档统计周期对齐，一个月前的证据恰好半权；调大则旧证据久拖不散，调小则单次考试波动主导结论，调整须走后台常量并留痕。

> 原型现状：树节点掌握度与得分率均为内置静态演示值，页面未实现本模型；以上为真实作业与考试数据接入后的计算规范，须由数据侧聚合产出，前端只负责展示与档位映射。

## XK-07 知识图谱诊断

> **本节回答**：知识图谱诊断整体做什么、怎么跑、结果怎么显示。

## 一、诊断流程总览（3 步串行）

```
步骤 1 · 可诊断性过滤（XK-07D）
   ↓ 剔除缺证据 / 缺关系 / 环路的条目
步骤 2 · 证据等级 + 规则判定（XK-07B 规则 1~6）
   ↓ 每条知识点按 6 条规则逐一命中
步骤 3 · 冲突消解 + 结构化输出（XK-07C）
   ↓ 同一知识点命中多规则时取唯一主因
最终 → 6 个标签分面展示 + 计数徽章一屏总览
```

**关键约束**：计数为 0 时必须区分两种空态——「已检查·无问题」与「无法诊断（缺证据/缺关系）」，不得只显示数字 0。

## 二、6 个诊断标签：判定口径与处置动作

下表是教师最终看到的 6 个标签页，每个标签对应一条或多条规则（规则编号见 XK-07B）：

| 标签 | 一句话说明 | 判定口径 | 处置要点 | 对应规则 |
| --- | --- | --- | --- | --- |
| 顽固薄弱 | 哪些错一直没解决 | 同一考核项 ≥3 次不同任务失分率 ≥40%；强度两档：≥5 次结构性 / 3~4 次疑似（不设 1~2 次档：命中门槛已要求 ≥3 次失分，该区间不可达）；**病型五类本期不做** | 全部顽固项共用一条**统一建议**：同点巩固 + 变式复测（复盘失分题 → 变式复测 2 次 → 失分率降到 40% 以下退出名单）；安排**专项课**而非重复讲题 | 规则 2 |

| 易错点 | 在哪一步错（比错因更细） | 阅卷标注 + 客观题规则匹配；点级=知识点×易错点=讲评落点；同一易错点 ≥3 个知识点命中→跨点习惯性错误 | 可直接写进讲评稿；跨点项升级为审题/书写规范，不逐点重复 | 规则 5 |
| 前后序证据 | 周期内多任务汇总的作答证据 | 四态映射证据等级：本期已考查 A/B、仅历史 C、暂无证据与未学 D；D 级禁止出结论 | **无作答证据=未知**，不得标为未掌握；点节点标签打开关联诊断抽屉 | 规则 1 |
| 已达标 | 正向展示：存量认可+增量可见 | 统计单元=题目挂接的末级节点；达标线=「掌握」档下限（3档/4档均 80%）；有效场次 ≥3 场方可判达标，1~2 场标「待确认」并进折叠带、不计入已达标数（同规则 1 的 A 级门槛）；进步=首末提升 ≥8pp | 转「减量维持」，每周 1 次滚动复测；新晋达标换情境再测一次 | — |

## 三、顽固薄弱处置（规则 2 展开）

**本期范围**：不做病型五类判断（概念型 / 基础型 / 方法型 / 习惯型 / 孤立型）。顽固判定本身不变（≥3 次不同任务失分率 ≥40%），但所有顽固项**共用同一条建议**，不按病型分派动作，界面也不出现病型徽章。

**统一建议（唯一口径）**：同点巩固 + 变式复测——① 复盘该考核项各次失分题、归类错因；② 用同知识点变式题连续 2 次复测；③ 失分率降到 40% 以下即退出顽固名单。

| 强度 | 触发 | 与统一建议的关系 |
| --- | --- | --- |
| 结构性 | ≥5 次不同任务失分率 ≥40% | 优先排专项课，统一建议为主路径 |
| 疑似 | 3~4 次 | 统一建议照常执行，同时核查前置关系标注是否缺失 |

不设 1~2 次档：顽固命中门槛已要求 ≥3 次不同任务失分，1~2 次区间不可达；原先单列的「观察」档已删除。

**判定红线**：无证据节点不参与比较（未知 ≠ 薄弱，也不等于达标）；统一建议对所有顽固项一视同仁，不得因缺少关系标注而拒绝给建议，也不得反过来由建议推断病型。

> 病型五类算法（概念 → 基础 → 方法 → 习惯 → 孤立）与参数仍保留在代码 kgClassifyPathology，本期无调用点，供二期恢复；恢复前不得在界面出现病型标签或「处置 <动作>」措辞。

## XK-07A 诊断关系体系与画布边界

## 一、为什么按「拓扑角色」分组

题库知识关系共 21 类。拓扑角色决定算法能力，每一类关系的建议生成条件与停用边界必须在 XK-12.3 逐类登记，不得用「同拓扑」省略具体显隐规则。按拓扑角色分 4 组：

| 拓扑角色 | 结构特征 | 能做什么诊断 | 不能做什么 |
| --- | --- | --- | --- |
| 链条（深链） | 入度≈1，可无限延伸 | 路径回溯（断层链、补链顺序） | — |
| 二元（无序对） | 两个节点互为混淆 | 成对辨析、混淆链 | 不能做路径回溯 |
| 枢纽（多对多） | 一个方法/能力连多个知识点 | 聚合统计（能力短板；方法诊断本期不做） | 不能画在图谱上 |

## 三、画布-诊断一致性（红线）

**核心原则：画布上看得见的关系才能生成路径型结论。**

- 只有画线类关系（知识点与题点的前后置、易混淆）可生成路径型结论（断层链、混淆对）
- 方法 / 能力 / 易错点属「仅详情类」，只能出现在清单、聚合卡与教学建议中
- 每条结论须列出所引用关系（类型 + 对象 + 关系度）并可点回图谱
- **宣称画布可见却引用非画线关系 = 实现缺陷**

## XK-07C 诊断冲突消解与结构化输出

> **本节回答**：同一知识点命中多条规则时，如何取唯一主因、如何折叠其余、输出哪些字段。

## 一、为什么需要冲突消解

一个知识点可能同时命中断层、易混、顽固、能力。如果全部平铺，教师会看到矛盾建议（「先补前置」与「直接讲本点」并存）。因此**每个知识点只输出一条主因**，其余折叠为「同时命中 N 项」。B 级疑似结论不参与主因排序，一律进折叠带；只有 A 级结论可争夺主因。若某知识点全部命中都是 B 级（1~2 场）而凑不出任何 A 级结论，主因位留空并显示「疑似（证据不足）」，疑似项全部进折叠带，不生成教学动作、不计入建议条数。

## 二、优先级顺序（取第一条命中作主因）

| 优先级 | 主因类型 | 为什么排这里 |
| --- | --- | --- |
| 1 | 前序断层 | 前置不牢时讲本点无效——必须先解决 |
| 2 | 易混淆（单弱） | 概念方向错时刷题无效——辨析优先于练习 |
| 3 | 顽固薄弱（本期不区分病型） | 统一建议唯一，不存在「按病型给不同动作」的分歧 |
| 4 | 能力短板 | 跨知识点专项，优先级低于单点问题 |
| 5 | 已达标 | 减量维持，非问题项 |
| 6 | 补标注 | 数据治理，不计入教学动作条数 |
| — | 主因留空 ·「疑似（证据不足）」 | 仅 B 级（1~2 场）命中、凑不出 A 级结论时，主因位显示该文案，不把疑虑写成结论；此态不出动作 |

| 字段 | 说明 |

## 四、数据前置条件（未满足则规则降级）

## XK-07D 无法诊断的判定与说明

> **本节回答**：什么时候「诊断不了」、页面怎么显示、谁来修。

## 一、核心区分

**无法诊断 ≠ 无问题。** 前者缺证据或缺关系（系统能力不足），后者已检查且结论正常（学生确实没问题）。两者的文案、计数口径与处置动作完全不同。

## 二、三个级别的不可诊断

| 级别 | 含义 | 举例 | 页面处理 |
| --- | --- | --- | --- |
| 单元级 | 该分析单元不提供此类诊断 | 微题点的前序断层、未开通的题点方法 | 标签禁用 +「该单元不提供此类诊断」，不显示 0 |
| 规则级 | 整条规则所需关系类型未开通 | 题点与知识点无直属映射边 | 模块置「规则未启用」，从覆盖率分母剔除 |
| 条目级 | 个别知识点缺边/边失效/成环/无证据 | 某知识点无前置关系 | 灰底 + 原因徽章 + 悬停说明，不显示得分率 |

## XK-08 错因结构分析

- **堆叠柱状图**：横向 100% 堆叠，一条横柱一次任务，段长 = 该错因占该次任务全部失分的比例，每条合计 100%。
- **悬停**：停在任一段上，高亮该错因在所有场次的段、淡化其余；气泡给出该错因的周期均值、Δ 徽章和逐场占比，当前场次那一行加亮。图例只作说明，不能点击显隐。
- **配色**：错因种类随题库扩展，颜色优先取题库定义，未定义的按色板循环取色，柱段、气泡、关键发现三处同源。

关键发现只回答两件事：本周期失分原因的构成变没变，变的那几条该先做什么。它不随维度筛选变化，初始化时算一次；演示用的是内置矩阵（6 场 × 6 种错因），不是真实数据。

**一、取数：每个错因算四个量**

| 量 | 怎么算 | 用途 |
| --- | --- | --- |
| 首次占比 | 矩阵第一行（最早场次）中该错因的占比 | 与末次占比配对求 Δ |
| 末次占比 | 矩阵最后一行（最近场次）中该错因的占比 | 求 Δ；另在「高位」判断里单独使用 |
| Δ | 末次减首次，四舍五入保留 1 位小数，展示带正负号 | 定升降、定是否成条、定红绿 |
| 逐场序列 | 该错因在各场次的占比按时间先后排列 | 只定方向短语说「持续」还是「波动」 |

矩阵按时间先后排，首行最早、末行最近，取数与柱子的上下位置无关。首末两点只说明变没变，逐场序列才说明怎么变，不能只用首末两点推中间有没有反复。

**二、分拣：成条还是合并**

| 归类 | 条件 | 页面输出 |
| --- | --- | --- |
| 显著迁移 | Δ 绝对值 ≥3 个百分点 | 单独成行，按 Δ 绝对值从大到小排；Δ 为正红色、为负绿色 |
| 基本稳定 | Δ 绝对值 <3 个百分点 | 合并为一条蓝色汇总，明细见下 |

- 成条行的固定结构：错因名 + 首次占比 → 末次占比（加粗）+ Δ 徽章（如 +9%、-7%）+ 一行处置句。错因名只作数据展示，不写进文案句子。
- 汇总文案：「基本稳定：A、B 的占比变化均在 ±3% 以内，错因结构未发生明显迁移。」名单按错因体系当前顺序用顿号拼接，不按 Δ 或末次排序。
- 汇总内若有错因末次占比 ≥30%，追加：「其中 A、B 末次占比仍 ≥30%，属高位稳定：建议纳入常态讲评，不因「未迁移」而忽略。」

**三、方向短语（四态）**

| 方向 | 逐场走势 | 短语 |
| --- | --- | --- |
| 上升 | 一路不降 | 占比逐场持续上升 |
| 上升 | 中途有回落 | 占比波动上行 |
| 下降 | 一路不升 | 占比逐场稳步下降 |
| 下降 | 中途有反弹 | 占比波动回落 |

单调性按 Δ 的方向单向校验：上升项要求每一步相邻差 ≥0，持平算不降，出现任一步回落即判波动；下降项对称。只有 1 场任务时无差分可比，按波动处理，但此时 Δ 必为 0，不会成条，页面上看不到这种措辞。

**四、处置句（只对成条的错因）**

方向短语在前、处置句在后，两段拼成完整一句。

| 分支 | 条件 | 方向短语之后的原文 |
| --- | --- | --- |
| 急升 | Δ ≥6 个百分点 | 「，升幅达 Δ 个百分点：建议先复盘近期任务中该错因的典型题、定位共性触发条件，再安排专项干预」 |
| 高位 | Δ 为正且 <6，末次 ≥30% | 「且末次占比已 ≥30%：建议列为本周期首要干预错因，短时高频专项讲练 + 下周期复测验证」 |
| 上升常规 | Δ 为正且 <6，末次 <30% | 「：建议安排短时、高频率的针对性讲练，并在下周期复测验证是否退出上升名单」 |
| 低位 | Δ 为负，末次 ≤10% | 「且末次占比已 ≤10%：干预见效，转为滚动观察，把课时让给上升错因」 |
| 下降常规 | Δ 为负，末次 >10% | 「：保持当前干预节奏并持续观察，防止反弹」 |

- 命中顺序：上升侧先试急升、再高位、最后上升常规；下降侧先试低位、再下降常规。急升与高位同时满足时只出急升。
- 两段都由通用指标生成，不含错因名与学科名，换学科、新增错因种类都不用补文案。

**五、边界**

- **区间补全**：上升常规实际覆盖 3 ≤ Δ <6，下降常规实际覆盖 Δ ≤ -3 且末次 >10%；Δ 绝对值在 1 到 2 的错因进蓝色汇总，拿不到这两条文案。
- **Δ 为 0**：一律进基本稳定（实现上落下降侧，但不成条、不出文案）。
- **30% 有两个身份**：分支里的「高位」给处置建议，汇总里的「高位稳定」只提醒别忽略，两处文案不互用。
- **场次口径**：矩阵覆盖周期内全部场次，含考试，不按作业 / 考试过滤；只有 1 场任务时首末同值，Δ=0，全部进基本稳定。
- **与教学建议不是同一套**：教学建议的限时短训只取 Δ ≥3 的上升项、按 Δ 降序，文案固定写「占比持续上升」，不套本节四态——逐场有波动的错因在那里同样写成持续上升。

> 用演示数据验一遍：计算失误 28→37（Δ+9，逐场 28/30/32/33/35/37 一路不降）走急升；概念混淆 26→19（Δ-7，末次 19%）、审题不清 16→12（Δ-4，末次 12%）走下降常规；方法选择 14→14、书写规范 10→12（Δ+2）、未作答 6→6 进基本稳定，末次都低于 30%，不触发高位稳定句。

| 关注范围 | 当前点在前，随后按树内顺序列全部直接子点；不递归后代、不按得分率筛选、不混入前置 / 后续 / 易混点。子点无证据只表示纳入教学范围，不表示薄弱 |
| 判定依据 | 依次显示名单人数、个人入组条件、「巩固当前点本身」、目标班级周期汇总；班级得分率四舍五入为整数百分比。人数、范围和班级得分率分别取数，不得相互推算 |

## XK-13 缺省页与空态方案

缺省页按原因分级：同一句「暂无数据」背后可能是没布置、没回传、没勾选、没标注、没接入，处置与责任方完全不同。

| 级别 | 判定条件 | 责任方 | 主文案 |
| --- | --- | --- | --- |
| L0 周期全空 | 周期内作业 + 考试任务数 = 0 | 教学侧 | 本周期没有作业与考试任务 |
| L0-b 已选 0 份 | 任务池非空，但学情来源被全部取消勾选 | 用户操作 | 已取消全部任务勾选，当前无可分析数据 |
| L1 学科无任务 | 多学科权限下任务池非空，但当前学科任务数 = 0 | 教学侧 | 该学科本周期没布置任务；其他学科有 N 份 |
| L2-a 体系未接入 | 该学科无知识体系（题库映射缺失） | 产品侧 | 该学科知识体系未覆盖 |
| L2-b 未标注知识点 | 有任务有批改，但题目未关联知识点 | 数据治理 | 任务未关联知识点，无法做知识点分析 |
| L3-a 非智批 | 作业为人工登分 / 扫描录入 | 数据链路 | 仅智批作业支持错因分析 |
| L3-b 未标注错因 | 智批完成但无错因标注 | 数据治理 | 已批改，未标注错因 |
| L4 证据不足 | 有证据但有效场次 ≤2 | 教学侧 | 本周期仅 N 场，结论仅供参考 |

- **判定顺序**：L0 → L0-b → L1 → L2 → L3 → L4，命中即停；顺序颠倒会出现「有任务却提示无任务」「未标注却提示未接入」。
- **不存在「无学科」态**：教师可选学科恒 ≥1 个（单学科 / 多学科两种形态），页面不设「无可选学科」空态；单学科下永远不会出现 L1，L2-a 也不会因切学科触发，只能由「已有任务但题库未接入其知识体系」引起。
- **L0 三子情形**：未布置（任务池空且无布置记录）/ 未回传（有布置记录无批改结果）/ 全取消勾选（任务池非空且已选 0 份），三者文案与下一步动作不同，不得共用一句。
- **处置码**：H 整块隐藏不留空框；E 缺省占位（容器 + 插图 + 文案 + 入口）；D 保留结构、数值置「—」；N 正常渲染。

# 三、指标口径与计算公式

## CALC-01 全局指标口径与计算公式

**为什么单独一章**：同一个量在多个页面被重复计算——平均得分率同时出现在周期概览、摘要卡与任务清单。口径一旦分叉，页面之间就会互相打脸，而且没人能判断哪个数是对的。本章是全站唯一的口径出处：页面上任何一个数字都必须能指回本章某一行；页面文案与本章冲突时，先改文案，再改计算。

**三条铁律**

| 铁律 | 内容 |
| --- | --- |
| 一 · 口径不互引 | 单次原值、算术平均、时间衰减加权是三类独立口径，各自只与同类比较；不得用 A 的分子配 B 的分母，也不得用 A 的结论解释 B 的数字 |
| 二 · 未知 ≠ 0 | 未考查、无作答证据、未学，不进分子也不进分母，页面显示「—」或「未覆盖」；按 0 计入会系统性压低所有均值与达标率 |
| 三 · 阈值单点 | 全部阈值只在 CALC-01 §3 定义一次；页面文案、悬停气泡、导出 CSV 不得出现第二套数字 |

### 1 基础量（全部下游计算的原子输入）

| 符号 | 名称 | 公式 | 说明 |
| --- | --- | --- | --- |
| `rate` | 单场得分率 | 该场该考核项得分 ÷ 该场该项满分 × 100 | 场次内已按分值算比例；场次之间不再按分值加权 |
| `loss` | 单场失分率 | 100 − `rate` | 热力单元格与顽固判定用它，不用得分率 |
| `qRate` | 单场知识点得分率 | 作业、考试已分别实现 | 两类任务均已分别实现计算，本 PRD 不展开算式；下游直接消费其结果 |
| `cRate` | 班级同场得分率 | 班级该项总得分 ÷ 班级该项总满分 × 100 | 必须与 `rate` 同场同口径，否则年级对比失真 |
| `Δ` | 距锚点天数 | 锚点日 − 任务日期（自然日，当日为 0） | 全站只用周期结束日一个锚点，不另设锚点 |
| `w` | 时间权重 | 0.5 的（`Δ` ÷ `H`）次幂，`H` = 30 天 | 30 天前的证据恰好半权 |
| `mastery` | 节点掌握度 | 同节点各场 `rate` 按 `w` 加权平均，上限 100 | 树、表格、图谱着色与档位映射的唯一输入 |
| `mSet` | 题目挂接集合（达标率分母） | 两部分之并：① 本周期各任务的题目所挂接的末级知识点，按任务汇总去重；② 关联知识点至少 1 个被挂接的能力末级节点，其得分率由这些知识点聚合派生 | 它不是整个知识树的末级节点，也不是全树叶子；挂接即证据，集合内每个节点都有得分率，因此不存在「无证据节点」这一类别 |

### 2 聚合公式

| 名称 | 公式 | 备注 |
| --- | --- | --- |
| 算术平均 | `mean` = Σ`v` ÷ `n` | 按任务次数平均，不按分值、不按权重重 |
| 时间衰减加权平均 | `W` = Σ(`w` × `v`) ÷ Σ`w` | 权重归一；仅 1 场时退化为该场原值 |
| 总体标准差 | `σ` = 根号下（Σ(`v` − `mean`)² ÷ `n`） | 除以 `n`，不是 `n` − 1；这是教学口径，不是抽样估计 |
| 稳定度 | 100 − `σ` | 越高越稳；`σ` 与稳定度须同源，不得各自四舍五入后相减 |
| 极差 | `max` − `min` | 结论里的最高、最低、极差同源 |
| 胜率 | 胜场数 ÷ 任务数 × 100 | 胜 = 本班（本人）严格大于对比对象；相等不计胜 |
| 首末变化 | 末次值 − 首次值 | 有效场次按日期升序，跳过空值 |
| 名单人数 | 命中学生 ID 去重后的个数 | 同一学生可命中多个条件，须先取并集，不得把各组人数相加 |

### 7 数据基座：末级知识点图谱与题目挂接

末级知识点取自教研标签表（《维度标签数据-高中数学》同步知识点表的末级目录），并入原有知识体系形成四层结构：**模块 → 章 → 节 → 考核项（kpTree 末级节点）→ 末级知识点（原子）**。

| 层 | 来源 | 挂接关系 |
| --- | --- | --- |
| 末级知识点（原子） | 教研标签表末级目录：目录 id + 知识点名 + 归属考核项 + 模块 | 题目 → 多个末级知识点（一题多标签，不限额） |
| 考核项 | kpTree 末级节点（页面「考核项」） | 末级知识点 → 归属考核项（多对一） |
| 章 / 模块 | kpTree 上级节点 | 由有派生值的子节点回算均值，未覆盖子树保留基线值 |

**派生链（单场 → 周期）**

1. 单场知识点得分率 `qRate`：作业、考试两类任务已分别实现计算，本 PRD 不展开算式；同一道题可被多个知识点引用，各知识点得分率之间不存在加总守恒关系；
2. 考核项单场得分率 = 其下全部末级知识点对应题目**合并后**按分值加权（同一场同一考核项内合并计算，避免同一道题被重复计入）；
3. 周期掌握度 = Σ(`w` × 单场得分率) ÷ Σ`w`，见 XK-06A；
4. 父节点掌握度 = 有派生值子节点的算术平均，逐层向上回算；
5. 能力维度独立挂接：题目可同时标注能力素养标签，能力末级节点得分率 = 挂接该能力的题目按分值加权。

**证据规则**

- 挂接即证据：末级知识点在本周期没有任何题目挂接，就不产生得分率，也不进 `mSet`、不进达标率分母；
- 不进集合 ≠ 0 分：页面不显示 0，也不显示档位色（未知 ≠ 未掌握）；
- 原型题库规模：本周期 6 场任务（共 56 题）、末级知识点 61 条，覆盖当前考核项所在的集合与逻辑、函数基础、指数与对数、三角函数等模块；接入真实数据时原子表按教研标签表增量补行即可，派生链不需改动。

> 本章只登记口径，不重复各章交互细节。新增任何指标时，先在 CALC-01 §3 登记阈值、在 CALC-01 §4 登记使用位置，再改页面——顺序颠倒就会出现同一个数字两种算法。
