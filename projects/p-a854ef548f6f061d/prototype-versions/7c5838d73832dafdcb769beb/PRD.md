## LP-01 筛选区

**功能**：按学年、年级、班级、学科、模块与关键词收窄作业列表，决定作业卡与班级行的可见集合。

| 项 | 内容 |
| --- | --- |
| 筛选条件 | 学年、年级（高一 / 高二）、日期范围、任教班级（全部或单班）、学科、模块、关键词 |
| 过滤规则 | 先按班级过滤班级行，再按类型、学科、模块精确匹配；关键词命中作业名称或编号，不区分大小写 |
| 联动 | 班级行被全部滤掉的作业整卡不显示；学科、模块改动即时刷新，关键词停顿约 0.2 秒后刷新 |
| 边界 | 学年、年级、日期范围为占位交互：切换只提示，不重新取数【演示】 |

## LP-03 作业卡片

**功能**：以「作业」为单位出卡（一张卡 = 一次作业），卡头给年级入口，卡内按班级行列出各班任务。

| 项 | 内容 |
| --- | --- |
| 卡头 | 作业名称 + 类型标签（四色）+ 学科标签；右侧显示「N 班待批阅」 |
| 汇总 | 班级数、整体提交率（已交合计 ÷ 应交合计）、平均得分率（按各班已交人数加权）、待批阅班数、最近提交时间 |
| 缺值 | 无任何已批阅班级时平均得分率显示「—」 |
| 着色 | 得分率四档：≥ 85 绿 / ≥ 70 蓝 / ≥ 50 橙 / < 50 红 |
| 折叠 | 班级行超过 2 行时默认只显示前 2 行，可展开全部；默认展开一份示例作业 |

**功能**：班级行承载单班进度与操作入口；班级、年级两个报告入口按「已批阅且有得分率」严格准入，并按当前身份路由到对应角色版本。

| 项 | 内容 |
| --- | --- |
| 班级行 | 五列：班级 / 提交率 / 得分率 / 时间 / 操作；提交率 = 已交 ÷ 应交，含进度条与未交名单悬浮提示 |

## LP-06 报告设置（组长及以上）

**功能**：学科组长及以上在控制条打开「报告设置」，为全校统一设定报告判定口径；任课教师看不到该入口，各报告页只读同一份配置。

| 项 | 内容 |
| --- | --- |
| 权限 | 仅学科组长及以上可见：身份切到组长时按钮出现，任课教师无入口；弹窗开着时切回教师视角会自动收起 |
| 入口 | 控制条右侧、「全部展开」按钮之前；确定后 toast 回显四组阈值 |
| 知识点掌握率档位 | 掌握 ≥ 80% / 薄弱 60–80% / 未掌握 < 60%；只填「掌握 ≥」与「未掌握 <」两个端点，薄弱区间自动成对显示 |
| 等级设置 | 优秀 ≥ 90% / 良好 ≥ 80% / 及格 ≥ 60% / 低分 < 30%，累计口径；可勾选「包含 30%」将低分改为 ≤ 30%（勾选框数值随低分阈值联动） |

| 提交率警示值 | 默认 90%：班级提交率低于该值时，列表行与报告 KPI 转警示色（与 CR-01 警示规则同源） |
| 校验 | 各阈值限 0–100；知识点需掌握 > 未掌握；等级需优秀 > 良好 > 及格 > 低分；分层合计 = 100%；不满足时留在弹窗并提示 |
| 生效范围 | 班级报告 / 年级报告的知识点分级、等级四档、班内分层、提交率警示均读同一份配置（QT-01）；班级对比页「设置等级」为该配置的作业级入口 |
| 存储与边界 | 保存写入会话配置（sessionStorage），刷新后保留；弹窗可点遮罩或 Esc 关闭；列表演示数据不按新阈值重算【演示】 |

## QT-01 指标口径与判定阈值

**功能**：集中声明全部统计口径、判定阈值与降级规则，各模块共用同一份配置，不各自计算。

| 定义 | 口径 |
| --- | --- |
| 有效样本 | 实交 − 空白卷 − 异常卷；仅已批阅班级参与；年级有效样本为各已批阅班级之和，未批阅班级不计入 |
| 年级聚合 | 按有效人数加权（Σ 班均 × 有效人数 ÷ Σ 有效人数），不是班级简单平均 |
| 平均分与得分率 | 同一次作业的两个单位：得分率 = 得分 ÷ 满分 × 100%，平均分 = 得分率 × 满分（本作业满分 105，取逐题分值合计）；两卡并列展示，换算只在展示层做，不回写任何比率、档位与判定 |
| 等级四档 | 优秀 ≥ 90% / 良好 ≥ 80% / 及格 ≥ 60% / 低分 < 30%，累计口径；表头统一写「≥ 该档（低分档除外）」 |
| 班内分层 | A 前 30% / B 中间 50% / C 后 20%，按班内得分率位次；与四档是两套口径，不互相换算、不回写 KPI |
| 讲评来源 | 需讲评 = 学生标记 ∪ 教师标记 ∪ 得分率 < 讲评阈值（默认 70%） |
| 知识点分级 | 掌握 ≥ 80% / 薄弱 60–80% / 未掌握 < 60% |
| 知识点维度 | 维度由学科知识点体系给出（原型演示「同步知识点」「复习知识点」两个维度），维度并列、各自独立统计；一个知识点只属一个维度，同一题挂了多个维度的知识点时分别计入各自维度，不合并、不加权折算；不设能力 / 核心素养维度，也不由知识点反推能力项 |
| 维度切换 | 知识点相关模块各自在模块头提供同一套维度切换器，切换后本模块图表、表格与结论按该维度重算；打印稿以文字回显当前维度名 |
| 维度适用范围 | 维度切换只作用于「按知识点聚合」的分析模块；逐题表与下钻中的知识点列仍展示该题挂接的全部知识点（按维度分组或色点区分），不随切换过滤；错因分析按题目聚合，不设维度切换 |
| 错因数集 | 各学科各有一套错因字典，报告只聚合本次作业实际出现的类别：类别数与名称都不写死、不补 0 行；不同学科不共用同一份 list（详见 CR-05、GR-09） |
| 小样本保护 | 有效样本 < 10 → 隐藏排名、分位与显著性检验，各档率显示「样本不足」 |
| 阈值 | 讲评 70%（20–95 步长 5 可调）；均差判定 ±3pp；标准差与班际极差 15pp；低分率预警 10%；共性薄弱覆盖 ≥ 50%；显著性 p < 0.01 记 **、p < 0.05 记 * |
| 维护入口 | 等级四档、班内分层、知识点分级、提交率警示四组阈值统一由 LP-06「报告设置」（学科组长及以上）维护，报告各模块只读、不各自计算 |
| 权限 | 组长可见真实班名与教师名；教师仅见匿名聚合，不渲染他班明细，不出现学生姓名学号 |
| 范围 | 单次作业口径，不接历史数据、不做跨次对比与趋势预警；全部数据为 mock【演示】 |

## CR-01 一眼概况

**功能**：先用 5 张 KPI 卡（平均分 / 得分率 / 优秀率 / 及格率 / 低分率）定位水平，再逐条列出本次结论（每条一行、行首序号圆编号）。

| 项 | 内容 |
| --- | --- |
| KPI 五卡 | 固定顺序：班级平均分（主卡：大一号数值 + 主色数字）→ 班级得分率 → 优秀率 → 及格率 → 低分率；五卡统一浅蓝底（--rp-primary-bg），主卡不再另设底色；每卡副标固定为「年级同口径值 · 差值」，平均分差用「分」、率差用「pp」，平均分卡另注满分；小样本时三档率显示「样本不足」，平均分与得分率仍给年级值与差值；组长版在得分率卡后追加年级位次徽标 |
| 次级小注 | 提交率（含年级差值与「未交名单」入口）与有效样本（应交 / 空白 / 异常）不再占卡，降级为卡下小注行 |
| 警示规则 | 平均分低于年级（主卡转警示色）、优秀 / 及格率低于年级、低分率高于年级时整卡转警示色（主卡警示色优先于主色）；提交率 < 90% 与小样本改在小注数值上标橙 |

## CR-05 错因分析

**功能**：把本班失分按该学科本次作业实际出现的错因聚类，回答「错在什么类型」而不是「错了哪道题」；同一份错因归属结果同时支撑「按题目看班级汇总」与「按学生看个人各小题」两个视图，并与年级同口径失分占比对照，识别本班比年级更突出的错因。

| 项 | 内容 |
| --- | --- |
| 两个视图 | 模块头切换器：「按题目 · 班级汇总」与「按学生 · 个人下钻」；两视图取同一份逐题 × 逐生错因归属结果，人次可直接对账；打印稿与导出稿两个视图同时输出 |
| 归属模型 | 错因先落到题（每题一组错因权重，权重最大者即该题主错因），再落到做错该题的学生；同一道题可对应不止一类错因 |
| 人次与人数 | 人次 = 学生 × 题目（一人一题记 1 人次，跨题同错因累加）；人数 = 该错因涉及的学生数；Σ 各生错题数 = Σ 各题做错人次 = 班级错因人次 |
| 失分归属 | 该题全班失分按做错人数均摊到做错学生，再按错因归属拆分，故各错因失分之和 = 该题全班失分；失分占比 = 该错因失分 ÷ 全部错因失分（本班 / 年级各自归一） |
| 错因数集 | 由学科错因字典 + 逐题错因标注聚合：出现几类即几类，类别数与名称均不写死；不同学科各自一套，不跨学科复用同一份 list |
| 类别命名 | 直接取该学科错因字典的名称与配色，报告侧不另设一套叫法；字典新增或改名只改字典，报告代码不动 |
| 视图一 · 按题目 | ① 班级错因结构环形图 × 年级对照表（错因 / 本班失分占比 / 年级失分占比 / 差值 / 人次 / 人数 / 涉及题号）；② 错因 × 题目分布矩阵（单元格 = 该题该错因人次，底色深浅表示人次多少，数字可点直达该题）；③ 逐题错因卡（题号、题干、知识点、本班得分率、需讲评、主错因，可展开看该题错因构成堆叠条、错因明细表与做错学生按错因分组） |
| 视图二 · 按学生 | 左侧名单（搜索姓名 / 学号 + 按错因筛选，按错题数降序，带层级与空白卷 / 答题异常标记）；右侧该生逐题明细：先给「该生错因结构 vs 本班」判定个人特征错因 / 班级共性错因，再逐题对照该生错因与本题班级主错因，标「共性错因 / 个别错因」与建议动作（随班讲评 / 单独订正） |
| 联动 | 题卡内与结构表里的做错学生姓名可点，直接跳到「按学生」视图并选中该生；矩阵单元格可点，展开对应题卡并定位 |
| 聚合口径 | 错因按题目聚合，不设知识点维度切换；只有知识点分析类模块才分维度 |
| 年级对照 | 年级口径 = 各已批阅班同一模型叠加；差值 = 本班占比 − 年级占比，正差标红表示本班该错因更突出 |
| 读法 | 失分占比看提分空间（该错因失分 ÷ 全班错因失分），人次看错误面；两者分开读 |
| 空态 | 只列本次出现的错因；无错因数据（仅判分、未接入错因标注）时整块提示「本次作业无错因数据」，不补 0 行、不占位 |
| 权限 | 组长版只读：错因分析位于「教师视角明细」折叠块内，只给班级汇总与年级对照，不出现学生名单与个人下钻 |
| 边界 | 只有接入大模型智批且带错因标注的题目才有错因数据；人次、人数、失分为演示派生值；原型演示数据为英语单一错因字典，其余学科字典接入后同口径生效【演示】 |

## ES-02 作文报告数据与汇总口径

**功能**：班级报告由学生级智批数据现算聚合，禁止手写硬编码的汇总数字；页底不再单独设汇总口径区，口径统一收进本节与标题问号。

| 项 | 内容 |
| --- | --- |
| 数据来源 | 本班学生的个人智批报告；演示数据为确定性 mock，刷新后稳定 |
| 统计范围 | 仅「已智批」学生参与聚合；白卷、异常卷不计入任何均值与占比，仅在明细表单独列示 |
| 通用口径 | 均分 = Σ作文得分 ÷ 人数；得分率 = 得分 ÷ 满分；优秀 ≥ 85%；及格 ≥ 60% |
| 年级口径 | 年级 = 同作业同题下全部「已批阅」班级的已智批学生合集（含当前班，未批阅班不计入）；年级维度均分 = Σ年级维度得分 ÷ 年级已智批人数；年级错误人次 = 该类型在年级全体已智批学生中的命中总次数；对比数据现场现算，不缓存 |
| 得分率标准差 | 取本班已智批学生的逐个得分率 rᵢ 求样本标准差：rᵢ = 该生作文得分 ÷ 满分 × 100%；s = √( Σ(rᵢ − r̄)² ÷ (n − 1) )，r̄ 为这 n 个得分率的算术平均（中心值与卡上大数「平均得分率 = 均分 ÷ 满分」口径略异：前者逐生求率再平均，后者先取均分再折率，差异通常 ≤ 0.1pp）、n 为已智批人数；保留 1 位小数，单位 pp（百分点，如 6.4pp 即学生得分率大致在均值上下浮动 6.4 个百分点）。未交不计入、白卷 / 异常卷不进样本；n < 2 时记 0pp；该值与两极分化判定同源（≥ RP_CONFIG.sdPp 15pp 判分化明显），年级页「年级得分率」卡用同一算法在全年级已智批学生上计算 |
| 概览卡 | 「已批/已交」卡副标只示未交人数、悬停（或键盘聚焦）只浮出未交名单，无报告人数与名单不上卡（白卷 / 异常卷在明细表逐人标注）；「最高分」卡单人直书姓名、多人写并列人数，悬停列最高分名单；两者口径互不混算（未交不计 0 分、不进聚合）；浮层靠边自动回贴可视区，打印不输出；概览六卡与班级 / 年级报告概览一致，统一浅蓝底（--rp-primary-bg），警示态只改数字颜色不改底色 |
| 比率卡 | 「优秀率 / 及格率」两卡由同一张公共卡渲染，两科同口径（优秀 = 得分率 ≥ 85%，及格 = 得分率 ≥ 60%），不按类文或档位折算；及格率卡副标同时给不及格人数及其占已智批人数的比例，该占比 > 10%（RP_CONFIG.lowWarn）时整卡转警示色（88% 及格率也可能因 12% 不及格而标红），与汇总结论「及格线下学生」同源互补 |
| 档位分布与名单 | 模块 2 命名为「档位分布」（英语第一~五档 / 语文一~五类文）；段宽 = 该段人数占比；点击段块或段标签，在同一张卡片内列出该段学生名单（按得分降序）；空段灰显不可点；档位阈值：英语 第五档 ≥ 85% · 第四档 ≥ 70% · 第三档 ≥ 55% · 第二档 ≥ 35% · 第一档 < 35%（零分单列），语文 一类 ≥ 80% · 二类 ≥ 70% · 三类 ≥ 60% · 四类 ≥ 50% · 五类 < 50%（按满分比例折算）；条长 = 该档 / 类人数 ÷ 已智批人数；阈值不在页面上单独说明，只在本节维护 |
| 模块底注下线 | 各模块底部的口径说明块（.rp-note）已整体取消：作文报告 8 个模块各带一段口径，页面被说明文字切碎、阅读动线被打断，口径统一收进本节与 ES-03～ES-06。页面只保留两类非口径文本：① 随本次数据变化的一次性提示（已智批 < 10 人时的小样本提示）；② 语文模块 6 的「讲评建议」正文（属输出内容，不是口径说明） |
| 名单样式 | 段内名单一格一人：姓名与得分、得分率同卡锁定，卡片边界即分组边界，下方进度条示意该生得分率；不再把姓名与分数拆到多列并排，避免横向阅读时姓名与分数跨列错配 |
| 个人智批报告弹窗 | 点击段内名单中的学生、模块 8 明细表的「查看报告」或模块 7 优秀范文的「查看该生智批报告」（并列最高分时指向当前 tab 选中学生），弹窗打开该生个人智批报告，信息架构与个人智批报告一致：顶部居中为报告名与学生切换器，其下为姓名、考号、要求词数 / 字数、全文字数、满分、总分、得分率与档位，并列出该生命中的错误 / 问题类型标签；左栏为该生批注与修改（逐条编号，英语为原句 → 修改 + 错误类型 + 说明，语文为旁批类型 + 批注内容），栏底不再附来源说明（扫描件接入情况见 ES-01 边界）；右栏按报告分部设页签；支持关闭按钮、点击遮罩、Esc 三种关闭方式；弹窗不进纸面，打印与导出稿不输出 |
| 弹窗顶部学生切换 | 顶部居中显示当前学生姓名与切换器：左右箭头在当前范围内上一位 / 下一位循环，姓名按钮点开下拉列出本次已智批学生（姓名 + 考号 + 分数 + 档位），下拉展开时自动把当前学生滚动到可视区；从档位名单进入时切换范围为该档位学生，从模块 8 明细表或模块 7 优秀范文进入时切换范围为全班已智批学生；切换后保留当前页签；同名学生以考号区分，不串档 |
| 弹窗遮罩覆盖范围 | 弹窗打开时遮罩覆盖整屏：报告视图内的弹窗（学生个人智批报告、导出设置、右侧抽屉、报告设置）遮罩不仅压暗页内内容，还压暗视图上方的全局导航、作业标题行与视图页签；遮罩颜色与页内遮罩一致，拼接处无色差；关闭弹窗后遮罩同步收起，切换视图时遮罩一并收起；报告页独立打开时遮罩只覆盖页内区域 |
| 弹窗内页签与维度卡 | 右栏页签：英语为「智批详情 / 润色提升」（智批详情含基础数据行、综合评价、三维星级卡与教学建议；润色提升含更多表达与佳句亮点），语文为「评分维度详情 / 批改详情 / 全文润色」（维度详情为三维卡下挂 13 个子项达成率，批改详情含综合评价、亮点赏析、扣分明细与待提升，全文润色为逐句润色建议）；维度卡口径同个人报告：星级 = 维度得分 ÷ 满分 × 5 四舍五入，右侧标「得分 / 满分」并附一句维度评语 |
| 英语口径 | 档位按得分率映射（≥85% 五档 / ≥70% 四档 / ≥55% 三档 / ≥35% 二档 / >0 一档）；维度得分率 = Σ维度得分 ÷ Σ维度满分；高频错误按类型聚合人次与人数，模块 4 以班级 × 年级分组柱形对比呈现（详见 ES-03）；典型错误例句以错误类型为主轴（类间按人次降序，与模块 4 同源），每类固定列 2 条、每条只标一位作者，类内不合并同句、不统计同句人数（详见 ES-03）；模块 6「学生佳句」按高级句式 / 高级词汇 / 生动描写三类维度独立分组，各类内部按各自规则归一后成组，组内句子挂学生姓名（详见 ES-05） |
| 语文口径 | 类文按满分比例折算（≥80% 一类 / ≥70% 二类 / ≥60% 三类 / ≥50% 四类 / < 50% 五类）；子项得分率取班级均值；扣分按类型聚合人次与合计扣分；旁批按类型聚合，亮点单独列示 |
| 汇总与假设 | 汇总结论为 2–3 段总结性文本（水平与结构 → 讲评安排 → 数据可信度），不用表格、清单、分隔线与列对齐，判定规则收进标题问号；显式假设：个人智批报告弹窗按结构化字段还原（不含原稿扫描件）、英语总分 = Σ维度、语文总分 = Σ维度 − 扣分；年级对比已接入维度得分与错误类型两处（口径见本节「年级口径」） |

## ES-03 高频语法错误

**功能**：按错误类型聚合高频语法错误，用班级 × 年级分组柱形对比各类型人次；柱组兼作模块 5「典型错误例句」的类型筛选器。

| 项 | 内容 |
| --- | --- |
| 数据 | 学生级错误按类型聚合，每类计人次与涉及学生数，全量列出（不设「其他」、不做 8 类截断）；年级人次取同作业同题下全部已批阅班级的已智批学生合并统计 |
| 展示 | 班级 × 年级分组柱形：每类两根柱（左 = 班级人次、主色；右 = 年级人次、浅色），柱顶标实际人次、柱下注「班 N · 级 M」；类序按班级人次降序（与模块 5 分组同序），每次显示的类数不设上限 |
| 柱高口径 | 两组柱各自按本系列最高人次归一（柱高 = 该类人次 ÷ 本系列最高人次）：年级人次量级远大于班级，同一把尺会把班级柱压平、读不出班内主次；跨系列比较请读柱顶数字与柱下注记，不以柱高直接比大小 |
| 交互 | 点击某类（或键盘 Enter / 空格聚焦该柱组）→ 模块 5 只留该类卡片，顶部出现「类型 · 该类 N 人次 / M 人」提示条与「显示全部」；再点同一类取消 |
| 模块 5 | 模块更名「典型错误例句」（锚点导航同步更名）：一类一卡，卡头给该类人次 / 涉及人数 / 该类学生名单（取前 6 人 + 「等 N 人」，完整名单悬停可见），卡内固定列 2 条例句，列序为序号 / 原句 / 修改 / 讲评要点 / 作者；不设「展开全部」，也不统计句子条数 |
| 例句口径 | 例句出自单个学生的卷面，不存在「一句多人」的统计维度，因此不做同句合并、不设「同句人数」列：类内按学生出现顺序收录，同一原句只保留首次出现（作者即首次写到的学生），每条例句只标一位作者 |
| 口径 | 人次 = 学生报告中 errors 计数，同一学生命中同类两句计 2 人次，故人次 ≥ 涉及人数；原环形图把第 7 类以后合并为「其他」（占 27%~33% 人次），已废弃。这些口径原以模块 4 / 模块 5 底部底注形式显示，现已下线，只在本节维护 |
| 打印 | 柱色按原色彩输出；筛选条不输出；被筛掉的例句卡强制回展为全集（不依赖脚本状态）；例句卡不跨页断开 |

## ES-04 评分维度详情

**功能**：两科共用一套维度卡：三维横向并排，卡头给「维度均分 / 维度满分」，卡内给达成度。语文卡内为 13 条子项达成率；英语无子项，卡内为一条维度得分率通栏，并追加年级对比行与 5 星级分层名单。

| 项 | 内容 |
| --- | --- |
| 维度分 | 卡头大字为维度均分、小字为该维度满分，格式「均分/满分」；均分 = Σ维度得分 ÷ 已智批人数（保留 1 位小数，整数不带小数） |
| 满分来源 | 三维满分按题目配置分发，不写死：语文 60 分卷 20/20/20、微写作 10 分卷 4/3/3；英语 25 分卷 10/10/5、15 分卷 6/6/3 |
| 子项达成率 | 语文 13 子项取全体有效卷的班级均值（整数 %，5–100），条长 = 达成率；子项行不展示评语。英语无子项，卡内改给维度得分率（整数 %，条长 = 得分率） |

## ES-05 学生佳句

**功能**：把班级学生的优秀表达按三类维度独立成组展示：高级句式、高级词汇、生动描写；三类维度互不混排，各自成块，组内每条句子都挂上写作该句的学生姓名。

| 项 | 内容 |
| --- | --- |
| 模块 | 英语作文报告模块 6，标题「学生佳句」，锚点导航同步更名 |
| 三类维度 | ① 高级句式 ② 高级词汇 ③ 生动描写；三个维度块各自独立，左侧色条与浅色标题栏区分归属（句式紫 / 词汇蓝 / 描写青）；某一维度本次无数据时，该块单独显示空态提示 |
| 高级句式归一 | 按语法类型归一化后分组：原始类型中含「倒装」的（倒装句 / not only 倒装 / so 倒装 / 让步倒装）同归「倒装」；主语从句 / 宾语从句 / 定语从句 / 状语从句 / 强调句 / 虚拟语气 / 被动语态各成一类；未命中已知类型的按原名归入「其他」，不按字面碎成多组 |
| 高级词汇归一 | 以词条内容为分组键：去首尾空格、统一小写，并把连字符与多余空白折成空格，因此 take part in / Take part in / take-part-in 归为同一条目；展示时保留首次出现的原始大小写（连字符按空格呈现）；同一词条只列一次，组内列出所有引用该词条的句子与对应学生姓名 |
| 词汇 / 短语 | 按归一化后的词条形态判定：连字符视作空格，词元多于一个者判为「高级短语」，单词判为「高级词汇」；判定基于分组键而非首次出现的写法，保证同一词条的不同写法判定一致 |
| 生动描写归一 | 按描写类型分组，类型为受控枚举（动作 / 心理 / 环境 / 对话），直接映射为中文标签，天然不会因文案差异碎成多组；组序按枚举固定顺序，不随人数变动 |
| 组内条目 | 每条为「姓名徽章 + 句子」：姓名左挂，句子自适应换行；同一学生同一句在同一组内只出现一次；高级词汇维度在句中把该词条加粗高亮（容忍句首大写与连字符写法，词形变化如 took part in、is devoted to 也能命中） |
| 计数 | 组头给「N 人使用 · M 句」，维度块标题栏给「X 组 · Y 人」；人数按学生去重，句子按句计数 |
| 排序 | 高级句式与高级词汇按使用人数降序；生动描写按枚举固定顺序 |
| 关联口径 | 学生个人报告弹窗的「佳句亮点」小节同步列出该生的词汇（含引用例句）、句式与描写；模块 8 明细表的「亮点数」= 高级词汇 + 高分句式 + 生动描写 |
| 说明位置 | 三类维度的归一化规则不在页面上复述（原模块 6 底部三段归一说明已下线），统一维护于本节；页面只在各维度块标题栏保留一行短口径：句式「语法类型归一化后分组」、词汇「词条归一化去重，一词一组」、描写「按描写类型分组」 |
| 打印 | 维度块内的条目行不跨页断开；姓名徽章与底色在纸上保留 |

## ES-06 优秀范文

| 项 | 内容 |
| --- | --- |

| 并列切换 | 并列最高分时以顶部姓名 tab 切换范文学生：切 tab 只换该生的原稿 / 润色后范文两栏与头部信息、查看入口，不重排页面、不跳滚动；默认选中明细表顺序靠前者；打印与导出稿只输出当前选中的那一位 |

| 说明位置 | 模块底部不再输出说明（原「范文取本次得分最高学生…两栏逐段对照」底注已下线），作文标题行同步下线；取样口径见本节「取样口径」，入口说明见「头部卡」 |
