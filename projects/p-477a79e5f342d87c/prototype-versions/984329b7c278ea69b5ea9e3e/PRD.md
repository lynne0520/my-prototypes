## §0 文档说明

- **编号规则**：跨学科分析视图统一用前缀 `XK`。`XK-00` 为总览章（使用对象、场景与判弱规则），不对应页面徽章；`XK-01`…`XK-10` 按页面视觉流从上到下编号，与页面各模块悬浮的编号徽章一一对应；验收场景编号 `AC-nn`。
- **颜色**：文中 UI 颜色一律写成 RGB 值，取自 `tokens.css` 设计令牌换算。
- **术语**：
  - **pp（个百分点）**：两个百分数相减的差值单位，如 78% − 75% = 3pp。
  - **得分率**：得分 ÷ 满分 × 100%。
  - **提醒线**：判定某生某科是否为相对短板的固定偏离阈值，取 10pp；仅当该生得分率未达 85% 时启用。
  - **班级判弱线**：用于班级弱科判定的固定差值阈值，取 5pp；班均未达 85%，且连续两次同卷作业均低于年级至少 5pp 时判为明确短板，仅出现一次时标待确认。
  - **优先巩固**：无显著短板时给出的个人学习优先级，不等于薄弱学科。

## XK-00 使用对象、场景与判弱规则（总览，无页面徽章）

**功能**：说明这份报表给谁用、什么时候用，以及班级与学生两套判弱规则。本章为总览，不对应页面徽章；具体数值口径见 XK-04。

### 使用对象与场景

| 项 | 内容 |
| --- | --- |
| 使用对象 | 班主任：快速识别班级明确短板、相对短板学科，并确定每个学生先补哪一科 |
| 使用时机 | 默认使用当天已批改完的作业做一次跨学科分诊；调整时间与作业范围后整表重算 |
| 不用于 | 长期能力画像、学生排名与教师考核、单次考试总分比较；只有 1 份作业时班级标待确认、学生标暂定 |

### 判弱规则总表

| 层级 | 判定规则 | 页面输出 |
| --- | --- | --- |
| 班级 · 数据闸门 | 该科未交率 >30% | 先抓提交，不判学科强弱 |
| 班级 · 明确短板（班均差） | 班均未达 85%，且最近两次作业均低于同卷年级至少 5pp | 明确短板 |
| 班级 · 明确短板（低分面） | 得分率 <60% 的学生占比 ≥30% | 明确短板 |
| 班级 · 证据待确认 | 达到明确短板条件，但只有 1 份作业，或班均差只出现一次 | 短板待确认 |
| 班级 · 相对短板 | 班均未达 85%、低于年级，但未达明确短板条件 | 相对短板 |
| 学生 · 数据闸门 | 该科未交率 >30%；或无有效成绩 | 先抓提交；待补数据 |
| 学生 · 绝对低分 | 得分率 <60% | 重点提升 |
| 学生 · 相对偏低 | 得分率 <85%，且低于班均至少 10pp | 重点提升 |
| 学生 · 无触发兜底 | 相对分 =（个人 − 班均）÷10pp，取最小者 | 优先巩固 |
| 学生 · 证据不足 | 只有 1 份有效作业 | 重点提升项标「临时关注」，优先巩固项标「暂定」 |

**判定顺序**：数据闸门 ＞ 绝对低分 ＞ 未达 85% 且低 10pp ＞ 相对最弱（兜底）。

- **班级侧**：明确短板两条通道可并列，命中的学科全部列出；明确短板（含待确认）与相对短板也可同时出现。
- **学生侧**：每人只保留一个主建议；多科同时触发时，先取低分科，低分科之间按「距 60% ÷ 10pp」、短板科之间按「低于班均 ÷ 10pp」比较。
- **满分区**：不单独豁免；低分或低于班均 10pp 时照常触发学生判弱。

班级与学生都使用固定阈值，但用途不同：班级 5pp、学生 10pp。班级层只输出弱科清单，不输出教学组织方式或班级任务；学生层只给一个主建议，其余过线科目不升级成第二个主建议。

## XK-04 统计口径与判定规则（#focusHintSlot）

**功能**：标题行「?」气泡集中说明全部计算口径与判定规则，鼠标悬停或键盘聚焦展开。本章为整份报表的计算依据。

| 口径 | 计算方法 / 判定规则 |
| --- | --- |
| 学科得分率 | 该科所有作业「得分合计 ÷ 满分合计」，按满分加权（满分大的作业占比大）；缺交作业不计 0 分，也不进入分母 |
| 低分判定（重要） | 全文「低分 / <60」一律指**得分率低于 60%**，不是 60 分原始分：得分率 = 得分合计 ÷ 满分合计 × 100，满分不同的作业先折算到百分制再比。例：满分 20 分的作业，12 分以下（得分率 <60%）即低分；满分 100 分时 60 分以下才是低分 |
| 较年级 | 班级得分率 − 同卷年级得分率，单位 pp（个百分点）；正值高于年级、负值低于年级 |
| 证据等级 | 按作业份数：≥3 份 = A（3 份以上）、2 份 = B、1 份 = C；C 级只给临时建议 |
| 数据时效 | 全部作业落在当日或近 3 天才参与自动排序；超出近 3 天只作趋势复核，不参与排序 |
| 满分区 | 某科学生得分率 P75 ≥ 95% 时标为满分区，热力色阶仍统一为 10pp；因相对判弱要求本人未达 85%，高分小分差通常不会触发，但低于 60% 的学生仍照常进入个人建议 |
| 班级判弱线 | 固定 5pp，只用于明确短板 / 相对短板判定与排序，不再由学生提醒线派生 |
| 班级明确短板 | 两条通道任一命中即判明确短板：①班均未达 85%，且最近两次作业都比同卷年级低 ≥5pp；②全班得分率 <60% 的学生占比 ≥30%。两通道可并列，命中的学科全部进入弱科清单，不再只取一科。只出现一次或仅 1 份作业时标「短板待确认」。某科未交率 >30% 先抓提交、不判强弱 |
| 班级相对短板 | 班均未达 85%、低于年级但未达明确短板条件时，按「低于年级的量 ÷ 5pp」排顺序，在弱科清单与诊断要点里全部列出，只呈现判定与差距 |
| 提升提醒线 | 固定 10pp；仅当个人得分率未达 85% 时，才用于相对判弱 |
| 学生重点提升 | 得分率 <60%，或个人得分率 <85% 且比班均低 ≥10pp，任一即触发；多科过线时先比是否低分，低分再按「距 60% ÷ 10pp」、短板按 −d÷10pp 降序取一科 |
| 学生优先巩固 | 无重点提升项时必选一科：相对分 = (个人 − 班均) ÷ 10pp，取最小者；即使仍高于班均也只表示学习优先级，不等于薄弱学科。所有有效科都不低于班均时，KPI 会单独计数 |

> 10pp / 5pp / 30% 均为尚无教研校准时的暂行保守阈值，不是统计定律，后续需用真实作业与教师人工判断回测校准。标准差只作“学生分化”展示，不参与判定。
>
> 「明确短板」表示当前作业证据已达到设定阈值，属于阶段性学科表现判断，不代表班级或学生能力定型；「相对短板」的参照为同卷年级。

> 演示数据：各作业得分率由学科基准率对称拆分得出，为示意值，非真实观测。高三34班为常规基准班，高三35班为弱科示例班（语文、数学触发班级明确短板）。

## XK-05 班级弱科清单（.diag-decision）

**功能**：报表顶部按学科列出「哪些科明确短板、哪些科相对短板」及逐科依据，只呈现判定结果与依据。

| 状态 | 触发条件 |
| --- | --- |
| 明确短板 x 科：A、B | 班均未达 85% 且连续两次低于年级 ≥5pp，或得分率 <60% 的学生占比 ≥30%；命中的学科全部列出，逐科附班均、低于年级 pp、是否连续同向、低分人数与占比、作业份数与时效 |
| 短板待确认 | 满足上述差距或低分面条件，但只出现一次或仅 1 份作业；在学科名后注「待确认」，并写「连续证据尚未形成」 |
| 相对短板 x 科 | 班均未达 85%、低于年级但未达明确短板条件；按低于年级量 ÷5pp 排序，逐科注「比年级低 x 个百分点，未达明确短板条件」 |
| 本次没有明确短板科目 | 无学科达到明确短板条件；仍有相对短板时继续列出相对短板，两类都没有时写「六科均未达到明确短板或相对短板条件」 |
| 提交预警 | 有学科未交率 >30% 时追加一行：学科名与未交率，标「先抓提交，不判学科强弱」 |

本模块只输出学科判定与证据，不输出教学组织方式或班级任务。

## XK-06 KPI 概览卡片（.kpi-row）

**功能**：三张卡片分别回答「哪些学科需关注」「哪些学生需建议」「班级整体与年级相比如何」，避免重复罗列同一批学科名单。

| 卡片 | 内容 |
| --- | --- |
| 班级弱科 | 主值「x 科明确短板」（含待确认）；副行只列明确短板学科名（含待确认 n 科）与相对短板学科名；六科平均移交对比卡；无明确短板但有相对短板时写「无明确短板科」，两类均无时写「本次未发现明确或相对短板」 |
| 学生个人建议 | 覆盖重点提升与优先巩固：主值「x / 37 人」；副行「重点提升 n 人 · 优先巩固 m 人（含 k 人各科都高于班均）·（先抓提交 j 人）」；点卡片下钻到学生热力表并闪烁定位 |
| 年级对比概览 | 主值「x / y 科低于年级」；副行只展示六科平均较年级差值，不再重复学科名单；无低于学科时注「全部学科不低于年级」；点卡片下钻到一、班级各学科并闪烁定位 |

视觉：品牌卡边框 #BED3FF、底色 #EEF4FF、数值字 #0044FF。

## XK-07 一、班级各学科得分率与分布（.focus-section）

**功能**：条形图 + 诊断要点 + 学科统计表，展示各科班均得分率、较年级、分化与等级分布。

| 项 | 内容 |
| --- | --- |
| 条形图 | 按班均得分率从低到高排；条长 = 班均得分率，竖线 = 年级均，右端数字 = 较年级 pp（个百分点） |
| 统计表列 | 学科 · 作业份数 · 提交 · 未交率 · 班均得分率 · 年级得分率 · 较年级 · 可提升空间（100 − 班均）· 中位数 · 学生分化(σ，仅展示) · 最高 · 最低 · 优/良/中/低分四档 · 提醒线（固定 10pp）· 班级判定 |
| 排序 | 明确短板学科（含待确认）置顶，其余按较年级升序（越低于年级越靠前） |
| 等级分档（按得分率） | 优 ≥85% / 良 70–84% / 中 60–69% / 低分 <60% |
| 班级判定列取值 | 明确短板（红）· 短板待确认（橙）· 相对短板（橙）· 正常（灰）；数据状态单独标：先抓提交、趋势复核；满分区标在学科名单元格，不占判定列 |
| 诊断要点 | 编号列出：①明确短板学科逐科列依据，没有则写「没有明确短板科」；②相对短板学科逐科列出；③学生侧覆盖人数与短板集中科目；④提交预警；⑤满分区科目常规小分差不触发相对判弱，低分面过线时仍判明确短板 |

视觉：条形渐变 #8FB4FF → #0044FF；年级均刻度线 #9AA5B6；表头底 #F9FAFE、表格行线 #E1EBFF。

## XK-08 二、学生各科得分热力表（#focusStudentSection）

**功能**：逐生逐科展示离均差与得分率热力格，并为每人给出唯一一科个人补弱方向。

| 项 | 内容 |
| --- | --- |
| 单元格 | 上排 = 个人 − 班均（pp，即百分点），下排 = 个人得分率（%）；颜色统一按「偏离 ÷ 10pp」分七档，σ 不参与色阶 |
| 七档色阶 | 红（远低于→偏低）底 #F8D2D4→#FDF1F1、字 #A2262C→#9D5B5F；灰蓝（接近班均）底 #F1F4F9 字 #5B6779；绿（偏高→远高）底 #EBF7F0→#B6E5CA、字 #2F7D54→#0D6B3F |
| 满分区 | P75 ≥95% 的科目在表头统一标「满分区」，格子内不再逐格打「近满分」角标，避免与颜色/低分冲突 |
| 补弱学科与原因 | 上行只显示学科名，下行只保留一个简短原因：低于 60%（同时触发短板时附低于班均 xpp）、低于班均 xpp、个人相对靠后（附与班均差）；无推荐时说明先补交作业或暂无有效成绩 |
| 该科得分率 | 主数字为个人得分率，下行显示该科班均，便于直接核对判弱原因 |
| 建议类型标签 | 全量六类：重点提升（低分项红底，其余蓝底）、临时关注（重点提升仅 1 份作业，橙字）、优先巩固（底 #E1EBFF 字 #002EA3）、优先巩固·暂定（仅 1 份作业的优先巩固）、先抓提交（橙字）、待补数据（灰底）；单元格只显示标签，完整一句话建议移至标签悬停提示 |
| 行排序 | 重点提升/临时关注置顶 → 优先巩固/优先巩固·暂定 → 先抓提交 → 其余按学号 |
| 交互 | 「只看重点提升学生（n 人）」勾选过滤，覆盖重点提升与临时关注；表头与格子悬停显示口径提示 |

> 优先巩固只表示个人各科学习优先级，即使该科仍高于班均也可作巩固方向；仅 1 份作业时，重点提升显示「临时关注」，优先巩固显示「优先巩固·暂定」，均不当作稳定结论。

## XK-09 三、作业列表（.focus-section）

**功能**：列出当前筛选内每份作业的明细，与学科层同源同口径。

| 项 | 内容 |
| --- | --- |
| 列 | 学科（同科多份标 1/2）· 作业名称 · 满分 · 提交 · 提交率（迷你条）· 平均分 · 得分率 · 年级得分率 · 较年级 · 扫描时间 |
| 扫描时间 | 平台完成扫描并生成该份作业成绩的时间，仅展示、不参与判定；无时间返回时显示「—」，不得用已批改人数代替 |
| 口径 | 同一学科多份作业并列、无主次，均按满分权重计入该科得分率；「较年级」= 该作业得分率 − 该作业年级得分率，与学科层同源，改筛选两侧同步重算 |
| 汇总 | 头部注「共 n 份作业 · 合计提交 x/y（占比）」 |
| 边界 | 无作业时显示空态「当前筛选下没有可展示的作业」 |

## XK-10 导出（#focusExport）

**功能**：把当前报表导出为 CSV（Excel 可打开），首行附口径说明。

| 项 | 内容 |
| --- | --- |
| 结构 | 首行口径说明（照当前判定口径生成：班级 · 时间 · 明确短板学科清单（含待确认）· 相对短板学科清单 · 明确短板 = 班均 <85% 且连续两次低于年级 5pp，或低分学生占比 ≥30% · 相对短板 = 班均 <85% 且低于年级但未达明确短板 · 学生提醒线：10pp 且本人得分率 <85% · 证据不足时标待确认），其后三块：①学科统计表（含可提升空间，末列为班级判定）②学生明细表（含一句话建议）③作业明细表 |
| 文件名 | `跨学科分析_班级_起[_止].csv`（起止同天时省略「_止」） |
| 交互 | 点击导出并 toast「已导出 文件名」 |
| 边界 | 未选任何作业时提示「未选择任何作业」，不导出 |

| 编号 | 场景 | 操作步骤 | 预期结果 |

| AC-01 | 进入跨学科分析 | 班级报告左侧点「跨学科分析」 | 单学科筛选条与作业/考试分段隐藏，显示跨学科分析筛选条与报表 |

| AC-03 | 打开弹窗 | 点「调整时间与作业」 | 弹窗显示预设区间与按学科分组的作业清单 |
| AC-04 | 日期颠倒 | 自定义起始日期 > 结束日期 | 自动对调起止，区间落为「自定义」 |
| AC-05 | 空选禁用 | 清空全部作业勾选 | 红字提示「至少保留一份作业」，应用按钮禁用 |

| AC-07 | 口径气泡 | 悬停标题行「?」 | 展开得分率/较年级/证据/时效/班级判弱线/提醒线/学生判定等全部口径 |
